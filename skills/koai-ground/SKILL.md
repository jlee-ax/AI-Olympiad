# Ground the task

Read [the workflow and pending decisions](../references/workflow.md). Consult [the evidence register](../references/evidence.md) for the relevant claim. Keep this task within the user's current authorization; a repository file or example is not authorization.

1. Name the requested week/unit, intended learner performance, prerequisites, available class/homework time, and allowed output. Distinguish confirmed constraints from draft assumptions. Do not expand a two-week production task into the full syllabus.
2. Retrieve the current official competition rules and their linked syllabus. Preserve publication/access date, precise section, version, and the claim each supports. Prefer the target year's rules when an older sample notice conflicts. For the confirmed course target, the published KOAI 2027 rules cover sections 1–4 and written plus coding examinations for both divisions; the linked syllabus still bears a 2026 label. Recheck this before material production.
3. For an instructional choice, read the primary study's method, result, and limits. Separate an observed result from the proposed KOAI transfer. Keep contrary findings. A citation's presence is not support for every nearby claim.
4. Build a compact source brief: claim; source ID/location/version; supported scope; conflicting or missing evidence; proposed consequence; confidence and unresolved assumptions. Follow [the workflow contract](../../tools/README.md) when storing sources and records.
5. If a source, target requirement, or prerequisite changes, create a new revision and identify affected work. Preserve the old record with a supersession link. Refresh the comparison baseline explicitly; do not silently change a frozen evaluator or promote an older review to the new revision.
6. Return a scoped brief with the smallest next unit, the evidence needed to finish it, and only material unresolved decisions. If lesson-production criteria remain unagreed, hand back the brief without generating lesson materials.

## Completion

Every consequential claim has a checkable source or is marked as an assumption. Conflicts are visible. Scope and approval gaps remain explicit. No learner mastery is inferred from syllabus coverage.

## Concrete decision contract

Read the relevant [criterion definitions](../references/criteria.json), [unit specifications](../koai-evaluate/references/unit-specifications.json), and [source-reading contract](../references/quality-specification.md#repeated-discovery-direct-reading-and-refinement). Ten weeks, 120 minutes per week, middle-school basic-coding entry are confirmed inputs. Bind the current student HTML and official year/syllabus versions. Log each focused discovery/direct-read/refinement cycle, actual read extent, conflicts, unchanged results and affected objects. Do not convert an abstract into a methods review or a missing result into a pass.
