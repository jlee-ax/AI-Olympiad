1. 입력 데이터와 특성¶

분류는 입력을 보고 정해진 종류 가운데 하나를 예측하는 문제다. 손글씨 숫자 분류에서는 이미지 한 장이 하나의 입력이며, 예측할 종류는 0부터 9까지다. 머신러닝에서는 입력 한 건을 샘플, 입력의 한 가지 성질을 수로 나타낸 값을 특성, 실제로 어떤 종류에 속하는지 표시한 값을 클래스 레이블이라고 한다.

이 장에서 쓰는 자료는 scikit-learn에 들어 있는 손글씨 이미지 1,797장이다. 원래 32×32칸인 흑백 이미지를 가로세로 4칸씩 겹치지 않게 나눈다. 각 구역에서 획에 속한 픽셀 수를 세면 0부터 16까지의 정수 하나를 얻는다. 구역은 가로 8개, 세로 8개이므로 이미지 한 장을 64개의 특성으로 나타낼 수 있다. 같은 구역 안에서 획의 위치만 다르고 픽셀 수가 같으면 이 표현으로는 그 차이를 알 수 없다. 자료의 구성 · scikit-learn 자료 설명

이미지 한 장과 특성 벡터¶

0번 이미지의 정답은 숫자 0이고, pixel_2_2의 값은 15다. 15는 그 구역에서 센 픽셀 수다. 아래 그림은 64개 구역의 값을 원래 위치에 배치한 것이다. 이어지는 표에는 그림과 같은 값을 숫자로 표시했다. 표의 첫 행부터 차례로 읽으면 특성 벡터, 즉 각 특성값을 정해진 순서로 나열한 목록이 된다.

구역의 행 번호가 r, 열 번호가 c라면 벡터에서의 위치는 8r+c이다. 앞에 있는 r개의 행마다 구역이 8개씩 있기 때문이다. 따라서 구역 (2,2)는 벡터의 18번 위치다. 이 순서를 알면 길이 64인 벡터를 원래 8×8 배열로 되돌릴 수 있다. 반면 구역 안에서 처음에 합쳐 버린 4×4개의 픽셀 배치는 되돌릴 수 없다.

2. 산술평균과 결측값¶

값 x1,…,xn의 산술평균은 그 합을 값의 개수 n으로 나눈 수다. 예를 들어 0과 10의 평균은 (0+10)/2=5다. 0도 값이므로 개수에 포함한다.

결측값은 해당 위치의 값을 알 수 없다는 표시다. 아래 예제는 결측값이 없는 원자료를 복사한 다음, 세 이미지의 측정값 중 하나를 연습용으로 가린다. 보이는 값이 0, 10, 빈칸이면 기록된 두 값의 평균은 5다. 세 번째 값을 m이라 하면 세 값 전체의 평균은 (10+m)/3이므로 가린 값을 모르는 동안에는 전체 평균을 결정할 수 없다. 빈칸을 0으로 채우면 평균은 10/3이 된다. 이는 세 번째 값이 0이라는 가정을 새로 한 계산이다.

다음 함수는 수치 목록에서 기록된 값의 합과 개수를 따로 누적한다. 기록된 값이 하나도 없으면 평균이 정의되지 않으므로 None을 반환한다. Python의 반복문과 반환값은 함수 연습에서 확인할 수 있다.

def observed_mean(values):
    total = 0
    count = 0
    for value in values:
        if not pd.isna(value):
            total += value
            count += 1
    return None if count == 0 else total / count

observations = source_table.loc[[11, 56, 10], "pixel_2_2"].copy()

분산과 표준편차¶

자료 A가 2,4,6, 자료 B가 4,4,4라면 두 자료의 평균은 모두 4다. A에는 평균보다 작은 값과 큰 값이 모두 있고, B에서는 모든 값이 평균과 같다. 평균 하나만으로는 이 차이가 드러나지 않는다.

각 값에서 평균을 뺀 값 xi−x¯를 편차라고 한다. A의 편차는 −2,0,2다. 그대로 더하면 음수와 양수가 상쇄되어 합이 0이 된다. 각 편차를 제곱한 뒤 평균을 낸 것이 분산이다. 주어진 자료 전체를 기술할 때에는 값의 개수 n으로 나눈다.

v=1n∑i=1n(xi−x¯)2

A의 분산은 (4+0+4)/3=8/3이고 B의 분산은 0이다. 표준편차는 분산의 제곱근이다. A의 표준편차는 약 1.63이다. 길이를 cm로 쟀다면 분산의 단위는 cm²이고, 표준편차의 단위는 원래 값과 같은 cm다. 여기서는 주어진 값 자체를 요약한다. 통계에서 관심을 두는 대상 전체를 모집단, 거기서 고른 일부를 표본이라고 한다. 표본을 이용해 모집단의 분산을 추정할 때에는 흔히 분모 n−1을 쓴다.

3. 특성 행렬의 행과 열¶

이미지마다 같은 두 구역을 측정했으므로 각 이미지를 행, 두 구역을 열로 두어 특성 행렬 X를 만들 수 있다. 아래에는 원자료의 0번, 1번, 11번 이미지를 이 순서로 넣었다.

이미지 번호 구역 (2, 2) 구역 (4, 2)
0 15 8
1 3 1
11 0 12

NumPy에서 X.shape는 각 축의 길이를 순서대로 나타낸다. 이 행렬의 크기는 (3, 2)이다. 배열의 X[2,1]=12는 세 번째로 선택한 11번 이미지의 두 번째 구역 값이다. 배열에서의 위치 2와 원자료의 이미지 번호 11은 다른 정보다.

X.mean(axis=0)은 행에 걸쳐 같은 구역의 값을 평균 낸다. 첫 결과는 (15+3+0)/3=6이다. X.mean(axis=1)은 열에 걸쳐 한 이미지 안의 두 구역 값을 평균 낸다. 0번 이미지의 결과는 (15+8)/2=11.5이다. 전자는 구역마다 값 하나, 후자는 이미지마다 값 하나를 낸다.

전치, 배열 모양 변경, 브로드캐스팅¶

전치는 행과 열을 교환한다. X의 첫 열 [15,3,0]은 전치한 배열의 첫 행이 된다. reshape는 기본 설정에서 원소를 행 순서로 읽어 새 모양에 차례로 채운다. 같은 X를 (2, 3)으로 바꾸면 첫 행은 [15,8,3]이다. 결과의 크기가 같다고 해서 좌표의 뜻까지 같은 것은 아니다.

브로드캐스팅은 NumPy가 크기가 다른 배열의 원소를 대응시켜 계산하는 규칙이다. 오른쪽 끝의 축부터 크기를 맞춘다. 두 크기가 같거나 한쪽이 1이면 계산할 수 있고, 없는 축은 크기 1로 본다. (3, 2) 행렬에서 길이 2인 열 평균을 빼면 각 열의 값에서 그 열의 평균이 빠진다. 반면 길이 3인 배열을 그대로 빼면 마지막 축의 2와 3이 맞지 않는다. 필기 연습

4. 산점도¶

산점도는 한 대상에서 측정한 두 값을 가로축과 세로축의 좌표로 나타낸 그림이다. 여기서 가로축은 이미지의 구역 (2, 2)에서 센 픽셀 수, 세로축은 구역 (4, 2)에서 센 픽셀 수다. 예를 들어 0번 이미지는 첫 값이 15, 둘째 값이 8이므로 (15,8)에 표시된다. 점 옆의 번호는 원자료의 이미지 번호다.

그림에서 (16,16)을 보자. 10번, 20번, 26번 이미지가 이 좌표에 겹친다. 실제 숫자는 각각 0, 0, 6이다. 두 특성만 쓰는 분류기는 세 입력을 모두 (16,16)으로 받는다. 같은 입력에 항상 같은 답을 내는 방법으로는 이 세 이미지를 전부 맞힐 수 없다. 그래프가 겹쳐서 보기 어렵다는 문제에 그치지 않는다. 특성을 두 개로 줄이는 과정에서 분류에 필요한 정보가 사라진 사례다.

빈도와 상대도수¶

어떤 값이 나타난 횟수를 도수, 전체 개수에서 그 값이 차지하는 비율을 상대도수라고 한다. 위에서 고른 이미지 중 실제 숫자가 0인 것은 네 장이다. 그중 좌표가 (16,16)인 이미지는 두 장이므로 도수는 2, 숫자 0 집단 안에서의 상대도수는 2/4=0.5다. 숫자 6 집단에는 한 장이 있고 그 한 장이 조건에 맞아 상대도수는 1/1=1이다.

아래 막대의 높이는 집단별 상대도수를 백분율로 나타낸 값이다. 100%인 숫자 6 집단이 조건에 맞는 이미지를 가장 많이 포함한 것은 아니다. 또한 이 여덟 장은 설명을 위해 골랐으므로, 구한 비율을 전체 손글씨 자료의 비율로 해석할 수 없다.

여러 특성을 하나의 수로 요약하는 방법 중 하나는 각 특성에 정해진 수를 곱하여 더하는 것이다. 두 벡터 x=(x1,x2)와 w=(w1,w2)의 내적은 x1w1+x2w2이다. w를 계수로 쓰면 이 식은 x의 가중합이다.

두 구역 중 어느 쪽에 획이 더 많은지 비교하려면 첫째 값에서 둘째 값을 빼면 된다. 이는 w=(1,−1)인 내적과 같다. 0번 이미지에서는 15×1+8×(−1)=7이다. 첫째 구역에 획 픽셀이 7개 더 많다는 뜻이다. 구역 순서를 바꾸고 계수는 그대로 쓰면 부호가 뒤집힌다. 또한 (15,8)과 (13,6)은 둘 다 차이가 7이다. 차이 하나로 두 원래 값을 알아낼 수는 없다.

벡터로부터 유사도 행렬 계산하기¶

두 벡터의 내적에는 방향과 크기가 모두 영향을 준다. 예를 들어 질의가 q=(1,1)이고 후보가 a=(4,0), b=(1,1)이면 내적은 각각 4와 2다. 내적이 큰 후보는 a이지만 질의와 방향이 같은 것은 b다.

방향만 비교하고 싶으면 내적을 두 벡터의 길이의 곱으로 나눈 코사인 유사도를 쓸 수 있다. 벡터의 길이 ‖q‖는 각 좌표의 제곱합의 제곱근이다. 위 두 후보의 코사인 유사도는 각각 4/(2×4)=1/2, 2/(2×2)=1이다. 벡터 하나를 양의 상수배 하면 분자와 분모가 같은 비율로 바뀌어 결과가 같다. 길이가 0인 벡터에는 이 계산이 정의되지 않는다.

질의 벡터를 행으로 둔 행렬을 Q, 후보 벡터를 행으로 둔 행렬을 G라고 하자. QG𝖳의 (i,j) 원소는 질의 i와 후보 j의 내적이다. 따라서 한 번의 행렬곱으로 모든 쌍의 점수를 구할 수 있다. 크기까지 비교해야 하는지, 방향만 비교해야 하는지에 따라 입력 벡터를 그대로 쓸지 길이 1로 바꿀지 결정한다. 국제 과제의 원문이 이 점수 계산식을 지정한 것은 아니다.

queries = np.array([[1., 1.], [0., 1.]])
candidates = np.array([[4., 0.], [1., 1.], [0., 2.]])
candidate_numbers = np.array([81, 14, 57])
dot_scores = queries @ candidates.T
unit_queries = queries / np.linalg.norm(queries, axis=1, keepdims=True)
unit_candidates = candidates / np.linalg.norm(candidates, axis=1, keepdims=True)
cosine_scores = unit_queries @ unit_candidates.T
print("내적 행렬:\n", dot_scores)
print("코사인 유사도 행렬:\n", cosine_scores.round(3))
print("첫 질의가 고른 후보 번호 (내적 / 코사인):",

심화 A. 유클리드 거리와 최근접 중심 분류¶

숫자 0과 1의 손글씨를 구별하는 간단한 분류기를 만든다. 입력은 이미지에서 얻은 두 수 (x1,x2)이고, 출력은 예측한 숫자 0 또는 1이다. 두 입력 x=(x1,x2)와 z=(z1,z2)의 유클리드 거리는 다음과 같다.

d(x,z)=(x1−z1)2+(x2−z2)2.

이는 평면에서 두 점을 잇는 선분의 길이다. 두 거리를 비교할 때는 제곱근을 생략해도 대소관계가 같다. 예를 들어 (4,3)에서 (3,1)까지의 제곱거리는 12+22=5이다. 한 특성의 단위만 바꾸어 수치가 10배가 되면 그 좌표가 제곱거리에 기여하는 양은 100배가 된다. 거리 계산에서는 어떤 특성을 쓰고 어떤 척도로 재는지가 중요하다.

def squared_distances(point, centers):
    differences = np.asarray(centers, dtype=float) - np.asarray(point, dtype=float)
    return np.sum(differences ** 2, axis=1)

print("점 (4,3)에서 (3,1), (4,7)까지의 제곱거리:",
      squared_distances([4, 3], [[3, 1], [4, 7]]))

클래스 중심이 평균인 이유¶

최근접 중심 분류기는 클래스마다 훈련 벡터의 평균을 구하고 새 입력을 가장 가까운 평균의 클래스로 분류한다. 차이가 큰 훈련값에 더 큰 벌점을 주기 위해 거리의 제곱합을 쓰면, 한 클래스의 대표점으로 평균이 얻어진다.

한 특성의 두 값이 8과 16일 때 대표값을 a라고 하자. 두 값까지의 제곱거리 합은 (8−a)2+(16−a)2=2(a−12)2+32이다. 오른쪽의 첫 항은 음수가 될 수 없으므로 a=12가 최솟값을 준다. 일반적으로 n개의 평균을 x¯라 할 때에도

∑i=1n(xi−a)2=∑i=1n(xi−x¯)2+n(a−x¯)2.

xi−a=(xi−x¯)+(x¯−a)를 제곱해 합하면 교차항이 사라진다. 편차들의 합이 0이기 때문이다. 벡터에서는 각 좌표의 제곱오차를 더하므로 좌표별로 평균을 구하면 된다.

이 예제에서 숫자 0의 훈련 벡터는 (15,8)과 (6,16)이다. 중심은 ((15+6)/2,(8+16)/2)=(10.5,12)이다. 숫자 1의 벡터 (3,1)과 (0,12)에 대해서도 중심을 계산한 뒤 아래 결과와 비교하자.

심화 B. 마스크를 이용한 특성 추출과 분류 문제¶

이미지의 모든 위치가 유효하지는 않을 수 있다. 어느 위치를 계산에 포함할지 표시한 배열을 마스크라고 한다. 이 연습에서 작은 흑백 이미지 I와 마스크 M은 각각 2×2 배열이며, 원소는 0 또는 1이다. I에서 1은 획에 속한 칸을, M에서 1은 측정에 사용할 칸을 뜻한다. 예를 들어 이미지의 값이 1이어도 같은 위치의 마스크 값이 0이면 그 칸은 계산에서 제외한다.

아래는 이미지와 마스크를 마지막 축에 나란히 저장한 연습 자료다. 각 channels의 크기는 (2, 2, 2)이고 channels[:, :, 0]이 이미지, channels[:, :, 1]이 마스크다. value는 함께 주어진 또 하나의 수치 특성이다. 훈련 표의 label은 클래스 0 또는 1이고, 빈칸은 레이블 미상이다.

  1. 학습에 사용할 수 있는 레이블을 가진 행을 고르시오. 그 행들만 사용해 value의 결측값을 대체할 평균을 구하시오. 수치 0과 결측값이 계산에 각각 어떻게 들어가는지 쓰시오.
  2. T2의 이미지와 마스크를 따로 그리시오. 유효한 획의 개수를 곱과 합으로 표현하고 계산하시오. 같은 개수이면서 획의 위치가 다른 이미지 두 개를 만드시오. 이 예로부터 개수만으로 풀 수 없는 문제를 하나 설명하시오.
  3. T2의 배열을 .copy()한 뒤 이미지 채널을 기본 슬라이스로 꺼내시오. 슬라이스의 복사본도 따로 만든 뒤, 복사하기 전의 슬라이스에서 유효한 획 픽셀 하나를 1에서 0으로 바꾸시오. 처음 배열, 실험용 복사본, 슬라이스, 슬라이스의 복사본 가운데 어느 곳에 변화가 생기는지 예상한 뒤 확인하시오. NumPy의 뷰는 원래 배열과 같은 메모리를 본다.
  4. value와 유효한 획의 개수를 두 특성으로 사용하시오. 클래스마다 중심을 구하고 새 입력에서 두 제곱거리를 비교하시오. 검증용 세 행의 예측을 먼저 보관한 다음 정답과 비교하시오. 한 검증 결과의 손계산을 제시하시오. 새 입력 N7, N3, N1의 결과는 이 순서로 정리하시오.

심화 C. 이미지 영역과 배열 슬라이스¶

이미지에서 직사각형 영역을 선택할 때 NumPy의 A[top:bottom, left:right]는 시작 좌표는 포함하고 끝 좌표는 제외한다. 영역 안 행의 개수는 bottom−top, 열의 개수는 right−left이다. 따라서 선택한 칸 수는 두 값의 곱이다.

예를 들어 8행 12열 이미지에서 행 구간 [2,4), 열 구간 [4,7)인 영역은 행 2·3과 열 4·5·6으로 이루어져 6칸이다. 잘라낸 부분의 크기는 (2, 3)이지만 원래 이미지에서 선택한 위치를 나타내는 불리언 마스크의 크기는 (8, 12)다. 원래 값이 0인 칸도 선택한 위치라면 영역의 넓이에 포함된다.

아래 코드는 좌표가 배열 안에 있고 허용 넓이 이하인지 확인한 뒤 영역을 자른다. NumPy 슬라이스는 배열 밖의 끝 좌표를 자동으로 줄일 수 있으므로, 잘라낸 배열의 크기만 보고 원래 좌표가 유효했다고 판단해서는 안 된다.

이 계산은 IOAI 2025 Pixel Efficiency에서 필요한 원리 중 하나다. 공식 과제에서는 224×224 이미지의 6.25% 이내, 즉 최대 3,136칸에 해당하는 영역을 고른다. 유효한 영역을 잡는 일과 분류에 유용한 영역을 고르는 일은 다른 문제다. 아래 8×12 배열은 좌표 계산을 위한 연습이다. 대회 원문
