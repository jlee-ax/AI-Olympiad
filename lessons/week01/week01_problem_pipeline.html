1주차 보충 · 라벨이 일부만 있는 데이터의 분류¶

IOAI 2025 개인전 Antique Painting Authentication은 그림의 디지털 특성으로 진품과 복제품을 구분하는 문제입니다. 이 문제에서 라벨은 진품이나 복제품으로 확인된 결과를 나타내는 값입니다. 공개 훈련 데이터 500점 중 진품으로 확인된 그림은 2점, 복제품으로 확인된 그림은 2점입니다. 나머지 496점에도 특성값은 있지만 정답은 알려지지 않았습니다. 대회 훈련 데이터

1–3절에서는 진위가 확인된 그림으로 진품과 복제품의 평균 벡터를 구합니다. 평균 벡터는 같은 종류의 그림을 모아 특성마다 평균을 낸 뒤 그 값들을 차례로 적은 것입니다. 새 그림을 두 평균 벡터 중 어느 쪽에 더 가까운지로 분류하고, 학습에 쓰지 않은 그림으로 정확도를 구합니다.

4절의 독립 문제에서는 다른 표로 같은 원리를 직접 적용합니다. 파일을 저장하면서 행 순서가 달라지는 경우는 선택 실습에서 다룹니다.

1. 그림의 특성, 라벨, 훈련 데이터¶

대회 훈련 파일에서 한 행은 그림 한 점입니다. feature1부터 feature5까지는 특성, 즉 그림을 나타내는 다섯 개의 수입니다. 원문은 각 특성이 어떤 물리량인지 밝히지 않습니다. 마지막 열 Authenticated는 라벨, 즉 확인된 분류 결과를 기록하는 열입니다. 1은 진품, −1은 복제품, 0은 미확인입니다. 공식 문제 1–2절

훈련 파일의 행 번호 다섯 특성의 값(소수 셋째 자리까지 반올림) Authenticated
1 [0.600, 0.012, 0.209, 1.088, 4.088] 0
47 [−0.534, 4.897, 0.658, 1.269, 3.627] −1
142 [3.188, −2.940, −0.404, 0.737, 3.842] 1

행 번호는 열 이름을 제외하고 첫 그림부터 센 순서입니다. 47번째 그림은 복제품의 예로 학습할 수 있습니다. 첫 번째 그림은 다섯 특성이 모두 있어도 진품인지 복제품인지 모릅니다. 미확인 496점을 모두 복제품으로 처리하면 확인하지 않은 정답 496개를 훈련 데이터에 넣게 됩니다. 공개 훈련 CSV

훈련 데이터는 분류 규칙을 정하는 데 쓰고, 검증 데이터는 그 규칙으로 새 표본을 얼마나 잘 분류하는지 살펴보는 데 씁니다. 테스트 데이터는 마지막 평가에 씁니다. Antique의 검증·테스트 데이터에는 각각 별도의 그림 500점이 있습니다. 참가자가 직접 볼 수 있는 것은 훈련 데이터입니다. 채점할 때 제출한 코드가 검증·테스트의 다섯 특성을 읽고 각 그림의 라벨 −1 또는 1을 예측합니다.

모든 대회 문제가 훈련 데이터를 제공하는 것은 아닙니다. IOAI 2026의 Potato에는 라벨이 붙은 훈련 데이터가 없습니다. 심판이 알려 주는 두 단어의 비교 결과를 바탕으로 다음 단어를 제안하며, 공개된 게임으로 제안 방법을 시험할 수 있습니다. 그림의 정답으로 분류기를 학습하는 Antique와 어떤 자료가 다른지 구분해 보세요. Potato 원문의 Task·Dataset

계산에 사용할 훈련 표¶

다음 표는 손으로 계산할 수 있도록 새로 만든 연습 데이터입니다. 대회 파일에서 뽑은 값이 아닙니다. 두 특성 feature1과 feature2는 같은 척도의 숫자로 두고, label에는 대회와 같은 기호를 씁니다. row_id는 같은 그림을 다시 찾기 위해 붙인 식별자(ID)입니다. 예를 들어 T2는 이 훈련 표의 두 번째 그림입니다. 대회 훈련 파일에는 별도의 식별자 열이 없습니다.

라벨이 확인된 표본과 정답을 짝지어 분류 규칙을 배우는 방법을 지도학습이라고 합니다. 여기서는 라벨이 있는 훈련 그림만 사용합니다. 미확인 그림의 특성값까지 활용하도록 한 대회의 전체 요구 중 일부를 연습하는 것입니다.

2. 클래스별 평균 벡터와 최근접 중심 분류기¶

클래스는 분류할 종류를 뜻합니다. 여기에는 진품과 복제품 두 클래스가 있습니다. 연습 표에서 T2의 둘째 특성은 비어 있습니다(NaN). 라벨이 확인된 훈련 그림 중 이 특성을 관측한 T1, T3, T4의 평균 (1+3+5)/3=3으로 빈칸을 채웁니다. 같은 방식으로 첫째 특성의 평균은 (1+3+7+9)/4=5입니다. 검증 그림에 빈칸이 있어도 이 훈련 평균을 씁니다.

복제품 T1과 T2의 특성 벡터는 이제 [1,1]과 [3,3]입니다. 첫째 특성의 평균도 (1+3)/2=2, 둘째 특성의 평균도 2이므로 복제품의 평균 벡터, 곧 이 클래스의 중심은 [2,2]입니다.

왜 평균을 중심으로 삼을까?¶

첫째 특성의 값 1과 3을 대표할 수 하나를 a라고 합시다. 각 값과 a 사이의 차이를 제곱해 더하면 (1−a)²+(3−a)²입니다. 이 식은 2(a−2)²+2와 같습니다. 제곱은 0 이상이므로 a가 2일 때 합이 2로 가장 작습니다.

이 성질은 표본이 늘어나도 같습니다. 한 특성의 훈련값을 x₁,…,xₙ, 그 평균을 m이라고 쓰겠습니다. Σ는 n개 항을 더한다는 기호입니다. xᵢ−a를 (xᵢ−m)+(m−a)로 나누어 제곱하면 다음 식을 얻습니다.

Σ(xᵢ−a)² = Σ(xᵢ−m)² + n(m−a)²

각 훈련값 xᵢ에서 그 클래스의 평균 m을 뺀 값을 편차라고 합니다. 편차의 합 Σ(xᵢ−m)이 0이므로 전개할 때 생기는 항 2(m−a)Σ(xᵢ−m)도 0입니다. 오른쪽 첫 항은 a와 관계없고 둘째 항은 a=m일 때 가장 작습니다. 두 점 사이의 제곱거리는 각 좌표에서 두 값의 차이를 구하고, 그 차이를 제곱한 뒤 모두 더한 값입니다. 따라서 각 특성의 평균을 모은 벡터가 같은 클래스 안에서 제곱거리의 합을 가장 작게 합니다.

새 그림을 분류하는 방법¶

최근접 중심 분류기는 새 그림에서 각 클래스 중심까지의 거리를 비교해 더 가까운 클래스의 라벨을 예측합니다. 두 점 [x,y]와 [a,b] 사이 거리의 제곱은 (x−a)²+(y−b)²입니다. 제곱근을 취해도 대소 관계가 같으므로 제곱거리만 비교해도 됩니다. 한 특성의 단위만 바꿔 값을 10배로 쓰면 그 특성이 제곱거리에 더하는 값은 100배가 됩니다. 그래서 이 연습에서는 두 특성의 척도를 같게 두었습니다.

새 그림의 특성은 [6,3]입니다. 복제품 중심까지의 제곱거리는 (6−2)²+(3−2)²=17입니다. T3와 T4로 진품의 중심을 구한 뒤, 그 중심까지의 제곱거리와 예측 라벨을 먼저 적으세요. 아래 코드의 fit은 빈칸을 채울 평균과 두 클래스의 중심을 훈련 데이터에서 구합니다.

def new_model():
    return Pipeline([("fill", SimpleImputer(strategy="mean")),
                     ("classifier", NearestCentroid())])

model = new_model().fit(known_train[feature_cols], known_train["label"])
fill_values = model.named_steps["fill"].statistics_
centers = model.named_steps["classifier"].centroids_
class_names = model.named_steps["classifier"].classes_
print("빈칸에 쓸 훈련 평균:", fill_values)
for label, center in zip(class_names, centers):
    distance_squared = np.sum((np.array([6, 3]) - center) ** 2)
    print(f"라벨 {label}의 중심 {center}, [6, 3]까지의 제곱거리 {distance_squared:g}")

중심과 결정 경계¶

두 중심까지의 거리가 같은 위치를 결정 경계라고 합니다. 이 예에서는 특성이 [x,y]인 그림의 두 제곱거리가 (x−2)²+(y−2)²와 (x−8)²+(y−4)²입니다. 두 값이 같다는 식을 정리하면 3x+y=18입니다. [5.25,3]에서는 3×5.25+3=18.75이고 진품 중심 쪽이 더 가깝습니다.

T4의 첫째 특성만 9에서 11로 바꾼 훈련 표에서는 진품 중심이 [9,4]로 이동합니다. 이번에는 같은 [5.25,3]이 어느 중심에 더 가까운지 두 제곱거리를 비교하세요. 코드에서는 바꾼 표로 모델을 따로 학습합니다.

3. 검증 정확도와 데이터 누수¶

다음 네 그림은 훈련에 사용하지 않은 연습용 검증 표본입니다. V1~V4는 이 표에서 그림을 구별하는 식별자입니다. V3의 특성은 방금 손으로 계산한 [6,3]이고 V4의 첫째 특성은 비어 있습니다. V4에는 어느 훈련 평균을 적용해야 할까요?

훈련할 때 검증 정답을 사용하거나 검증값까지 섞어 대체 평균을 구하면 학습에 평가 데이터의 정보가 들어갑니다. 이를 데이터 누수라고 합니다. 검증 결과로 모델을 여러 번 고르면 검증 점수도 그 표본에 맞춰질 수 있습니다. 최종 평가는 따로 보관한 테스트 데이터로 합니다.

4. 독립 연습 · 세 특성으로 그림 분류하기¶

이 절부터 바로 실행할 수 있습니다. 아래 세 표는 원본 대회 데이터와 별도로 만든 새 연습 데이터입니다. 각 행은 그림 한 점이고, item은 그 그림의 식별자(ID)입니다. R1~R5는 훈련 그림, V1~V3는 검증 그림입니다. J3, J1, J2는 추가로 예측할 그림을 입력 순서대로 표시한 ID입니다.

def values_by_item(table, value_column, expected_items):
    if not isinstance(table, pd.DataFrame) or table.columns.tolist() != ["item", value_column]:
        raise ValueError(f"필요한 두 열: item, {value_column}")
    expected_items = list(expected_items)
    received_items = table["item"].tolist()
    for items in (expected_items, received_items):
        if not all(isinstance(item, str) and item.strip() for item in items):
            raise ValueError("각 그림에 비어 있지 않은 식별자가 필요합니다.")
        if len(items) != len(set(items)):
            raise ValueError("그림 식별자가 중복됐습니다.")
    if set(received_items) != set(expected_items):
        raise ValueError("검증 그림의 식별자를 각각 한 번씩 적으세요.")
    values = table.set_index("item")[value_column]
    for value in values:
        integer = isinstance(value, (int, np.integer)) and not isinstance(value, (bool, np.bool_))
        if not integer or value not in (0, 1):
            raise ValueError("정수 0 또는 1을 써 주세요.")
    return tuple((item, int(values.at[item])) for item in expected_items)

def is_missing_id(value):
    if not pd.api.types.is_scalar(value):
        raise ValueError("ID는 하나의 값이어야 함")
    return bool(pd.isna(value)) or (isinstance(value, str) and not value.strip())

def predict_pairs(fitted_model, frame):
    required = ["row_id"] + feature_cols
    missing = [name for name in required if name not in frame.columns]
    if missing:
        raise ValueError("필수 열 없음: " + ", ".join(missing))
    if frame["row_id"].map(is_missing_id).any() or frame["row_id"].duplicated().any():
        raise ValueError("row_id 결측 또는 중복")
    values = frame[feature_cols].apply(pd.to_numeric, errors="raise")
    if np.isinf(values.to_numpy(dtype=float)).any():
        raise ValueError("특성에 무한값은 허용하지 않음")
    labels = fitted_model.predict(values)
    return list(zip(frame["row_id"].tolist(), labels.tolist()))

def align_predictions(expected_ids, pairs):
    ids = list(expected_ids)
    pairs = list(pairs)
    if any(is_missing_id(row_id) for row_id in ids):
        raise ValueError("요구 ID 결측")
    if len(ids) != len(set(ids)):
        raise ValueError("요구 ID 중복")
    mapping = {}
    for row_id, prediction in pairs:
        if is_missing_id(row_id):
            raise ValueError("예측 ID 결측")
        if row_id in mapping:
            raise ValueError("예측 ID 중복")
        if isinstance(prediction, (bool, np.bool_)) or not isinstance(prediction, (int, np.integer)):
            raise ValueError("예측은 정수 -1 또는 1")
        if int(prediction) not in (-1, 1):
            raise ValueError("예측은 -1 또는 1")
        mapping[row_id] = int(prediction)
    if set(mapping) != set(ids):
        raise ValueError("요구 ID와 예측 ID가 다름")
    return [mapping[row_id] for row_id in ids]

import csv
import io
import zipfile

def csv_text(labels):
    return "".join(f"{value}\n" for value in labels)

def archive_texts(text_A, text_B):
    stream = io.BytesIO()
    with zipfile.ZipFile(stream, mode="w", compression=zipfile.ZIP_DEFLATED) as archive:
        archive.writestr("submissionA.csv", text_A)
        archive.writestr("submissionB.csv", text_B)
    return stream.getvalue()

def inspect_archive(blob, ids_A, preds_A, ids_B, preds_B):
    wanted = {"submissionA.csv": align_predictions(ids_A, preds_A),
              "submissionB.csv": align_predictions(ids_B, preds_B)}
    with zipfile.ZipFile(io.BytesIO(blob)) as archive:
        names = archive.namelist()
        if len(names) != 2 or set(names) != set(wanted):
            raise ValueError("ZIP 파일명이 다르거나 중복됨")
        actual = {}
        for name, expected in wanted.items():
            rows = list(csv.reader(io.StringIO(archive.read(name).decode("utf-8"))))
            if any(len(row) != 1 or row[0] not in ("-1", "1") for row in rows):
                raise ValueError("헤더 없는 한 열의 -1 또는 1이 필요함")
            labels = [int(row[0]) for row in rows]
            if len(labels) != len(expected):
                raise ValueError("입력 행 수와 예측 행 수가 다름")
            if labels != expected:
                raise ValueError("저장한 ID 대응 순서가 다름")
            actual[name] = labels
    return actual
