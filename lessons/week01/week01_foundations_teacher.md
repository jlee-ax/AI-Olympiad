## 수업을 여는 질문

A는 $(0,5)$인 복제품이고 B는 $(4,0)$인 진품이다. Q는 $(3,4)$다. 첫째 값으로만 보면 B, 둘째 값으로만 보면 A에 가깝다. 학생 둘의 답이 다르면 어느 답을 먼저 지우기보다 “당신의 풀이에서 어느 정도의 차이가 큰 차이인가?”를 묻는다. 출발점에 정답 라벨이 없는 Q를 쓴 이유다.

두 좌표를 그대로 믿는 풀이에서 거리제곱은 A에 10, B에 17이다. 첫째 값을 10배 단위로 표시하면 901과 116이 된다. 입력한 그림은 같지만 판정이 바뀐다. 학생이 “거리면 객관적인 기준”이라고 말하면, 단위를 정한 사람이 두 항목의 상대적 비중까지 정했다는 점을 이 계산으로 짚는다. 거리의 제곱이 측정값에 주는 가중치와 경계선의 기울기를 연결할 수 있다. 계산이 낯선 학생은 한 점의 세 숫자(가로 차이, 세로 차이, 제곱합)부터 확인한다.

## 어느 설명을 더 해 줄까?

- “감정받지 않은 그림은 버리면 된다.” 라벨 투표에는 쓸 수 없다. 하지만 허용된 훈련 자료에서는 496점의 좌표를 사용해 각 열이 얼마나 퍼져 있는지 잴 수 있다. 어떤 부류인지와 무관하게 얻을 수 있는 양을 학생이 하나 말하게 한다.
- “496점이 보이니 진위도 알 수 있다.” $0,1$의 복제품과 $9,10$의 진품에 맞는 경계를 2와 6 두 가지로 그린다. 둘 다 관측과 맞으면서 미상 4의 답이 갈린다. 새로운 감정 결과 또는 데이터가 생긴 방식에 대한 가정이 필요하다.
- “반복문이 1을 돌려줬으니 진품이다.” 그 1은 이 함수가 반환한 **행 위치**다. 예시의 위치 1에는 A가 있고 A의 감정값은 $-1$이다. 표지판 과제에서는 그 위치에 있는 사진의 번호를 꺼내므로 마지막 한 줄이 달라진다.
- “배열 합 아무 축이나 같은 것 같다.” U·A·B 차이제곱의 행별 합은 `[0,10,17]`, 열별 합은 `[10,17]`이다. 두 수치가 우연히 겹친다. U를 `(6,8)`으로 옮기면 행별 합은 `[25,10,17]`, 열별 합은 `[19,33]`이다. 학생에게 **결과의 숫자 하나가 그림 한 점에 대응하는가, 측정 항목 하나에 대응하는가**를 말하게 한다.
- “폭이 작은 열은 쓸모없다.” 작은 크기와 작은 예측력은 서로 다른 성질이다. 본문에서 A·B 두 점으로 구한 표준편차는 `[2,2.5]`, Q에서 표준화한 거리제곱은 `[2.41,2.81]`이다. 표준화는 양의 배율로 단위를 바꿔도 결과가 같은 장점이 있고, 좁게 분포하는 잡음을 키울 위험도 있다.

**두 CSV 복원.** `painting`과 `work_id`가 같은 그림을 가리킨다. 두 열로 왼쪽 결합하면 K7은 실제 첫째 측정값 0에 라벨 −1, M2는 둘째 측정값이 비었고 감정값 0, P8은 라벨 +1, D1은 감정표에 기록이 없다. M2의 측정값을 0으로 메우거나 D1에 복제품이라는 정답을 주면 안 된다. 읽고 결합한 행이 4개인지, 순서를 뒤집어도 `painting`별 연결이 같은지 확인한다. 학습 가능 여부를 판단할 때 ‘기록 없음’과 ‘감정값 미상’의 원래 출처도 보존한다. 자습의 문제 재서술 시간 45분 중 20분을 이 과제에 쓴다.

**배열 복원.** 첫 번째 파일은 `.reshape(2, 2)`, 두 번째 파일은 `.reshape(2, 2).T`로 같은 `[[0,5],[4,0]]`을 복원한다. 두 번째를 전치하지 않으면 `[[0,4],[5,0]]`이 되어 제곱거리는 9와 20이다. 원래의 10과 17과 비교한다. `d @ d`는 같은 원소끼리 곱해 더한 스칼라다. 이 검산은 배열 자습 90분 안에서 기존 거리 검산과 함께 진행한다.

**짧은 과제 검산.** 세 그림 중 진품 수는 1이다. 원문에는 그림마다 순서대로 세 값이 필요하다. 동점 실습의 첫 두 후보는 거리제곱이 모두 2이고 미상 그림의 거리는 0이다. 원래 순서에서는 행 위치 0의 $+1$, 행을 서로 바꾸면 같은 위치 0의 $-1$을 고른다. 상수열 실습에서는 원래 거리제곱이 10, 2라서 $+1$이다. 첫째 열을 100배로 표시하면 90001, 10001이 된다. 표준화 거리제곱은 이 단위 변경 전에나 뒤에나 각각 4.375, 1.375다.

## 교사용 풀이 예 · 두 부류의 대표점

학생이 자기 규칙을 제출한 다음 비교할 한 가지 풀이이다. “같은 부류의 그림이 모인다”는 가정에서 먼저 한 부류의 중심을 정한다. 훈련 자료 전체로 측정값의 폭을 맞춘 뒤, **감정된 그림만** 사용해 진품 중심 $c_+$와 복제품 중심 $c_-$를 각각 구한다. 새 그림의 표준화 좌표 $z$가 $c_+$에 가깝거나 두 거리가 같으면 $+1$, 그렇지 않으면 $-1$로 예측한다. 표준화에 사용할 평균과 폭은 각 가림에서 새로 계산한다.

예를 들어 한 축에 복제품이 0, 1에 있고 진품은 $-6,6$에 있다고 하자. 새 점 0에서 최근접 그림은 명백히 복제품인데 진품의 평균은 정확히 0이고 복제품의 평균은 0.5다. 대표점 규칙은 진품을 택한다. 이 사례를 먼저 예측하면 **부류 안에 떨어진 두 무리가 있을 때 평균은 어느 무리에도 속하지 않을 수 있다**는 반증 가능성이 생긴다. 어느 쪽이 맞는지는 새 점을 실제로 감정해야 알 수 있다.

```python
# exercise: classifier
def teacher_rule(train, queries):
    x = train[FEATURES].to_numpy(dtype=float)
    y = train[LABEL].to_numpy()
    center, width = fit_scale(x)
    z = (x - center) / width
    tests = (queries[FEATURES].to_numpy(dtype=float) - center) / width
    classes = np.unique(y[np.isin(y, [-1, 1])])
    if len(classes) == 0:
        raise ValueError("대표점을 만들 감정 그림이 없습니다.")
    if len(classes) == 1:
        return np.full(len(tests), classes[0], dtype=int)
    negative = z[y == -1].mean(axis=0)
    positive = z[y == 1].mean(axis=0)
    d_negative = ((tests - negative) ** 2).sum(axis=1)
    d_positive = ((tests - positive) ** 2).sum(axis=1)
    return np.where(d_positive <= d_negative, 1, -1)
```

**실제 공개 훈련 파일에서의 결과.** 각 회차는 표시한 그림을 통째로 빼고 499점으로 맞춘다. 이웃을 고르는 풀이에서 라벨을 줄 수 있는 점은 세 점뿐이다. 미상 496점은 표준화의 평균과 폭에 참여한다. 표의 행 번호는 헤더를 뺀 파일 순서로 1부터 센다. 학생이 다른 규칙을 썼을 때 마지막 열은 그 규칙으로 다시 계산한다.

| 가린 그림 | 공개 감정값 | 다수결 | 원래 단위의 최근접 | 표준화 최근접 | 표준화한 부류 중심 |
|---:|---:|---:|---:|---:|---:|
| 47 | −1 | +1 | −1 | −1 | −1 |
| 142 | +1 | −1 | −1 | −1 | −1 |
| 183 | +1 | −1 | −1 | +1 | +1 |
| 380 | −1 | +1 | −1 | −1 | −1 |
| 맞힌 수 | | 0/4 | 2/4 | 3/4 | 3/4 |

**183번에서 무슨 일이 있었는가?** 원래 단위에서는 47번 복제품이 가장 가까웠다. 훈련 자료로 폭을 맞추면 142번 진품이 가장 가까워진다. 반대로 142번을 가렸을 때 두 거리 풀이와 중심 풀이가 모두 오판했다. 뒤의 두 풀이가 3/4로 같다는 사실로 어느 쪽이 실전에서 나을지는 알 수 없다. 한 사례라도 새로 감정한다면 두 규칙이 다른 예측을 내는 그림이 차이를 밝히는 데 더 유용하다. 예를 들어 중심 부근이지만 가장 가까운 감정 그림은 반대 부류인 그림을 찾아 이유를 받는다.

다수결의 0/4는 공개 감정 결과가 정확히 2 대 2인 상태에서 하나씩 감춘 구성의 결과다. 전체 라벨 개수를 미리 아는 사람은 가린 그림의 답을 역산할 수도 있다. 채점할 때 훈련·질의로만 정의한 규칙인지 보고, 개수나 ID가 바뀐 새 입력에서도 그 설명대로 움직이는지 확인한다. 학습자는 네 정답을 이미 확인하고 다른 식을 설계했다면 최초 검증과 사후 탐색을 나누어 기록한다.

## 교사용 풀이 예 · 새 명세에서 결정이 달라지는 곳

같은 화장실이라는 정답은 평가 시 알 수 없다. 학생용 축소 과제는 표시와 특징을 주고, 재현 가능한 검색 규칙만 명세했다. 번호 8은 가장 가까워도 표시가 같아 탈락한다. 번호 40과 12는 거리제곱 4로 동점이고 번호 56은 9다. 이 연습의 동점 규칙을 따르면 답은 12다. 입력 순서를 바꿔도 12, 반대 표시가 없으면 `None`이다. 후보 **번호**를 반환하며 분류 문제의 $\pm1$을 반환하지 않는다. 이 검색이 현실의 짝도 잘 맞힌다는 말에는 대응 정답이 붙은 별도 자료가 필요하다.

```python
# exercise: matching
def match_icon(query_icon, gallery):
    _, query_group, q = query_icon
    winner = None
    for gallery_id, group, point in gallery:
        if group == query_group:
            continue
        distance = sum((a - b) ** 2 for a, b in zip(point, q, strict=True))
        key = (distance, gallery_id)
        if winner is None or key < winner:
            winner = key
    return None if winner is None else winner[1]
```

**선택 탐구 검산.** 이웃 다섯 점을 고르는 좌표는 한꺼번에 읽고 갱신한다. 0은 $-1/12$, 2는 $19/12$, 새 점 $0.9$는 $7/5$로 이동하므로 처음 $-1$이던 답이 $+1$로 바뀐다. 중간을 평균 내는 계산은 더 조밀한 곳으로 좌표를 당긴다. 진짜 경계가 그 사이를 지나면 옳았던 답도 뒤집을 수 있다. 실제 미상 그림에 새 라벨을 붙여 이 기법의 우위를 단정하지 않는다.

## 어느 선까지 학생이 해냈는가

학생에게 처음 적은 식과 손계산, 같은 네 그림에서 기준 풀이와 자기 풀이의 행별 예측, 의견이 갈리거나 함께 틀린 그림, 규칙을 유지·수정할 조건을 받는다. 숫자만 제출한 학생에게는 “그림 하나를 골라 **왜 그 부호가 나왔는지** 옆 친구가 따라 할 수 있게 적어 달라”고 요청한다. 잘 설명한 학생에게는 부류가 둘로 나뉜 사례나 표시 단위를 바꾼 사례를 주고 기존 설명이 유지되는지 확인한다. 표를 읽고 함수를 실행한 사실만으로 독립 수행이나 학생 성취를 판정할 수 없다.

**기존 10주 계획과의 범위 차이.** 이번 판별 단원에서 새 이름의 두 CSV 결합, 원시 측정값의 0과 미기록 구분, 배열 전치·내적을 같은 문제에 연결했다. 10주 계획에 적힌 Python 5문항과 배열 4문항 각각의 독립 진단은 이 단원의 판별식 평가로 대체할 수 없다. 기존 진단과의 동등성은 미확인이다.

2주차에는 어떤 상황을 예측해야 하는지에 맞춰 분할·전처리·평가를 결정한다. 이후 모델 학습과 검증에서는 손으로 고른 경계와 자료로 학습한 경계를 비교한다. 여기서는 이미지 임베딩 학습이나 SVM, 정답 없는 자료 전반에 대한 완전한 해법을 선수로 요구하지 않는다. R5의 일반 CSV 결합 연습이 필요한 학생은 기존 교안을 별도로 활용할 수 있다.
