수업 · 개념부터 읽기¶

1. 한 행은 화분 하나의 기록입니다 · 0~5분¶

같은 종류의 어린 식물을 서로 다른 화분에 심었다고 가정합니다. 빛을 받은 시간과 준 물의 양을 기록하고, 일주일 뒤 높이를 잽니다. 여기서는 기록 방법을 배우기 위해 만든 숫자를 사용합니다.

화분 번호 장소 하루 빛을 받은 시간(h) 하루 준 물(ml) 일주일 뒤 높이(cm)
P01 실내 2 0 8
P02 실내 3 20 10
P03 창가 5 기록 없음 12
P04 창가 6 40 14
P05 실내 4 20 10
P06 창가 7 60 18

한 행은 화분 하나의 관찰 기록이고, 한 열은 같은 종류의 정보입니다. 주어진 정보로 높이를 예측하는 문제라면 빛의 시간과 물의 양을 특성(feature), 알아맞힐 높이를 **정답(target)**이라고 부릅니다. 정답이라는 말은 이 표에 기록한 비교 대상이라는 뜻입니다. 측정이 완벽하다는 뜻까지 담고 있지는 않습니다.

P01의 물 0ml는 물을 주지 않았다고 기록한 값입니다. P03의 빈칸은 물의 양을 모른다는 뜻입니다. 빈칸을 0으로 바꾸면 서로 다른 상황을 같은 값으로 만들게 됩니다. 화분 번호는 기록을 찾는 식별자입니다.

이 표로는 모델을 학습하지 않습니다. 높이가 큰 화분에서 빛의 시간이 길게 나타나더라도, 이 예제만으로 빛이 높이의 차이를 만들었다고 판단할 수는 없습니다.

2. 평균은 합계를 같은 몫으로 나눈 값입니다 · 5~12분¶

길이가 2cm, 4cm, 6cm인 세 막대를 생각해 봅니다. 길이의 합은 12cm이고 막대는 세 개이므로, 똑같이 나눈 길이는 4cm입니다.

$$ \bar{x}=\frac{x_1+x_2+\cdots+x_n}{n} =\frac{1}{n}\sum_{i=1}^{n}x_i. $$

기호 이 수업에서의 뜻
$n$ 값의 개수. 1 이상의 정수
$i$ 몇 번째 값인지 나타내는 번호. 1부터 $n$까지
$x_i$ $i$번째 값. 여기서는 cm로 잰 길이
$\sum_{i=1}^{n}x_i$ 첫 값부터 마지막 값까지 더한다는 표기
$\bar{x}$ 평균. 읽을 때는 ‘엑스 바’라고 부르며 단위는 cm

이 식은 유한한 숫자가 하나 이상 있고 모두 같은 종류·단위의 양일 때 사용합니다. 빈칸이 있는 표는 어떤 값을 계산에 포함했는지 먼저 정해야 합니다. 물의 양(ml)과 길이(cm)를 더한 평균은 여기서 해석하지 않습니다.

계산을 식으로 따라가면 $\bar{x}=(2+4+6)/3=12/3=4\text{ cm}$입니다. 평균은 실제 관측값 중 하나일 필요가 없습니다. 예를 들어 2와 3의 평균 2.5는 두 관측값 사이에 있습니다.

같은 평균이어도 퍼진 정도는 다릅니다¶

길이가 [2, 4, 6]인 묶음과 [4, 4, 4]인 묶음의 평균은 모두 4cm입니다. 평균 하나로는 두 묶음을 구별하기 어렵습니다.

각 값에서 평균을 빼면 편차입니다. 첫 묶음의 편차는 $[-2,0,2]$cm입니다. 그대로 더하면 $-2+0+2=0$이 되어 퍼진 정도가 사라집니다. 여기서는 편차를 제곱해 음수와 양수가 서로 지워지지 않게 합니다. 값의 개수가 다른 묶음도 비교할 수 있도록 제곱합을 개수로 나눕니다.

$$ v=\frac{1}{n}\sum_{i=1}^{n}(x_i-\bar{x})^2. $$

$v$는 분산이며, 나머지 기호는 바로 위 평균 식과 같습니다. 이 수업에서는 지금 가진 값 전체의 퍼짐을 기술하므로 분모를 $n$으로 정합니다. 표본으로 더 큰 집단의 분산을 추정할 때 쓰는 $n-1$ 공식은 이번 계산에 쓰지 않습니다.

단계 2cm 4cm 6cm
평균 4cm를 빼기 -2cm 0cm 2cm
편차를 제곱하기 4cm² 0cm² 4cm²

제곱합은 $4+0+4=8\text{ cm}^2$, 분산은 $8/3\approx2.67\text{ cm}^2$입니다. [4, 4, 4]에서는 편차가 모두 0이므로 분산도 0입니다. 제곱했기 때문에 분산의 단위는 원래 단위의 제곱입니다.

평균 계산을 순서로 적으면 알고리즘이 됩니다¶

알고리즘은 입력을 받아 결과를 만드는 절차입니다. 다음 표기는 Python 문법에 매이지 않고 계산 순서를 적은 의사코드입니다. 입력은 빈칸이 없는, 같은 단위의 숫자 목록입니다. 빈 목록의 평균은 정하지 않고 오류로 알립니다.

평균_구하기(숫자_목록):
    개수 ← 목록에 든 값의 수
    개수가 0이면 오류를 알리고 끝낸다
    합계 ← 0
    목록의 각 값을 하나씩 읽는다:
        합계 ← 지금 합계 + 읽은 값
    합계 / 개수를 결과로 돌려준다

화살표 $\leftarrow$는 오른쪽 값을 왼쪽 이름에 저장한다는 뜻입니다. 수학의 등호처럼 두 값이 항상 같다고 선언하는 표기와 구분합니다. Python의 대입에는 =를 쓰고, 계산한 결과를 호출한 곳에 돌려줄 때는 return을 씁니다.

[2, 4, 6]에서의 시점 읽은 값 누적 합계
시작 아직 없음 0
한 번 읽음 2 2
두 번 읽음 4 6
세 번 읽음 6 12
결과 반환 개수 3으로 나눔 4

분산은 평균을 먼저 구한 다음, 각 편차의 제곱을 같은 방법으로 누적해 개수로 나눕니다. 코드를 실행하기 전에 이 순서를 손으로 따라갈 수 있으면, 잘못된 결과가 나왔을 때 어느 단계부터 살필지도 정할 수 있습니다.

3. shape는 값이 놓인 자리의 수입니다 · 12~20분¶

같은 단위(cm)로 잰 길이 여섯 개를 3행 2열로 놓겠습니다.

$$ A= \begin{bmatrix} 2&4\\ 6&8\\ 10&12 \end{bmatrix}, \qquad \mathrm{shape}(A)=(3,2). $$

shape는 차례대로 각 축의 길이를 적은 것입니다. 이 2차원 배열의 첫 축 axis=0 길이는 행 수 3, 둘째 축 axis=1 길이는 열 수 2입니다. 수학에서는 $a_{ij}$로 $i$행 $j$열 값을 나타내며 여기서 $i=1,2,3$, $j=1,2$입니다. Python은 0부터 세므로 수학의 $a_{12}=4$는 코드의 A[0, 1]에 대응합니다.

평균을 구할 때 axis는 어느 축을 줄일지 지정합니다. 이 수업의 배열은 직사각형이며, 모든 값은 유한한 숫자입니다. keepdims=False로 줄인 축은 결과에서 사라집니다.

  • axis=0: 행 축의 세 값을 모아 평균을 냅니다. 열마다 하나씩 남으므로 결과는 [6, 8], shape는 (2,)입니다.
  • axis=1: 열 축의 두 값을 모아 평균을 냅니다. 행마다 하나씩 남으므로 결과는 [3, 7, 11], shape는 (3,)입니다.

(2,)의 쉼표는 한 축만 있는 shape 표기입니다. 2행 1열인 (2, 1)과는 모양이 다릅니다.

그림의 화살표 방향만 외우지 말고, 평균 하나를 만들 때 어떤 값을 묶었는지 확인합니다.

일반적인 $m$행 $p$열 배열에서도 같은 순서로 계산합니다. $m,p$는 모두 1 이상의 정수이고, 모든 원소의 단위는 같습니다.

$$ c_j=\frac{1}{m}\sum_{i=1}^{m}a_{ij}\quad(j=1,\ldots,p), \qquad r_i=\frac{1}{p}\sum_{j=1}^{p}a_{ij}\quad(i=1,\ldots,m). $$

$c_j$는 $j$번째 열의 평균, $r_i$는 $i$번째 행의 평균입니다. 첫 식은 행 번호 $i$를 움직이므로 행 축을 줄입니다. 둘째 식은 열 번호 $j$를 움직이므로 열 축을 줄입니다. 결과로 남은 번호가 각각 $j$, $i$라는 점을 코드의 결과 길이와 연결해 봅니다.

def mean_of_numbers(numbers):
    count = len(numbers)
    if count == 0:
        raise ValueError("평균을 구할 값이 하나 이상 필요합니다.")
    total = 0
    for value in numbers:
        total = total + value
    return total / count

print("[2, 4, 6]의 평균:", mean_of_numbers([2, 4, 6]))

10. 열 이름이 바뀌었을 때 · 90~100분¶

FileNotFoundError는 파일 위치부터 살핍니다. KeyError는 읽은 표에 요청한 열이 있는지 확인합니다. 두 오류는 실패한 단계가 다릅니다.

아래 함수는 필요한 열이 빠졌으면 어떤 열이 없는지 알립니다. column not in table.columns는 그 열 이름이 표에 없는지 검사합니다. 모르는 열을 조용히 빈 값으로 만들어 계속하지 않습니다.

def require_columns(table, required_columns):
    missing_columns = []
    for column in required_columns:
        if column not in table.columns:
            missing_columns.append(column)
    if missing_columns:
        raise KeyError(f"없는 열: {missing_columns}")
    return table[required_columns]

print("현재 높이 열:", require_columns(plants, ["height_cm"]).shape)
try:
    require_columns(plants, ["height"])
except KeyError as error:
    print("예상한 오류를 확인했습니다:", error)

11. 손계산을 NumPy와 대조하기 · 100~108분¶

위에서 계산한 배열을 그대로 만듭니다. mean(axis=...)의 결과는 두 벡터이고, mean()의 결과는 전체 여섯 값의 평균인 숫자 하나입니다. 출력 길이가 예상과 다르면 먼저 줄일 축을 다시 확인합니다.

A = np.array([[2, 4], [6, 8], [10, 12]], dtype=float)
column_means = A.mean(axis=0, keepdims=False)
row_means = A.mean(axis=1, keepdims=False)
print("입력 shape:", A.shape)
print("열별 평균(cm):", column_means, "/ shape:", column_means.shape)
print("행별 평균(cm):", row_means, "/ shape:", row_means.shape)
print("전체 평균(cm):", A.mean())

분산은 NumPy와 pandas 모두 분모를 $n$으로 맞추어 비교합니다. NumPy var의 기본 ddof는 0이고 pandas var의 기본은 1입니다. 여기서는 두 쪽 모두 ddof=0을 명시합니다. 분모는 n - ddof입니다.

표의 물 열에는 결측이 있으므로 방금 만든 결측 없는 배열과 섞어 계산하지 않습니다.

print("pandas 분산(ddof=0):", pd.Series(lengths).var(ddof=0))

과제 A · 배열을 다른 모양으로 놓기¶

reshape는 원소 수를 유지하며 모양을 바꿉니다. 여섯 원소를 2행 3열로 바꿀 수 있지만 4행 2열에는 여덟 원소가 필요하므로 맞지 않습니다. transpose는 축의 순서를 바꿉니다. 2차원에서 .T를 쓰면 행과 열의 역할이 바뀝니다.

try:
    six_values.reshape(4, 2)
except ValueError as error:
    print("원소 수가 맞지 않으면:", type(error).__name__)

과제 D · 벡터와 내적, 다시 실행하기¶

벡터를 값의 순서가 정해진 목록으로 생각해 봅니다. 두 종류의 화분을 2개, 3개 샀고 한 개 가격이 각각 1000원, 500원이라면 총액은 $2\times1000+3\times500=3500$원입니다.

$$ u\cdot w=\sum_{k=1}^{d}u_k w_k. $$

$u$는 수량 벡터, $w$는 단가 벡터, $d$는 종류 수이며 여기서는 2입니다. $k$는 같은 종류끼리 짝지을 번호입니다. 수량의 단위는 개, 단가는 원/개이므로 곱의 단위는 원이고, 이를 더한 내적도 원입니다. 두 벡터의 길이가 같고 순서가 같은 종류를 가리킨다고 가정합니다.

1차원 NumPy 배열에서 u * w는 짝별 곱을 남기고, u @ w는 그 곱을 모두 더한 숫자 하나를 냅니다. 단가 순서를 뒤집으면 다른 계산이 되므로 이름과 순서를 같이 확인합니다. 일반적인 벡터의 내적은 방향·길이와도 연결되지만 이번 과제에서는 짝별 곱의 합을 먼저 익힙니다.

quantities = np.array([2, 3])
unit_prices = np.array([1000, 500])
print("종류별 금액(원):", quantities * unit_prices)
print("내적, 총액(원):", quantities @ unit_prices)

종류별 금액(원): [2000 1500]
내적, 총액(원): 3500

수량 [1, 4, 2], 단가 [800, 500, 1200]으로 바꿔 손계산과 코드를 대조합니다. 마지막에는 커널을 재시작하고 노트북 전체를 위에서 아래로 실행합니다. 순서대로 실행했을 때만 필요한 변수를 얻도록 코드를 정리합니다.

제출할 때는 작성한 답안, 자료사전, 두 라이브러리 그림, 바꾼 입력, 실제 시간, 도움을 받은 부분을 함께 남깁니다. 예제와 같은 결과만 저장했다면 새 입력 과제를 아직 수행하지 않은 것입니다.

이 교안은 승인된 10주 계획 중 1주차 기본 교안입니다. 이론 20분, 비코딩 20분(필기 10분 포함), 코딩 80분과 필수 자습 5~7시간을 유지했습니다. 공식 목록의 Python(01), NumPy·pandas(02), Matplotlib·Seaborn(03), 텐서 조작(06)의 배열 선수학습을 연결합니다. 공식 목록에서 이 항목들의 별도 이론 요구 표시는 X이지만, 실제 사용에 필요한 개념과 계산 설명은 포함했습니다. PyTorch의 dtype·device와 GPU 실습은 이 자료에서 완료했다고 주장하지 않으며 6주차 연결로 남깁니다.

KOAI 2027 공지가 연결한 공식 실라버스는 확인 시점에 ‘IOAI 2026 기준’으로 표시돼 있습니다. 공지의 대회 연도와 실라버스의 표기 연도를 구분합니다. 이 교안이나 실행 기록은 공식 시험 문제나 합격 기준이 아닙니다.

자료의 기준은 다음과 같습니다. 저장소는 작성 시작 시 최신 main인 434fe5ad5d23에 고정했습니다.

  • 승인 학생용 10주 계획
  • 시간·범위 계약
  • 1·2주차 학습 단위 명세
  • NumPy 평균의 axis·keepdims, 분산의 ddof
