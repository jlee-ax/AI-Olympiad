Public source, arithmetic means and axes

The full published package has X.shape=(1797,64), images.shape=(1797,8,8), and y.shape=(1797,). UCI describes counting foreground pixels in nonoverlapping 4×4 blocks of a 32×32 binary image. Each feature is the count 0–16 in its block. A zero target denotes digit zero and a zero feature is a recorded count. For image position 0, block (2,3) equals feature 19 named pixel_2_3, both 2. Its target is 0. The target is unavailable as a feature when classifying an unlabeled image. The named arrays describe this supervised classification representation, not a universal layout for other contest tasks.

With numerical practice values [2,4,6] cm the arithmetic mean is 4 cm. Deviations [−2,0,2] cm sum to zero because n times the mean is the total. Squared deviations [4,0,4] cm² give variance 8/3 cm² with divisor n and standard deviation sqrt(8/3) ≈ 1.63 cm. The equal-valued group [4,4,4] cm has variance and standard deviation zero. The figure's vertical positions denote record order. Duplicating all data doubles both the squared sum and n. Translating by 10 cm preserves both measures. In this lesson n summarises the values actually supplied. A statistical population is the collection about which an inference would be made; a statistical sample is the selected collection of observations. With independent observations from the same population and n>1, division by n−1 is the usual unbiased estimator of the population variance when that variance is finite. An individual sample in the scikit-learn API is one input example, here one image.

The mean algorithm accumulates 0→2→6→12, retains total 12, and returns 4. On [1,3,8] the successive totals are 1,4,12 and the mean is 4. Its empty case raises ValueError. The shifted version with offset 2 has totals 3,8,18, returns 6 and allows shifted_average*3 = 18. A print-only version returns None, which cannot support this multiplication. Values and offset are finite Python integers or floats in [−1,000,000, 1,000,000], with at most 10,000 values. Validation of other types and overflows such as [1e308,1e308] is outside this exercise. A singleton [7] with offset 2 returns 9. One teacher solution follows.

  def shifted_mean(numbers, offset):
      count = len(numbers)
      if count == 0:
          raise ValueError("평균을 구할 값이 하나 이상 필요합니다.")
      total = 0
      for value in numbers:
          total = total + value + offset
      return total / count

Function contract, feature inner products and rerun (D, E)

For D, values are None or nonnegative finite Python int/float up to 1,000,000, with at most 10,000 list items. A recorded zero counts; an empty list or a list of only None returns (0,None). Check that the original list is preserved and compare nonintegral means with a tolerance. The earlier plain mean function raises on empty input under its own contract. One answer is:

  def recorded_mean(values):
      count = 0
      total = 0
      for value in values:
          if value is not None:
              count += 1
              total += value
      if count == 0:
          return (0, None)
      return (count, total / count)

Teacher variants include [2,None,8,10] → (3,20/3), [None,None,0] → (1,0.0), [None] → (0,None), and unchanged [3,None,9] → (2,6.0). A truth-value test loses zero. A print-only function cannot return the count and mean for later use.
