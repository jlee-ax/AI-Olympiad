1주차 교사용 해설과 수업 안내
============================

학생용 노트북에는 설명·문제·일반 사용법만 둡니다. 이 파일은 답안과 수업 운영을
위한 자료입니다. 새 입력 과제에서는 이 해설과 완성 예제를 가린 뒤 먼저 답하게
하고, 도움을 받았다면 무엇을 참고했는지 적게 합니다. 실제 학생 답안·이해도와
교실 소요 시간은 아직 관찰하지 않았습니다.

수업 편성
- 승인된 편성은 이론 20분, 손풀이 10분, 필기 10분, Python 진단 20분,
  CSV 40분, NumPy·Matplotlib 20분으로 총 120분입니다.
- 마지막 학습 확인과 새 그래프 문항은 기존 NumPy·Matplotlib 20분 블록 안에서
  다룹니다. 진단의 traceback은 기존 Python 진단 20분 안에 포함합니다. 실제
  가능 시간은 미관찰이며, 시간이 부족하면 지원·후속 확인을 수업 밖으로
  조정하고 어떤 문항을 다루지 못했는지 남깁니다.
- 추가한 유도·그림·상태 추적은 같은 개념을 다시 읽을 때도 쓸 수 있는 설명입니다.
  전부 강의에서 낭독하거나 수업 밖 과제를 수업 안에 덧붙이는 편성이 아닙니다.
- 수업 밖 필수 연습은 A~E입니다. A의 배열 과제는 기존 모양 바꾸기 연습을
  반례 비교로 바꾸었고, D에는 결측값 함수 명세 과제를 추가했습니다. E는 기존
  내적·재실행 과제입니다. 기존 계획의 5~7시간은 이전 범위의 추정치이며 이번
  변경 후의 필요 시간이나 실제 부담을 확인한 값이 아닙니다. 설치·기초 보충도
  별도이므로, 학생 수행을 확인해 분량과 지원 방식을 조정해야 합니다.
- 표의 예측식은 도입에서 한 행을 연결하는 짧은 설명으로 다루고, P01·P03의
  새 입력 확인은 수업 밖 필수 연습의 시작에 둡니다. 장소별 그래프 해석은
  기존 NumPy·Matplotlib 블록에, broadcasting 축 정렬은 기존 과제 A에 둡니다.
  추가 내용의 실제 수업·자습 소요 시간은 미관찰이며 분량을 재조정할 수 있습니다.
- 시간은 계획 추정치이며 숙달이나 수행 가능성을 입증하지 않습니다. 숫자형
  진단 통과 기준이나 개인별 자습 허용 상한은 이 자료에서 새로 정하지 않습니다.
- 도입은 한 행·단위 → 같은 몫 평균 → 편차와 분산 → 같은 입력의 axis로 연결합니다.
  긴 일반식이 어려우면 먼저 A의 한 열에 동그라미를 치고 합계와 개수로 돌아갑니다.

개념 해설과 오개념별 보충
- 예측 예시는 일주일이 끝난 뒤 높이를 재기 전, 매일 같은 빛·물 기록을
  확인할 수 있다는 가정입니다. 식의 4, 1, 0.1은 임의 수치이며 학습한 계수나
  인과 효과가 아닙니다. P02는 4+3+2=9cm, 실제10cm, 실제−예측=+1cm.
  수업 밖 P01은 4+2+0=6cm, 실제8cm, 실제−예측=+2cm입니다. P03의 물은
  기록이 없어 식에 임의의 0을 넣을 수 없습니다. 심는 날에 미래 실제 기록은
  모를 수 있고, 계획값을 쓴다면 실제 기록과 구분해야 합니다.
- 산점도는 실내 원 P01/P02/P05의 빛 2/3/4h와 창가 네모 P03/P04/P06의
  빛 5/6/7h를 구분합니다. P02와 P04는 장소·빛뿐 아니라 물도 20/40ml로
  다릅니다. 빛 시간은 장소 사이에 겹치지 않으므로 이 차이만으로 빛의
  인과 효과를 구할 수 없고, 장소 안에서도 빛은 달라집니다.
- broadcasting: (3,2)+(2,)는 왼쪽 1을 가상으로 보태 (3,2)+(1,2)로
  비교합니다. 오른쪽 2=2, 왼쪽 3 대 1이므로 결과는 (3,2)입니다.
  (3,2)+(3,1)은 오른쪽 2 대 1, 왼쪽 3=3이므로 같은 결과 shape입니다.
  (3,2)+(3,)은 (3,2)+(1,3)으로 비교해 오른쪽 2 대 3에서 오류입니다.
  빠진 축을 1로 생각하는 것은 비교 규칙이며 실제 복사나 reshape를 뜻하지 않습니다.
- 평균: 같은 몫 b에 대해 n*b=전체 합이므로 b=합/n입니다. [2,4,6]cm의 합은
  12cm, 평균은 4cm입니다. 합을 평균이라고 답하면 같은 길이 막대 세 개로
  나눈다는 조건을 다시 확인합니다. 빈 목록에는 나눌 개수가 없어 평균 미정입니다.
- 분산: 편차 합은 합(x)-n*평균=0입니다. [-2,0,2]cm의 제곱합은 8cm²,
  분산은 8/3cm²입니다. [4,4,4]의 분산은 0입니다. 같은 묶음을 두 번 적으면
  제곱합과 개수가 함께 두 배여서 분산은 같습니다. 모든 값이 10cm 커지면
  평균도 10cm 커져 편차·분산은 그대로입니다. n=1이면 이번 정의의 분산은 0입니다.
- 새 분산 그림: 점 하나는 길이 기록 하나이고 세로는 기록 순서입니다. 가로
  점선은 아니며, 세로 점선의 가로 위치가 평균 4cm입니다. 주황 화살표는
  평균에서 값으로 향하므로 편차의 부호와 크기에 대응합니다. 6cm 점의
  편차는 +2cm, 제곱은 4cm²입니다. 제곱 숫자 열은 길이 좌표가 아닙니다.
- axis: A[1,0]=6=a_21. 첫 열 합계는 0→2→8→18, 둘째 열은 합계를 다시
  0으로 놓아 0→4→12→24입니다. 행을 줄이면 열별 평균 [6,8], shape(2,),
  분모3입니다. 열을 줄이면 행별 평균 [3,7,11], shape(3,), 분모2입니다.
  전체 평균은 7cm입니다. 틀리면 결과 하나를 만드는 원소만 묶어 분모와
  출력 개수를 따로 세게 합니다. h와 ml처럼 뜻·단위가 다른 열은 섞지 않습니다.
- 상태와 반환: 평균 함수의 total은 0→2→6→12입니다. return total/count는
  total을 다시 대입하지 않으므로 합계는 12이고, 호출한 곳에 4를 돌려줍니다.
  print-only 함수는 화면에 6을 써도 반환값이 None입니다. 화면과 변수 칸을
  따로 적은 뒤 반환값을 곱셈에 재사용하게 합니다.
- 결측: P01의 물0은 관측값, P03은 모르는 값입니다. 관측5개, 합140ml,
  평균28ml입니다. 실제 여섯 화분의 평균은 P03 값을 모르면 알 수 없습니다.
  dropna로 만든 계산용 Series는 원본 행을 지우지 않습니다. 전부 결측이면
  pandas 평균은 NaN이며, 이것은 평균0이라는 뜻이 아닙니다.

Python 진단과 실제 수정 과제
- 1: water15, label충분. 조건문은 예측 코드와 확인 코드에서 같은 if/else입니다.
- 2: 반복3회, 합계2→6→12. 한 값을 읽은 뒤 상태를 기록합니다.
- 3: twice(3)는6 반환, show_twice(3)는 화면6·반환None.
- 4: 첫값8, 슬라이스[10,12], 원본[8,10,12,14] 유지.
- 5: FileNotFoundError는 현재 작업폴더·상대경로·파일 존재를 확인합니다.
  KeyError는 이미 읽힌 표의 columns와 자료사전을 확인합니다. 실패 단계가 다릅니다.
- traceback 진단: 마지막 오류는 IndexError이고 실제 실패 줄은 함수 안의
  `values[len(values)]`입니다. 길이3의 유효 인덱스는 0,1,2이므로 3은 범위
  밖입니다. 비어 있지 않다는 계약에서 `return values[-1]` 또는
  `return values[len(values)-1]`로 수정하면 [2,4,6]→6, [9]→9입니다.
  실패 위치와 호출 위치를 구분하게 한 뒤 새 입력으로 확인합니다. 빈 목록에
  대한 동작은 이 문제의 계약에 포함하지 않습니다.
- [1,3,8] 누적합1→4→12, 평균4. []는 개수0이며 ValueError가 예상 동작입니다.
- shifted_mean([1,3,8],2)는 [3,5,10]의 평균6을 반환합니다. total은3→8→18,
  count3입니다. shifted_average*3은18입니다. 출력만 하면 None*3에서 TypeError입니다.
  원본 함수는 보존하고 다음과 같은 복사본을 작성할 수 있습니다.

  def shifted_mean(numbers, offset):
      count = len(numbers)
      if count == 0:
          raise ValueError("평균을 구할 값이 하나 이상 필요합니다.")
      total = 0
      for value in numbers:
          total = total + value + offset
      return total / count

- 한 값 [7], offset2는9; 빈 입력의 오류는 유지됩니다. 정상 목록은 길이
  1~10,000, 각 유한한 정수/float 값 −1,000,000~1,000,000입니다. offset도
  같은 범위의 Python 정수 또는 유한 float입니다. 범위·자료형은 별도 검사하지 않습니다.
  예를 들어 매우 큰 유한 float [1e308,1e308]은 합계가 inf가 될 수 있어
  계약 밖입니다. 일반적인 float 계산은 반올림 오차가 있을 수 있습니다.

수업 밖 필수 연습 해설
- 배열 반례: task_array=[[2,5,8],[11,14,17]]의 reshape 결과는
  [[2,5],[8,11],[14,17]], 전치 결과는 [[2,11],[5,14],[8,17]]입니다.
  둘 다 shape(3,2)이지만 [0,1] 값은 각각5와11입니다. 전치 결과의 첫 행은
  task_array의 첫 열입니다. shape가 같아도 위치 대응이 달라집니다. 복사·공유
  여부는 별도로 판단합니다. 새 변수 이름은 앞의 A, B를 덮어쓰지 않습니다.
- 함수 명세: 숫자 0~1,000,000, 리스트 길이 최대 10,000의 입력 조건을 둡니다.
  `None`과0을 구분하고 관측값의 개수와 평균을 반환합니다. 관측이
  없을 때 이 과제의 약속은 (0,None)입니다. 아래는 하나의 교사용 예시입니다.

  def recorded_mean(values):
      count = 0
      total = 0
      for value in values:
          if value is not None:
              count += 1
              total += value
      if count == 0:
          return (0, None)
      return (count, total / count)

  비노출 확인: [2,None,8,10]→(3,20/3), [None,None,0]→(1,0.0),
  [None]→(0,None). [3,None,9]는 호출 뒤에도 그대로이고 (2,6.0)을 반환합니다.
  실수 결과는 math.isclose(rel_tol=1e-9, abs_tol=1e-12)로 비교합니다.
  `if value:`는0을 놓치고, 출력만 하는 함수는 후속 계산에 쓸 값을 돌려주지 않습니다.
- reshape는 원소 수 보존, .T는 축 교환입니다. (3,2)와(2,) 열별 보정은
  [[3,14],[7,18],[11,22]], (3,1) 행별 보정은[[3,5],[16,18],[110,112]].
- 새 브로드캐스팅: T는 (2,3). 열 보정 [10,20,30]은 shape(3,) 또는
  [[10,20,30]]의 shape(1,3) 모두 가능하며 오른쪽 아래 8+30=38,
  결과(2,3)입니다. 같은 열 보정 행을 두 번 쓴 (2,3)도 덧셈은 되지만
  이미 전체 위치에 값을 써서 크기 1인 축의 확장은 사용하지 않습니다.
  행 보정 [[100],[200]]은 shape(2,1), 오른쪽 아래 8+200=208,
  결과(2,3)입니다. 같은 행 보정을 열마다 반복한 (2,3)도 계산은 됩니다.
  길이 2 배열의
  마지막 축 2는 T의 마지막 축 3과 다르고 둘 다 1이 아니므로 오류입니다.
  행/열을 거꾸로 골랐다면 마지막 축부터 표시한 뒤 다른 작은 입력으로
  보정할 위치를 다시 묻게 합니다.
- 새 독립 분산 [1,3,8]cm는 평균4cm, 편차[-3,-1,4]cm, 분산26/3cm².
  모두 2cm 더하면 평균6cm이고 편차·분산은 그대로입니다. 원래 값을 2배 하면
  평균8cm, 편차[-6,-2,8]cm, 분산104/3cm²입니다. 제곱 전 편차를 비교해
  ‘평균 증가’와 ‘퍼짐의 배율’을 분리합니다. 답을 확인한 뒤 새 [2,5,8]에서
  모두 1cm를 더할 때 편차가 바뀌는지도 다시 묻습니다.
- 병합 경계: Q02 장소를 옥상으로 바꾼 왼쪽 표는 4행, note가 비는 행은
  Q02입니다. 이 옥상 변경 화분 복사본을 유지하면서 정보 표 복사본에
  실내 키를 중복하면 many_to_one 검증은 MergeError로
  멈춥니다. 검증을 빼면 Q01이 두 행으로 늘어 총 5행이 됩니다. 중복을
  임의로 버리기 전에 정보 표가 한 장소에 한 설명을 둬야 하는지 확인합니다.
  오해가 있으면 2행짜리 왼쪽 표로 줄여 매칭 횟수를 다시 세고 새 키로
  재시도합니다. 이 사례에서는 원본 자료를 변경하지 않습니다.
- 새 분포 [0,4,8], [3,4,5]는 평균4cm, 분산은 각각32/3,2/3cm²입니다.
- [0,4,8]에3을 더한 [3,7,11]의 평균은7cm, 편차[-4,0,4]cm와 분산
  32/3cm²는 그대로입니다. 원래 값을2배 한 [0,8,16]의 평균은8cm이고
  편차[-8,0,8]cm의 분산은128/3cm²로 네 배입니다. 단위만 cm에서 mm로
  바꾸면 분산의 수치는100배이지만 같은 물리적 자료입니다. 표준편차가0이면
  그 값으로 나누는 표준화를 그대로 적용할 수 없고, 통계량을 어느 자료에서
  구하는지와 누수는 후속 주차에서 다룹니다.
- 새 CSV 장소별 평균 높이는 실내8cm·창가13cm, 높이 관측수 각각2입니다.
  별도 복사본에서 Q02 높이만 결측이면 실내 전체 행은2, 높이 관측수1,
  관측 평균7cm입니다. count는 결측이 아닌 값, size는 전체 행을 셉니다.
  관측값이 0개라면 평균은 0이 아닌 결측이며 원본은 변경하지 않습니다.
  site_notes 왼쪽 병합은4행을 유지하며 note 결측은0입니다. 장소 정보 표의
  중복 키는 many_to_one에서 오류, 모르는 장소는 왼쪽 행을 보존하고 note 결측입니다.
- 내적: [2,3]과[1000,500]의 곱은[2000,1500]원, 합3500원.
  새 [1,4,2]와[800,500,1200]의 내적은5200원. 공급자의 B,C,A 순서
  [500,1200,800]을 그대로 곱하면6900원으로, 길이는 같아도 종류가 잘못
  짝지어집니다. 이름으로 A,B,C 순서를 맞춰 5200원을 구합니다. 혼동하면
  수량 A=2,B=1과 단가 B=4,A=6을 한 행씩 맞춰 16원인지 다시 확인합니다.

독립 사본 보완: 예제 파일과 그래프
- 주 예제와 새 예제는 파일이 없으면 각각 노트북 내장 CSV를 읽습니다. 같은 경로에
  외부 파일이 있으면 열·행 순서, 값과 결측 위치를 비교합니다. `2`와 `2.0`, CRLF와
  LF, CSV 따옴표처럼 pandas로 읽은 값이 같은 표기는 허용하되 다른 값이나 누락 열은
  바로 오류로 알립니다. 파일을 덮어쓰거나 복구하지 않습니다. 의도한 새 자료는
  별도 변수에 읽어 자료사전과 계산을 다시 확인합니다.
- 장소별 높이 그림의 입력은 적어도 한 행, 빈칸이 아닌 문자열 장소, 0 이상
  1,000,000 이하 유한 숫자 또는 None/NaN 높이입니다. 숫자는 Python int/float와
  NumPy 정수·float16/32/64로 제한합니다. 범위 끝 0과 1,000,000도
  허용하며 음수·무한대·초과값·문자·참거짓은 알립니다. 원표는 변경하지 않습니다.
  size는 전체 행, count는 기록된 높이의 수입니다. 모든 높이가 미상인 장소는
  평균이 없고 0cm 막대가 아니라 ‘관측 없음’으로 보입니다. 실제 평균의 최대값에
  맞춰 세로축을 잡으며, P06을 60으로 바꾸면 창가 평균은 86/3cm입니다.

독립 사본 보완: 여러 행의 고정식과 새 입력 해설
- 임의 고정식의 계수는 빛 1cm/h·물 0.1cm/ml이며 상수는 4cm입니다. 첫 예제
  X=(3,2), w=(2,), X@w+4=(3,)이고 P01/P02/P04 순서의 값은 [6,9,14]cm입니다.
  P02는 4+3*1+20*0.1=9cm입니다. X*w는 (3,2)의 항별 곱이고 행마다 합친 뒤
  상수를 한 번 더한 것이 예측입니다. 계수는 학습하지 않았습니다.
- 새 입력 [[4,30],[5,0]]의 예측은 [11,9]cm, X=(2,2), w=(2,), 예측=(2,),
  원소별 곱=(2,2)입니다. 열 순서만 물·빛으로 바꾸면 계수의 단위가 맞지 않습니다.
  같은 수치식을 유지하려면 계수도 [0.1,1]로 같은 순서로 바꿉니다. 물이 미상인
  세 번째 행의 예측을 0으로 대체해 확정하지 않습니다. 직접 작성한 코드·이유와
  참고한 도움을 확인하며, 실제 독립 수행이나 소요 시간은 관찰하지 않았습니다.
