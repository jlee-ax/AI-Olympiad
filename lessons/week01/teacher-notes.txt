1주차 교사용 해설과 수업 안내
============================

학생용 노트북에는 설명·문제·일반 사용법만 둡니다. 이 파일은 답안과 수업 운영을
위한 자료입니다. 새 입력 과제에서는 이 해설과 완성 예제를 가린 뒤 먼저 답하게
하고, 도움을 받았다면 무엇을 참고했는지 적게 합니다. 실제 학생 답안·이해도와
교실 소요 시간은 아직 관찰하지 않았습니다.

수업 편성
- 승인된 편성은 이론 20분, 손풀이 10분, 필기 10분, Python 진단 20분,
  CSV 40분, NumPy·Matplotlib 20분으로 총 120분입니다.
- 추가한 유도·그림·상태 추적은 같은 개념을 다시 읽을 때도 쓸 수 있는 설명입니다.
  전부 강의에서 낭독하거나 수업 밖 과제를 수업 안에 덧붙이는 편성이 아닙니다.
- 수업 밖 필수 연습은 A~E입니다. A의 배열 과제는 기존 모양 바꾸기 연습을
  반례 비교로 바꾸었고, D에는 결측값 함수 명세 과제를 추가했습니다. E는 기존
  내적·재실행 과제입니다. 기존 계획의 5~7시간은 이전 범위의 추정치이며 이번
  변경 후의 필요 시간이나 실제 부담을 확인한 값이 아닙니다. 설치·기초 보충도
  별도이므로, 학생 수행을 확인해 분량과 지원 방식을 조정해야 합니다.
- 시간은 계획 추정치이며 숙달이나 수행 가능성을 입증하지 않습니다. 숫자형
  진단 통과 기준이나 개인별 자습 허용 상한은 이 자료에서 새로 정하지 않습니다.
- 도입은 한 행·단위 → 같은 몫 평균 → 편차와 분산 → 같은 입력의 axis로 연결합니다.
  긴 일반식이 어려우면 먼저 A의 한 열에 동그라미를 치고 합계와 개수로 돌아갑니다.

개념 해설과 오개념별 보충
- 평균: 같은 몫 b에 대해 n*b=전체 합이므로 b=합/n입니다. [2,4,6]cm의 합은
  12cm, 평균은 4cm입니다. 합을 평균이라고 답하면 같은 길이 막대 세 개로
  나눈다는 조건을 다시 확인합니다. 빈 목록에는 나눌 개수가 없어 평균 미정입니다.
- 분산: 편차 합은 합(x)-n*평균=0입니다. [-2,0,2]cm의 제곱합은 8cm²,
  분산은 8/3cm²입니다. [4,4,4]의 분산은 0입니다. 같은 묶음을 두 번 적으면
  제곱합과 개수가 함께 두 배여서 분산은 같습니다. 모든 값이 10cm 커지면
  평균도 10cm 커져 편차·분산은 그대로입니다. n=1이면 이번 정의의 분산은 0입니다.
- 새 분산 그림: 점 하나는 길이 기록 하나이고 세로는 기록 순서입니다. 가로
  점선은 아니며, 세로 점선의 가로 위치가 평균 4cm입니다. 주황 화살표는
  평균에서 값으로 향하므로 편차의 부호와 크기에 대응합니다. 6cm 점의
  편차는 +2cm, 제곱은 4cm²입니다. 제곱 숫자 열은 길이 좌표가 아닙니다.
- axis: A[1,0]=6=a_21. 첫 열 합계는 0→2→8→18, 둘째 열은 합계를 다시
  0으로 놓아 0→4→12→24입니다. 행을 줄이면 열별 평균 [6,8], shape(2,),
  분모3입니다. 열을 줄이면 행별 평균 [3,7,11], shape(3,), 분모2입니다.
  전체 평균은 7cm입니다. 틀리면 결과 하나를 만드는 원소만 묶어 분모와
  출력 개수를 따로 세게 합니다. h와 ml처럼 뜻·단위가 다른 열은 섞지 않습니다.
- 상태와 반환: 평균 함수의 total은 0→2→6→12입니다. return total/count는
  total을 다시 대입하지 않으므로 합계는 12이고, 호출한 곳에 4를 돌려줍니다.
  print-only 함수는 화면에 6을 써도 반환값이 None입니다. 화면과 변수 칸을
  따로 적은 뒤 반환값을 곱셈에 재사용하게 합니다.
- 결측: P01의 물0은 관측값, P03은 모르는 값입니다. 관측5개, 합140ml,
  평균28ml입니다. 실제 여섯 화분의 평균은 P03 값을 모르면 알 수 없습니다.
  dropna로 만든 계산용 Series는 원본 행을 지우지 않습니다. 전부 결측이면
  pandas 평균은 NaN이며, 이것은 평균0이라는 뜻이 아닙니다.

손풀이·필기 답
- 손풀이: A[1,0]=6, a_21; axis0=[6,8], shape(2,); axis1=[3,7,11],
  shape(3,); 전체평균7. 각 출력의 실제 합계와 분모를 함께 확인합니다.
- 필기 선택형 1: ② 13. 조건을 통과하는 값은5와8이므로 합계는0→5→13입니다.
  ①은 조건 밖2까지 더함, ③은 마지막 값만 남김 또는5 제외, ④는 통과 횟수입니다.
- 선택형 2: ② shape(3,), 각 평균은 두 행의 값으로 만듭니다. ①은 axis1,
  ③은 축소 전 모양, ④는 분모를 열 수로 착각한 경우입니다.
- 서술형: 관측값0과12의 개수는2개, 평균은6ml입니다. 세 화분 전체의 실제
  평균은 알 수 없습니다. 빈칸이0이면4ml, 9이면7ml이므로 기록 없음과0은 다릅니다.
  관측값 식별, 분모·계산, 전체 평균의 불확실성을 각각 살펴 피드백합니다.

Python 진단과 실제 수정 과제
- 1: water15, label충분. 조건문은 예측 코드와 확인 코드에서 같은 if/else입니다.
- 2: 반복3회, 합계2→6→12. 한 값을 읽은 뒤 상태를 기록합니다.
- 3: twice(3)는6 반환, show_twice(3)는 화면6·반환None.
- 4: 첫값8, 슬라이스[10,12], 원본[8,10,12,14] 유지.
- 5: FileNotFoundError는 현재 작업폴더·상대경로·파일 존재를 확인합니다.
  KeyError는 이미 읽힌 표의 columns와 자료사전을 확인합니다. 실패 단계가 다릅니다.
- [1,3,8] 누적합1→4→12, 평균4. []는 개수0이며 ValueError가 예상 동작입니다.
- shifted_mean([1,3,8],2)는 [3,5,10]의 평균6을 반환합니다. total은3→8→18,
  count3입니다. shifted_average*3은18입니다. 출력만 하면 None*3에서 TypeError입니다.
  원본 함수는 보존하고 다음과 같은 복사본을 작성할 수 있습니다.

  def shifted_mean(numbers, offset):
      count = len(numbers)
      if count == 0:
          raise ValueError("평균을 구할 값이 하나 이상 필요합니다.")
      total = 0
      for value in numbers:
          total = total + value + offset
      return total / count

- 한 값 [7], offset2는9; 빈 입력의 오류는 유지됩니다. 코드에 숫자가 아닌
  입력이나 비유한 값까지 검증한다고 주장하지 않습니다. 계약 밖 입력입니다.

수업 밖 필수 연습 해설
- 배열 반례: task_array=[[2,5,8],[11,14,17]]의 reshape 결과는
  [[2,5],[8,11],[14,17]], 전치 결과는 [[2,11],[5,14],[8,17]]입니다.
  둘 다 shape(3,2)이지만 [0,1] 값은 각각5와11입니다. 전치 결과의 첫 행은
  task_array의 첫 열입니다. shape가 같아도 위치 대응이 달라집니다. 복사·공유
  여부는 별도로 판단합니다. 새 변수 이름은 앞의 A, B를 덮어쓰지 않습니다.
- 함수 명세: 숫자 0~1,000,000, 리스트 길이 최대 10,000의 입력 조건을 둡니다.
  `None`과0을 구분하고 관측값의 개수와 평균을 반환합니다. 관측이
  없을 때 이 과제의 약속은 (0,None)입니다. 아래는 하나의 교사용 예시입니다.

  def recorded_mean(values):
      count = 0
      total = 0
      for value in values:
          if value is not None:
              count += 1
              total += value
      if count == 0:
          return (0, None)
      return (count, total / count)

  비노출 확인: [2,None,8,10]→(3,20/3), [None,None,0]→(1,0.0),
  [None]→(0,None). [3,None,9]는 호출 뒤에도 그대로이고 (2,6.0)을 반환합니다.
  실수 결과는 math.isclose(rel_tol=1e-9, abs_tol=1e-12)로 비교합니다.
  `if value:`는0을 놓치고, 출력만 하는 함수는 후속 계산에 쓸 값을 돌려주지 않습니다.
- reshape는 원소 수 보존, .T는 축 교환입니다. (3,2)와(2,) 열별 보정은
  [[3,14],[7,18],[11,22]], (3,1) 행별 보정은[[3,5],[16,18],[110,112]].
- 새 분포 [0,4,8], [3,4,5]는 평균4cm, 분산은 각각32/3,2/3cm²입니다.
- [0,4,8]에3을 더한 [3,7,11]의 평균은7cm, 편차[-4,0,4]cm와 분산
  32/3cm²는 그대로입니다. 원래 값을2배 한 [0,8,16]의 평균은8cm이고
  편차[-8,0,8]cm의 분산은128/3cm²로 네 배입니다. 단위만 cm에서 mm로
  바꾸면 분산의 수치는100배이지만 같은 물리적 자료입니다. 표준편차가0이면
  그 값으로 나누는 표준화를 그대로 적용할 수 없고, 통계량을 어느 자료에서
  구하는지와 누수는 후속 주차에서 다룹니다.
- 새 CSV 장소별 평균 높이는 실내8cm·창가13cm, 높이 관측수 각각2입니다.
  site_notes 왼쪽 병합은4행을 유지하며 note 결측은0입니다. 장소 정보 표의
  중복 키는 many_to_one에서 오류, 모르는 장소는 왼쪽 행을 보존하고 note 결측입니다.
- 내적: [2,3]과[1000,500]의 곱은[2000,1500]원, 합3500원.
  새 [1,4,2]와[800,500,1200]의 내적은5200원. 종류 순서를 맞춰야 합니다.
