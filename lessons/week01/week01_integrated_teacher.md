# 1주 통합 경로 · 교사용 해설

이 해설에는 새 독립 문제의 답이 있습니다. 공개 저장소에서 파일을 분리해도 접근이 차단되는 것은 아닙니다. 독립 수행 전에 교사가 적절한 권한의 별도 공간이나 방법으로 해설을 보관·배포해야 합니다. 학생의 직접 작성·이유·받은 도움을 확인하지 않았다면 독립 수행이나 숙달로 기록하지 않습니다.

## 운영과 책임 범위

이 통합본은 89셀 본문, 축·ID 교량, 문제 해결 교안의 중복 설명을 반복해서 완독하는 대신 같은 화분 표를 따라가는 주 경로입니다. 기존 수업 120분에 새로운 시간을 더 확보했다고 가정하지 않습니다. 학생은 마지막의 필수 후속 연습도 수행해야 합니다. 기존 자습 5~7시간은 이전 범위의 추정치이며 통합 경로·후속 과제의 실제 총시간, 수행 가능성, 지원 부담, 이해·전이는 미관찰입니다. 부족하면 미완료와 지원·추가 시간 계획을 남기고 기간을 조정합니다.

중복을 줄일 후보는 본문과 통합본의 평균·축·CSV 설명을 반복 낭독하지 않고, 통합본의 작업과 학생 설명을 근거로 본문의 새 입력 문제로 바로 이동하는 것입니다. 단 실제 필수 목표는 덮어쓰지 않습니다. 통합본의 함수는 평균만 반환하므로 본문 과제 D의 관측 개수·평균 튜플과 전부 결측 정책을 별도로 확인합니다. 통합본의 산점도는 과제 B의 Matplotlib·Seaborn 분포/범주 실습을 대체하지 않습니다. 통합본의 인메모리 CSV는 새 CSV 파일의 집계·병합·dtype 과제를 대체하지 않습니다.

## 예제의 연결과 계산

- 예측은 일주일치 실제 빛·물 기록을 확인한 뒤 높이를 재기 직전입니다. 심는 날에는 미래 실제 기록이 아니며 계획과 실제를 구별합니다. P03 물은 모름이지 0이 아닙니다. 합성 물 관측 다섯 개 0,20,40,10,50의 합120ml·평균24ml는 여섯 화분 전체의 실제 평균이 아닙니다. 함수의 정상 입력은 길이 0~10,000인 리스트, 유한한 Python 정수·실수 −1,000,000~1,000,000 또는 None/NaN이며 bool은 제외합니다. 범위 밖은 검사·보장하지 않습니다. CSV에서 읽은 NaN과 None을 모두 제외하고 0을 셉니다. [0,None,NaN,6]은 평균3, [None,NaN]과 빈 목록은 None입니다.
- 첫 세 높이 [8,10,12]cm 평균10cm, 편차[-2,0,2]cm, 분산8/3cm²입니다. 빛 행렬의 열별 결과는 [11/3,11/3]h, shape(2,), 행별은 [2,3,6]h, shape(3,)입니다. reshape [[2,2,3],[3,6,6]]와 전치 [[2,3,6],[2,3,6]]는 shape(2,3)이 같아도 [0,1]이 2와3입니다. 날별 보정은 [[3,4],[4,5],[7,8]]h입니다.
- 산점도 P03=(5h,12cm). P01은 실내 (2,8), P06은 창가 (7,18)입니다. 원본의 P05는 물20→10·높이10→14, P06은 물60→50으로 바꾼 별도 합성 표이며 두 행의 세 값이 다릅니다. 점은 화분 하나이며 장소·물 등의 조건도 다르므로 인과 효과를 주장하지 않습니다.
- 고정식은 높이 예측 4+L+0.1W: P02는 9cm, 실제 10cm, 실제−예측 +1cm. 계수는 학습되지 않았습니다. P03의 미상 물을 임의의 0으로 넣을 근거는 없습니다.
- 이후 목표가 ‘높이 12cm 이상인가’로 바뀌고 이진값 0/1을 예측합니다. 모델 입력은 water_ml 하나, 정답은 height_cm에서 만들지만 입력에 포함하지 않습니다. P01~P04 훈련 관측 물은 0,20,40이어서 대체값20ml, 대체 후 0과1의 중심은 각각10과30ml입니다. 별도 검증 P05·P06의 실제는 [1,1], 예측 [0,1], 정확도1/2입니다. 검증이 두 양성뿐이라 현실 성능을 추정할 수 없습니다. 같은 25ml가 원래 모델에서는1, P04의 훈련 물을60으로 바꾸어 별도 fit한 모델에서는0입니다. 한 특성의 훈련·추론값을 동일하게 ml→L로 바꾸면 거리가 같은 비율로 바뀌므로 가까운 중심은 바뀌지 않습니다. 여러 특성의 상대 척도 변화는 다른 문제입니다. 이는 훈련 상태와 예측이 바뀐 사례이지 검증 기반 선택이 아닙니다.
- 결과 ID P05/P06과 예측 [0,1]을 함께 정렬해야 합니다. 순서만 바꾼 후 ID를 원래대로 되돌리지 않으면 길이는 같아도 다른 대상의 결과가 됩니다. 통합본은 메모리 CSV 문자열과 임시 디스크 파일을 각각 다시 읽고 임시 파일을 정리합니다. 헤더·ID가 있는 합성 계약이며 공식 Antique의 두 무헤더 파일/ZIP과 다릅니다. 상세 제출 검사는 별도 문제 해결 교안에 남깁니다.

## 독립 기기 문제의 예시 해설

훈련 T1,T2,T3,T4만 라벨이 알려졌고 T5의 ?는 미상입니다. 훈련의 관측 signal [0,2,4] 평균은2, T3의 빈칸에2를 적용합니다. signal만 특성이고 label과 ID는 모델 입력이 아닙니다. T1의 0은 실제 관측입니다.

한 가능한 가까운 중심 모델이면 정상 중심1, 점검 중심3입니다. 검증 V9,V4,V7의 예측은 정상·점검·정상, 실제는 정상·점검·점검이므로 정확도2/3입니다. N3,N1,N7의 예측은 점검·정상·정상이고 요구 순서 N7,N3,N1로 저장하면 다음과 같습니다.

    sample_id,prediction
    N7,정상
    N3,점검
    N1,정상

다른 타당한 학습 분류기를 고른 학생에게 이 예시 예측을 강제하지 않습니다. 학생 모델의 fit, 알려진 훈련 행만으로 배운 대체값, 검증 예측과 실제값의 정렬·분모, 허용 출력과 ID 순서, 없는 signal 열·중복 ID에 대한 명확한 오류 처리를 확인합니다. 손계산한 평균이나 class 구분, 모델의 배운 상태 및 도움받은 부분을 설명하게 합니다. 값 한 칸의 결측과 열 전체 누락은 별개입니다. 별도 최종 테스트 정답은 제공되지 않았습니다.

## 남은 필수 연습과 복귀 경로

학생용 ‘8. 남은 필수 연습’에서 기존 [1주 본문](week01_python_tables.ipynb)을 별도 새 커널로 열고 준비 코드 셀3 → 원본 CSV 코드27 → 새 입력 코드54만 먼저 실행합니다. 원본은 sunlight_hours와 기존 합성값을 쓰므로 통합본의 light_h 및 다른 합성값과 같은 커널에서 섞지 않습니다. 각 과제의 예제 코드를 필요한 순서로 추가 실행하고, 끝나면 통합본 7절 답안·8절 미완료 점검으로 돌아옵니다. [축·ID 교량](week01_axes_linear_bridge.ipynb)은 다시 별도 커널로 열고 준비 셀2와 독립 A/B 입력 셀21·25를 각각 실행한 뒤 답안 셀23·27을 작성합니다. 아래 번호는 각 노트북에서 0부터 센 셀 번호입니다.
