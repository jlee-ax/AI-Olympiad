# 2주차 교사용 해설과 검증 안내 — 학생 배포 금지

학생 교안은 `week02_prediction_evaluation.ipynb`입니다. 이 해설과 교사용 검증 스크립트에는 독립 과제 해답이 있으므로 학생에게 배포하지 마세요. 파일 분리는 접근 통제가 아닙니다. 공개 저장소에 해설이 있으면 학생도 볼 수 있으므로 독립 과제 수행 전에 학생 접근이 차단되는 별도 공유·보관 방법을 교사가 마련해야 합니다.

## 운영과 범위

- 대상은 Python의 변수·조건문·반복문·함수·리스트·기본 파일 읽기를 선행한 KOAI 2027 중등 준비생입니다. AI 선수학습은 가정하지 않습니다. 기존 2주차 계획에 맞춰 이론 30분, 비코딩 30분(이 중 필기 10분), 코딩 60분입니다. 자습 6~8시간은 별도입니다. 모든 세부 시간과 독립 문제에 배정한 10분+10분은 **제안이며 실측하지 않았습니다**. 학생의 실제 수행을 관찰해 조정하고 소요 시간과 도움을 기록합니다.
- 학생 자료의 예시는 전부 독자 합성했습니다. 공개된 IOAI 2025 Antique와 2026 Robot Chasing의 조건을 교육에 전이한 것으로, 중등 기출이나 대회의 충실한 재현이 아닙니다. 2025 Antique 원문은 0=unknown, -1=replica, +1=authentic입니다. 원문은 별도의 반지도 접근도 다룰 수 있으므로 이 교안의 알려진 행 전용 전처리 규칙을 그 과제의 유일한 허용 방식으로 일반화하지 마세요.
- Robot Chasing의 출력은 입력 순서대로 0~5의 정수 행동 하나이며, 개발용 공개 test에는 라벨이 있지만 채점 시에는 라벨 없이 대체됩니다. 로봇 6개 각각의 정확도 평균이 공식 점수입니다. 공개 test는 로봇당 600행으로 균형이므로 전체 행 정확도와 로봇별 평균이 같습니다. 교안의 불균형 R1/R2는 별도 합성 사례입니다. 입력 필드는 예측 시점 명세에 따라 결정하며 모든 test 라벨이 항상 없다고 말하지 않습니다.
- 정답이 알려진 학습 행의 특성만 대체·표준화하는 것은 **이 교안이 선택한 지도학습 계약**입니다. 미상 라벨의 입력을 사용하는 합당한 반지도·비지도 방법도 있으나 0을 음성으로 바꿀 근거가 되지 않습니다.
- 그룹 분리·시간 순서·클래스 비율의 동시 달성 가능성을 실자료에서 검사합니다. 그룹 ID가 행 ID보다 중요한 경우를 보여 주고, 시계열 예측에서는 시간 역전을 금합니다. 조건이 충돌하면 선택과 한계를 적습니다.

## 수업 예제 해설

1. 훈련 A/B, 검증 C/D, 최종 테스트용 자리 표시 E/F. 실제 최종 테스트는 아직 준비되지 않았습니다. 학습 가능한 라벨 행은 a1,a2,b1,b2. b3은 미상입니다. 관측값 2,4,6의 평균은 4. 4로 대체한 훈련은 [2,4,6,4], 평균 4, 모집단 분산 2, 표준편차 √2. 원래 단위 u인 검증 [20,결측,10,12]를 대체한 후 z는 대략 [11.314,0,4.243,5.657]. 잘못 검증 관측값까지 섞으면 평균은 (2+4+6+20+10+12)/6=9. 이 누수 평균은 일부러 별도 객체에서 보여 주며 실제 파이프라인에 연결하지 않습니다.
2. z≥1 규칙의 검증 예측은 [1,-1,1,1]. `labels=[-1,1]`인 혼동행렬은 [[0,2],[1,1]], TP=1, FP=2, FN=1, TN=0. 정확도 1/4, 정밀도 1/3, 재현율 1/2. d1만 -1로 바꾸면 TN=1, FP=1, FN=1, TP=1, 정확도·정밀도·재현율이 모두 1/2.
3. 항상 -1 기준모델: [[2,0],[2,0]], 정확도 1/2, 재현율 0/2=0, 정밀도 0/0은 수학적으로 정의 불가. sklearn의 `zero_division=0`은 보고값 0, `np.nan`은 NaN(버전 1.3 이상)이며 기본 `warn`은 경고와 0입니다. 보고 정책이 수학적 정의를 바꾸지 않습니다. 기본 표준화에서 상수 특성은 식의 0 나눗셈을 직접 적용할 수 없고 라이브러리 처리 확인이 필요합니다.
4. 라벨 [1,-1,0,1]과 예측 [-1,1,-1,1]에서 알려진 세 행만 채점하면 [[0,1],[1,1]]. 0을 임의로 -1로 바꾼 틀린 결과는 [[1,1],[1,1]]입니다. 어느 쪽이 실제 정답인지는 0의 판정 없이는 알 수 없습니다.
5. R1(8/10)과 R2(0/2)에서 전체 행은 8/12=2/3, 개체별 평균은 (0.8+0)/2=0.4. 관측 행이 없는 개체는 정확도 분모가 0이므로 채점 문서의 포함·제외 정책을 따릅니다. 이를 공식 Robot Chasing의 미관측 로봇 정책이라고 단정하지 않습니다.

## 독립 과제 답안·관찰 기준

수업 예제를 가리고 새 입력을 쓰게 합니다. 결과만 대조하지 말고 선택한 행·정보가 흐르는 경로·분모·도움을 함께 기록합니다. 미리 정한 합격률이나 실제 학생 성취는 없습니다.

- 알려진 훈련 행 m1,m2,n1,n2. n3의 0은 정답 미상이므로 제외. 관측 [3,6,9]의 평균은 6u, 검증의 관측 99까지 섞은 잘못된 평균은 (3+6+9+99)/4=29.25u. 결측을 채운 훈련 [3,6,9,6]의 평균은 6u, 모집단 분산은 (9+0+9+0)/4=4.5u², 표준편차 √4.5u.
- 검증 o1,o2,p1,p2의 대체 후 값 [99,6,6,6]과 z는 [93/√4.5,0,0,0]. z≥1 고정 규칙의 예측은 [1,-1,-1,-1]. 혼동행렬 [[2,0],[1,1]], TN=2, FP=0, FN=1, TP=1, 정확도 3/4, 정밀도 1/1, 재현율 1/2.
- 모두 -1 예측 시 [[2,0],[2,0]], 재현율 0/2=0, 정밀도 0/0 정의 불가. sklearn `zero_division=0`의 0은 정의 불가에 대한 보고값입니다.
- 개체 X는 3/3, Y는 1/5이므로 전체 행 정확도 4/8=0.5, 개체별 평균 (1+0.2)/2=0.6. 앞은 행을, 뒤는 개체를 같은 무게로 셉니다.
- M의 두 기록을 서로 다른 분할에 두면 새 개체를 보는 평가가 아닙니다. 시점 t에서 이후의 관측·라벨이 특징이나 전처리에 들어가면 미래 정보가 샙니다. Q는 4주차 필수 자습을 포함한 모든 후보/설정 선택을 고정한 뒤 한 번 평가합니다.
- 코딩 확인: `known`은 `label.isin([-1,1])`에서 훈련 그룹 M/N에 한정, `Pipeline([('imputer',SimpleImputer()),('scaler',StandardScaler())])`는 그 행에만 `fit`하고 O/P에 `transform`. `statistics_`, `mean_`, `scale_`을 검사합니다. Dummy 모델은 X값에 의존하지 않아 점수만으로 누수를 찾지 못합니다. 혼동행렬 예측 순서가 o1,o2,p1,p2인지 검사합니다.
- 점검 제안: (a) 예측 시점과 데이터 계약, (b) 그룹/시간/미상 결정, (c) train-only 통계와 누수 반례, (d) 독립 입력의 코드/예측, (e) 지표와 0분모, (f) 행 대 개체 집계 각각에 대해 설명, 오류·자기 수정, 사용한 도움을 기록합니다. 틀린 단계부터 작은 입력으로 되짚고 다른 입력으로 재확인합니다. 이는 채점 기준 초안이며 검증된 숙달 판정이 아닙니다.

## 최종 테스트 준비와 보관 — 현재 미생성

학생 노트북의 E/F는 나중에 평가할 새 개체의 자리 표시입니다. **실제 숨겨진 최종 테스트 자료와 정답은 아직 생성·확보하거나 검증하지 않았습니다.** 이전 해설에 공개된 테스트 수치와 정답은 독립 평가에 재사용하지 마세요.

교사는 모델·설정 선택에 착수하기 전에 훈련 A/B와 검증 C/D에 속하지 않는 새 개체의 최종 테스트 자료와 정답을 별도로 구성하고, 예측 시점의 입력 계약과 적용할 그룹·시간 분리 조건을 확인하세요. 자료와 정답은 공개 저장소가 아닌, 학생과 모델 선택 담당자의 접근이 차단된 별도 장소에 보관합니다. 분리된 파일 이름만으로 접근 제한이 되는 것은 아닙니다. 준비 후 4주차의 수업 및 필수 자습을 모두 끝내고 모델과 설정을 고정할 때까지 자료와 정답을 열지 않습니다.

선택을 고정한 뒤 보관한 최종 테스트로 한 번 평가합니다. 그 결과를 보고 모델이나 설정을 바꾼다면 해당 테스트는 더 이상 독립 최종 평가가 아니므로, 다음 최종 평가에는 새로 분리해 보관한 자료가 필요합니다. 이 절은 준비 절차이며 실제 보관·독립성·성취 검증의 완료를 뜻하지 않습니다.
