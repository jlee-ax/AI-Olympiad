# 2주차 교사용 해설과 검증 안내 — 학생 배포 금지

학생 교안은 `week02_prediction_evaluation.ipynb`, 이어지는 필수 연습은 `week02_temporal_preprocessing.ipynb`입니다. 이 해설과 교사용 검증 스크립트에는 독립 과제 해답이 있으므로 학생에게 배포하지 마세요. 파일 분리는 접근 통제가 아닙니다. 공개 저장소에 해설이 있으면 학생도 볼 수 있으므로 독립 과제 수행 전에 학생 접근이 차단되는 별도 공유·보관 방법을 교사가 마련해야 합니다.

## 운영과 범위

- 대상은 Python의 변수·조건문·반복문·함수·리스트·기본 파일 읽기를 선행한 KOAI 2027 중등 준비생입니다. AI 선수학습은 가정하지 않습니다. 기존 2주차 계획에 맞춰 이론 30분, 비코딩 30분(이 중 필기와 해설 10분), 코딩 60분입니다. 자습 6~8시간은 별도입니다. 본문 독립 과제의 선택형 2문항·짧은 서술 1문항과 피드백은 기존 필기 시간에 넣고, 추가 필기와 코딩은 기존 코딩·필수 자습에 연결합니다. 이는 편성 제안이며 **실측하지 않았습니다**. 학생의 실제 수행을 관찰해 조정하고 소요 시간과 도움을 기록합니다.
- 학생 자료의 예시는 전부 독자 합성했습니다. 공개된 IOAI 2025 Antique와 2026 Robot Chasing의 조건을 교육에 전이한 것으로, 중등 기출이나 대회의 충실한 재현이 아닙니다. 2025 Antique 원문은 0=unknown, -1=replica, +1=authentic입니다. 원문은 별도의 반지도 접근도 다룰 수 있으므로 이 교안의 알려진 행 전용 전처리 규칙을 그 과제의 유일한 허용 방식으로 일반화하지 마세요.
- Robot Chasing의 출력은 입력 순서대로 0~5의 정수 행동 하나이며, 개발용 공개 test에는 라벨이 있지만 채점 시에는 라벨 없이 대체됩니다. 로봇 6개 각각의 정확도 평균이 공식 점수입니다. 공개 test는 로봇당 600행으로 균형이므로 전체 행 정확도와 로봇별 평균이 같습니다. 교안의 불균형 R1/R2는 별도 합성 사례입니다. 원문은 훈련과 공개 test에 같은 여섯 로봇이 있고, 각 행은 독립 snapshot이며 이전 관측·행동을 제공하지 않습니다. 익숙한 구성 요소의 새 조합이 나올 수 있습니다. 이 수업의 새 개체 분할이나 보충의 미래 시계열 계약과 목적이 다릅니다. 입력 필드는 명세에 따라 결정하며 모든 test 라벨이 항상 없다고 말하지 않습니다.
- 정답이 알려진 학습 행의 특성만 대체·표준화하는 것은 **이 교안이 선택한 지도학습 계약**입니다. 미상 라벨의 입력을 사용하는 합당한 반지도·비지도 방법도 있으나 0을 음성으로 바꿀 근거가 되지 않습니다.
- 그룹 분리·시간 순서·클래스 비율의 동시 달성 가능성을 실자료에서 검사합니다. 그룹 ID가 행 ID보다 중요한 경우를 보여 주고, 시계열 예측에서는 시간 역전을 금합니다. 조건이 충돌하면 선택과 한계를 적습니다.

## 두 자료의 경로와 4주 준비

본문의 필수 연습 1~4는 본문 2·6·7절과 보충 1~4·6절을 가리킵니다. 목록과 해당 보충 문제를 별도로 두 번 제출하라는 뜻이 아닙니다. 다만 평균/표준화와 중앙값/MinMax, 미상 정답과 미지 범주, 행/개체 평균과 정답 가중 점수, 두 예측 시점은 서로 다른 목표입니다. 본문은 측정 직후라 그 측정이 제공되고 보충은 측정 전이라 같은 시각 측정이 허용되지 않습니다. 두 사례의 계약을 학생이 비교하게 합니다.

같은 합성 원본의 추가 훈련 후보는 G의 `(2,-1),(4,+1)`와 H의 `(4,-1),(6,+1)`입니다. 본문의 `records`·`known_train`은 A/B worked subset으로 그대로 두며, `additional_train`, `course_records`, `train_4w`, `known_train_4w`가 4주에 재사용할 후보를 제공합니다. C/D는 검증, E/F는 아직 자료와 정답이 없는 최종 테스트 자리 표시입니다. 4주에 A/B/G/H의 알려진 8행을 쓴다면 전처리와 모델을 다시 fit하고 Dummy 기준 모델도 그 훈련 조건으로 다시 계산해야 합니다. 2주 A/B의 fitted 객체를 재사용한 점수와 4주의 다른 훈련 조건을 같은 비교로 취급하지 않습니다.

2-fold 그룹 교차검증의 한 결정적 분할은 A/G 대 B/H입니다. 각 학습 fold는 4행이고 두 라벨을 포함합니다. A/G에서 훈련한 대체 평균은 3, B/H에서는 16/3입니다. 전처리는 **fold마다** 훈련 부분만 fit합니다. 예컨대 `k=3`은 두 학습 fold의 4행에 대해 유효하지만 4보다 큰 k는 유효하지 않습니다. 그룹 분리, 양 클래스, 각 fitted 통계 및 실제 fit/predict는 본문 검사기의 검사가 아닙니다. 별도의 [작성자 유한 검산 코드](../../reviews/week02-integration-20261111/author/check_candidate.py)와 [기록](../../reviews/week02-integration-20261111/author/independent-checks.json)에서 fit 행 ID·표준화 표본 수와 결과를 확인합니다. 독립 검토 기록은 각각의 대상 SHA와 검사 범위를 확인합니다. 이 작은 구성은 방법의 작동 확인이며 4주 교안 완성이나 성능의 신뢰할 만한 추정이 아닙니다.

## 수업 예제 해설

1. 훈련 A/B, 검증 C/D, 최종 테스트용 자리 표시 E/F. 실제 최종 테스트는 아직 준비되지 않았습니다. 학습 가능한 라벨 행은 a1,a2,b1,b2. b3은 미상입니다. 관측값 2,4,6의 평균은 4. 4로 대체한 훈련은 [2,4,6,4], 평균 4, 모집단 분산 2, 표준편차 √2. 원래 단위 u인 검증 [20,결측,10,12]를 대체한 후 z는 대략 [11.314,0,4.243,5.657]. 잘못 검증 관측값까지 섞으면 평균은 (2+4+6+20+10+12)/6=9. 이 누수 평균은 일부러 별도 객체에서 보여 주며 실제 파이프라인에 연결하지 않습니다.
2. z≥1 규칙의 검증 예측은 [1,-1,1,1]. `labels=[-1,1]`인 혼동행렬은 [[0,2],[1,1]], TP=1, FP=2, FN=1, TN=0. 정확도 1/4, 정밀도 1/3, 재현율 1/2, F1=2/5. F1의 count 식에서 분모 0은 TP=FP=FN=0일 때이며, 정밀도 또는 재현율 하나의 분모가 0이어도 F1의 count 식이 0으로 정의될 수 있습니다. 라이브러리 보고 정책과 구별합니다. d1만 -1로 바꾸면 TN=1, FP=1, FN=1, TP=1, 정확도·정밀도·재현율이 모두 1/2.
3. 항상 -1 기준모델: [[2,0],[2,0]], 정확도 1/2, 재현율 0/2=0, 정밀도 0/0은 수학적으로 정의 불가. 이 기준은 사람이 미리 정한 상수이지 최빈값으로 학습한 결과가 아닙니다. A/B의 알려진 훈련 라벨은 2:2 동률이므로 최빈 기준을 쓰려면 사전에 동률 정책을 정해야 합니다. 보충 5절은 별도 훈련 라벨의 최빈값을 학습해 같은 검증에 적용합니다. sklearn의 `zero_division=0`은 보고값 0, `np.nan`은 NaN(버전 1.3 이상)이며 기본 `warn`은 경고와 0입니다. 보고 정책이 수학적 정의를 바꾸지 않습니다. 기본 표준화에서 상수 특성은 식의 0 나눗셈을 직접 적용할 수 없고 라이브러리 처리 확인이 필요합니다.
4. 라벨 [1,-1,0,1]과 예측 [-1,1,-1,1]에서 알려진 세 행만 채점하면 [[0,1],[1,1]]. 0을 임의로 -1로 바꾼 틀린 결과는 [[1,1],[1,1]]입니다. 어느 쪽이 실제 정답인지는 0의 판정 없이는 알 수 없습니다.
5. R1(8/10)과 R2(0/2)에서 전체 행은 8/12=2/3, 개체별 평균은 (0.8+0)/2=0.4. 관측 행이 없는 개체는 정확도 분모가 0이므로 채점 문서의 포함·제외 정책을 따릅니다. 이를 공식 Robot Chasing의 미관측 로봇 정책이라고 단정하지 않습니다.

## ROC-AUC 예제와 경계

본문의 실제 라벨 `[1,-1,1,-1]`, 점수 `[0.9,0.6,0.4,0.1]`에서 양성 0.9는 두 음성보다, 양성 0.4는 음성 0.1보다만 높습니다. 네 양성–음성 쌍 중 세 쌍이므로 순위 AUC는 3/4입니다. ROC 사다리꼴 면적과 `roc_auc_score((roc_truth == 1).astype(int), roc_scores)`도 0.75입니다. 임계값 0.5에서는 정확도·F1이 각각 1/2, 1/2이고, 0.3에서는 3/4, 4/5입니다. 점수는 고정했으므로 AUC는 둘 다 같습니다.

점수를 모두 1 올리고 임계값도 0.5에서 1.5로 올리면 예측이 같습니다. 점수만 올리고 임계값을 0.5로 그대로 두면 모두 양성으로 바뀌고 F1은 2/3입니다. 어느 경우에도 양성·음성 점수 순서는 같아 AUC는 0.75입니다. 순위가 같다는 것은 확률 보정이 같다는 뜻이 아닙니다.

보충의 기존 그림은 AUC 0.5이지만 ROC 전체가 대각선은 아닙니다. AUC 0.5는 해당 표에서 동점에 반 점을 준 양성–음성 쌍의 평균이 0.5라는 뜻이지, 데이터 생성이 무작위라는 증거가 아닙니다. 모든 양성 점수가 음성보다 낮으면 AUC 0, 반대로 정렬하면 1, 전부 동점이면 0.5입니다. 실제 양성 또는 음성이 전혀 없으면 양성–음성 쌍이 없어 AUC는 정의되지 않습니다. 실제 scikit-learn 1.8.0에서는 경고와 NaN을 보았으며 버전에 따라 오류가 날 수 있으므로 두 클래스 존재를 먼저 확인합니다.

국내 [출제 기준](https://kitpa.org/koai/syllabus)은 ROC 곡선을 명시하나 AUC를 별도 이름으로 열거하지 않습니다. [KOAI 2026 예시 공지](https://kitpa.org/files/36)의 23번은 AUC 관련 고등부 수준의 학습 참고 예시이며 중등 기출이나 KOAI 2027 출제 예측이 아닙니다. 예시 문제는 재배포하지 않았습니다.

## 두 명세 독립 과제 답안·관찰 기준

이 해설은 공개 저장소에 있으므로 접근 제한이 없습니다. 별도 비공개 평가나 접근 차단은 아직 준비·검증하지 않았습니다. 선택형 1은 가, 선택형 2는 가입니다. 짧은 서술에서는 동일 검증 행·라벨과 목적 지표에서 비교해야 공정하고, 검증으로 선택한 뒤 후보·전처리·임계값을 고정해야 최종 평가를 선택에 재사용하지 않음을 설명합니다. 실제 학생의 답이나 소요 시간은 아직 없습니다.

- **명세 가:** 훈련 a1/a2/b1/b2, 검증 c6/c7/d6/d7. 훈련 기기 {A,B}와 검증 {C,D}는 겹치지 않고, 훈련 시각 최대 2는 검증 최소 6보다 작습니다. 실제 설계에서는 충분한 자료가 있다면 이 한 분할만 정답인 것은 아닙니다. 훈련 x는 [0,2,2,6], 평균·대체값 5/2, 모집단 표준편차 √19/2. 검증 입력 대체 후 [4,8,6,5/2]이며 R은 [1,1,1,1], K는 [-1,-1,-1,-1]. 정답 [-1,1,-1,-1]에서 각각의 정확도는 K=3/4, R=1/4, 재현율은 K=0/1, R=1/1입니다. 주어진 행 정확도로 K를 고릅니다.
- **명세 나:** 기존 설정 X의 rX/sX/tX/uX로 훈련, 다른 설정 Y의 rY/sY/tY/uY로 검증합니다. 모든 기기가 양쪽에 있어도 서로 다른 설정은 다른 행이며, 알려진 기기의 새로운 설정이라는 목표에 부합합니다. 이는 새 기기 일반화를 검증하지는 않습니다. 훈련 x [0,2,4,6]의 평균·대체값은 3, 모집단 표준편차는 √5. 검증 x를 대체하면 [4,6,8,3]이고 R은 [1,1,1,1], K는 [-1,-1,-1,-1]. 정답 [-1,1,-1,-1]에서 K와 R의 정확도는 각각 3/4와 1/4, 재현율은 각각 0/1과 1/1입니다. 정해진 재현율로 R을 고릅니다. 같은 표에서도 정확도로 고르면 K여서 목적에 따른 차이가 분명합니다.
- 명세 가의 라벨 없는 연습 w8/v8은 고정한 K로 [-1,-1], 명세 나의 rZ/sZ는 고정한 R로 [1,-1]입니다. 각각 지정된 ID 순서를 유지합니다. 연습 입력은 실제 보류 테스트가 아닙니다.
- 검증을 섞은 fit은 평가 입력에서 통계를 배우는 경로이고 예측 후 수리 기록은 이용할 수 없는 미래 정보입니다. A/B 학습을 고정하고 시각 6·7에 A/B만 있다면 새 기기를 평가할 수 없습니다. 새 기기의 미래 기록이 필요합니다. 실제 양성이 없으면 재현율 분모가 0이므로 정의되지 않아 그 지표로 순위를 매기지 않습니다. 라이브러리의 정책 출력 0을 정의된 수학적 0으로 취급하지 않습니다.
- 결과뿐 아니라 명세→행 ID→fit 통계→동일 검증 ID 예측→분모→선택→고정 후 출력의 연결과 사용한 도움을 살핍니다. 검증 입력을 변경해도 이미 fit한 통계는 변하지 않아야 합니다. 단지 코드 실행이나 교사용 참조값 일치만으로 학생의 독립 성취를 판정하지 않습니다.

이번에 본문 6절의 단일 M/N 문제를 위 두 명세로 **교체**하고, 보충 6절의 반복 분할 설계와 Robot 비교를 접어 본문의 새 과제로 통합했습니다. 보충의 과거 특성, ROC, 가중 지표, 훈련 최빈 기준 및 독립 연습은 유지합니다. 두 명세를 한 번에 풀어야 한다는 추가 과제로 보충을 다시 제출하지 않습니다. 본문 독립 문제의 원문 글자 수는 1,529→2,541자이고 보충 도입·분할 비교는 1,558→1,026자여서 두 부분 합계는 3,087→3,567자입니다. 보충 무라벨 입력 안내는 동률 여부를 드러내지 않게 고쳐 657→676자입니다. 본문의 한 사례가 두 명세로 바뀌어 독립 선택이 늘었고 보충의 반복 분할을 제공했으며 독립 코드칸 수는 그대로입니다. 문자 수와 활동 구성은 난도나 실제 소요 시간의 측정이 아닙니다. 기존 수업 120분과 필수 자습 6–8시간은 편성이고, 이 개정의 실제 수행 시간·도움·이해는 미관찰입니다.

### 교사용 전이 반례

별도 계약에서 라벨이 `0,1,None,0,1`이고 `None`만 미상이라면 알려진 정답 네 개에 숫자 0 두 개를 포함합니다. 예측 `0,1,1,1,1`이면 알려진 네 개 중 세 개가 맞습니다. 앞선 합성 예제의 0=미상을 모든 문제에 적용하면 두 개의 알려진 정답을 버립니다.

한 센서 계약에서 관측 시각·도착 시각·값이 각각 (1,1,3), (2,4,99)이고 예측 시점이 3이라면, 두 번째 관측은 과거에 이뤄졌어도 아직 도착하지 않아 99는 쓸 수 없습니다. 시점 4에서 이미 도착했고 과거 관측을 사용할 수 있다는 계약이면 쓸 수 있습니다. 관측 시각만이 아니라 예측 시점에 실제 제공된 정보와 계약을 확인합니다. 다른 과제의 허용된 전체 문맥을 일률적으로 금지한다는 뜻은 아닙니다.

두 명세와 이 반례는 `python -B lessons/week02/teacher_validate_contracts.py`로 교사용 유한 참조값을 검산합니다. 이 검사는 학생이 작성한 코드나 독립 이해도를 자동 판정하지 않습니다.

### 계획의 분할 문구와 정정

이전 계획의 조건 없는 개체 분리 문구는 명세 나처럼 **이미 알려진 기기의 새 설정**을 평가하려고 동일 기기 ID를 양쪽에 두는 연습과 표현상 충돌했습니다. 현재 학생 계획은 평가 목표에 따라 새 개체와 알려진 개체의 별도 기록을 구별하고, 2·4주 공통 자료에는 새 개체를 위한 그룹 분리와 최종 테스트 보류를 유지합니다. 원본의 복제·증강 누수와 예측 시점에 허용된 과거 문맥도 구분합니다. [계획 개정 기록](../../reviews/week02-plan-integration-20261111/review.md)은 이전 판본과 검토 영향의 한계를 보존합니다.

명세 나의 X와 Y는 같은 원본을 복제하거나 증강한 것이 아니라 **서로 다른 원본 기록**입니다. 같은 원본에서 만들어진 중복·파생 자료가 훈련과 검증을 오가는 문제와 구별합니다. 그럼에도 같은 기기에서 얻은 행은 상관될 수 있으므로 ID가 겹친 결과는 새 기기 일반화의 근거가 아닙니다. ID가 같다는 사실만으로 모든 분할이 적절해지거나, 다른 원본이라는 사실만으로 모든 누수가 사라지는 것도 아닙니다. 명세 가와 2·4주 공통 자료의 새 개체 평가는 기존 그룹 분리와 최종 테스트 보류를 그대로 따릅니다.

## 3–10주 연결과 근거

계획상의 3주는 회귀와 손실·평가 단위, 4주는 분류·CV와 fold별 재fit, 5주는 PCA 등 학습형 변환의 fit 경계, 6주는 학습·평가와 학습 루프, 7주는 이미지·원본 비디오 단위 분할, 8주는 훈련 문서의 어휘·TF-IDF, 9주는 원본 음원 단위 분할과 훈련 코드북, 10주는 새 명세의 입력·출력·지표·선택과 최종 평가로 연결합니다. 이는 기존 계획의 선수 경로이지 후속 교안의 완성이나 학생의 습득을 뜻하지 않습니다. 두 명세를 국제대회 문제의 실제 분할이나 국내 중등 기출로 주장하지 않습니다.

## 최종 테스트 준비와 보관 — 현재 미생성

학생 노트북의 E/F는 나중에 평가할 새 개체의 자리 표시입니다. **실제 숨겨진 최종 테스트 자료와 정답은 아직 생성·확보하거나 검증하지 않았습니다.** 이전 해설에 공개된 테스트 수치와 정답은 독립 평가에 재사용하지 마세요.

교사는 모델·설정 선택에 착수하기 전에 훈련 후보 A/B/G/H와 검증 C/D에 속하지 않는 새 개체의 최종 테스트 자료와 정답을 별도로 구성하고, 예측 시점의 입력 계약과 적용할 그룹·시간 분리 조건을 확인하세요. 자료와 정답은 공개 저장소가 아닌, 학생과 모델 선택 담당자의 접근이 차단된 별도 장소에 보관합니다. 분리된 파일 이름만으로 접근 제한이 되는 것은 아닙니다. 준비 후 4주차의 수업 및 필수 자습을 모두 끝내고 모델과 설정을 고정할 때까지 자료와 정답을 열지 않습니다.

선택을 고정한 뒤 보관한 최종 테스트로 한 번 평가합니다. 그 결과를 보고 모델이나 설정을 바꾼다면 해당 테스트는 더 이상 독립 최종 평가가 아니므로, 다음 최종 평가에는 새로 분리해 보관한 자료가 필요합니다. 이 절은 준비 절차이며 실제 보관·독립성·성취 검증의 완료를 뜻하지 않습니다.
