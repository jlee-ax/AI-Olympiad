# 2주차 시계열·전처리 보충: 교사용 해설

이 문서는 독립 과제의 답을 포함합니다. 학생 자료와 파일을 분리해도 **저장소 자체가 접근 통제를 제공하지는 않습니다.** 공개 저장소에 있을 때는 교사가 독립 과제 수행 전에 학생과 선택 담당자의 접근이 차단되는 별도 전달·보관 방법을 마련해야 합니다.

이 보충본은 기존 2주 교안의 평균 대체·표준화·그룹별 혼동행렬 설명을 다시 가르치기보다, 기존 계획의 전처리·특성·ROC 자습 항목에 실제 예제와 독립 과제를 제공합니다. 기존 2주 자습 배치를 대체하거나 연결하는 자료이며 새 시간이 확보되었다는 가정은 없습니다. 기존 6번을 확장하여 최빈 기준의 학습·혼동행렬·여러 지표와 빈도 반전까지 묻고 worked 코드 셀 하나를 추가했습니다. 새 번호의 대형 문제는 없지만 필수 수행 단계와 글은 늘었습니다. 실제 완수율, 학습 성취, 도움, 소요시간은 관찰하지 못했습니다. 기존 과정의 2·4주 후보 및 설정 선택이 모두 끝나기 전에는 최종 테스트를 보류합니다. 학생 자료의 E는 자리 표시이며 실제 최종 테스트는 생성·확보되지 않았습니다.

## 수업 예제: 확인할 개념

- 예측은 시각 t의 측정 전. 각 측정은 해당 시각의 예측 뒤 도착하고 정답은 그날 끝에 알려집니다. 훈련 A/B의 t=4,5 정답이 t=6 전에 도착한다는 가정이 없으면 이 학습·검증 일정은 성립하지 않습니다.
- 대상 예측 행은 A/B의 t=4,5와 C/D의 t=6,7로 미리 나눕니다. 새 개체의 미래가 목적이므로 이 예에서는 개체와 시간이 둘 다 분리됩니다. C/D의 t<6 관측은 라벨 없이 평가 개체의 별도 과거 문맥으로만 허용됩니다. t=6에서 측정한 값은 t=7에 도착한 과거라서 사용할 수 있습니다. 처음부터 미래 여러 시각을 일괄 예측하는 계약이면 t=6의 값은 허용되지 않습니다.
- 이미 아는 개체의 미래 예측에는 개체 중복이 정상일 수 있습니다. 새 개체의 같은 시기 일반화만 평가한다면 시간 분할이 반드시 필요한 것은 아닙니다. 교과서적 분할 이름보다 목표와 제공 계약이 우선입니다.
- A4의 최근 3개는 2,4,6: 평균 4, 모집단 표준편차 √(8/3). A5의 최근 3개는 4,6,4: 평균 14/3, 표준편차 √(8/9). B4의 최근값과 3개 통계는 모두 결측. B5의 최근값은 2지만 실제 관측 3개가 없어 3개 통계는 결측. C6/C7 최근값은 8/12, D6/D7은 1/7입니다. 관측만 세는 윈도와 forward-fill 값을 구별합니다.
- 전처리의 훈련 recent는 [6,4,결측,2], 중앙값 4, 최소 2, 최대 6. 평가 recent는 [8,12,1,7], 변환은 [1.5,2.5,-0.25,1.25]. 훈련 범위를 넘으면 기본 clip=False에서 0~1을 벗어납니다. mean3/std3 열에도 각각 훈련 중앙값 대체·최소최대 변환을 적용합니다.
- 훈련 범주는 blue/red이고 C의 green은 두 열 모두 0, D red는 [0,1]. 기본 handle_unknown은 오류입니다. drop='first'는 blue를 생략하므로 blue와 green이 모두 [0]이 되어 원래 종류를 구별할 수 없습니다. green을 transform할 수 있다는 것은 green이 학습된 종류라는 뜻이 아닙니다.
- 무조건 전체 자료에서 ffill하거나 중심 윈도를 만든 후 나누는 것은 다른 개체의 값 또는 예측 시점에 없는 미래를 옮길 수 있습니다. 단 분할 경계를 넘는 허용된 과거 문맥 자체는 누수가 아닙니다. 학습형 전처리 fit과 별도로 검토합니다. 값이 뒤늦게 도착하는 현실 자료라면 관측 시각만이 아니라 실제 도착 시각까지 계약에 포함해야 합니다. 이 합성 예제는 각 측정이 같은 시각 예측 직후 도착한다고 단순화합니다.
- 고정 점수는 scaled recent + 0.25 × red이고 C6,C7,D6,D7 순서 [1.5,2.5,0,1.5]. 1.5 이상에서 TP=2,FP=1,TN=1,FN=0, 정확도 3/4, 정밀도 2/3, 재현율 1, F1=4/5. ROC (FPR,TPR)은 (0,0), (1/2,0), (1/2,1), (1,1)이고 동점 1.5의 양성 2개가 함께 움직입니다. 양성 점수 1.5 두 개가 각각 음성 0은 이기고 음성 2.5에는 지므로 AUC는 2/4=0.5입니다. ROC 전체는 대각선이 아니며 0.5만으로 무작위 생성 여부를 판단할 수 없습니다. 결정 점수이므로 확률 보정이나 실제 모델 효과를 뜻하지 않습니다.
- 반복적으로 같은 검증을 보고 후보를 선택하면 검증에 과대적합될 수 있습니다. 검증 선택 자체는 예정된 역할입니다. 예측 당시 없는 미래 값이나 최종 테스트에 의해 전처리·선택이 달라지는 누수와 정보 경로가 다릅니다. 두 현상이 동시에 일어날 수도 있습니다.
- 가중 예제는 실제 B 5개·T 1개에 가중치 1·5: 가는 행 정확도 5/6, 가중 5/10, 나는 4/6과 8/10. 분모는 모든 실제 행의 최대점수 10입니다. 정답 의존 가중치는 사후 채점에 사용하며 예측용 입력이 아닙니다.
- 별도 훈련 라벨 B 3, T 1, 미상 0 다섯 개 중 알려진 라벨만 세면 B가 유일한 최빈입니다. 알려진 훈련 N행에서 상수 c의 정확도는 n_c/N이므로 argmax는 최빈 상수를 고릅니다. `DummyClassifier(strategy="most_frequent")`는 X와 y의 관계를 배우지 않으며 알려진 행만 fit합니다. 검증 B 5, T 1에서 이 기준의 예측은 가와 같습니다. T 양성일 때 가는 TP=0, FP=0, TN=5, FN=1, 재현율 0, 정밀도 0/0 정의 불가, F1 0입니다. `zero_division=0`은 보고 정책입니다. 나는 TP=1, FP=2, TN=3, FN=0, 정밀도 1/3, 재현율 1, F1 1/2입니다. 이 수치와 기존 가중 점수를 서로 다른 목표에서 비교합니다.
- 알려진 훈련이 동률이면 이 코드의 정책은 오류로 중단하고 사람이 정책을 정하는 것입니다. 알려진 정답이 없으면 중단합니다. Python의 False가 숫자 0과 같게 비교되므로 Boolean은 입력 오류로 거부하고 수치 0과 0.0은 이 예제에서 미상으로 취급합니다. 한 클래스만 알려지면 Dummy는 fit할 수 있으나 없는 클래스를 학습했다고 말하지 않습니다. `classes_`와 `predict_proba` 열 수를 확인합니다. 미상 0 제외는 이 합성 지도학습 예제의 계약이지 IOAI Antique의 반지도 입력 활용을 일괄 금지하는 말이 아닙니다. 검증 정답의 빈도만 B 1, T 5로 바꿔도 같은 fitted 기준의 예측은 B 여섯 개이며 정확도는 1/6로 달라집니다.

## 독립 과제 답과 피드백

**0. 분할 설계.** 시각 6 전에 끝난 학습과 이후 시각 6·7의 새 개체라는 조건에서 훈련 대상은 M4/M5/N4/N5, 검증 대상은 P6/P7/Q6/Q7입니다. 훈련 그룹 {M,N}과 검증 그룹 {P,Q}의 교집합은 없고, 훈련 대상 최대 시각 5는 검증 대상 최소 시각 6보다 작습니다. P/Q의 이전 관측은 그들의 검증 시점에서만 허용된 과거 문맥이고 훈련 대상 행이나 학습형 `fit`에 섞지 않습니다. 학생이 스스로 행을 배정하고 두 조건을 검사하는지 확인합니다. Robot Chasing 원문은 훈련과 공개 평가에 같은 여섯 로봇이 있고 행은 독립 snapshot이며 이전 관측은 제공되지 않습니다. 익숙한 표현·색·물체의 새 조합이 나올 수 있습니다. 별도 합성 설계 (가)는 이미 본 두 ID의 다른 조합을, (나)는 훈련에 없던 ID의 예측을 평가합니다. 제시된 알려진 로봇의 새 조합 목표에는 (가)가 더 직접 맞지만, 새 로봇 평가가 목표라면 (나)가 적절합니다. 두 설계 모두 원문의 실제 분할을 재현했다고 주장하지 않습니다. 원문처럼 이전 관측이 제공되지 않으면 어느 쪽에서도 이를 시간 윈도 입력으로 쓸 수 없습니다. 새 개체의 미래를 목표로 하는 위 합성 과제와 평가 목적 및 허용 과거의 의미가 다르며 개체 분리를 모든 과제에 일괄 강제하지 않습니다.

**1. 시점·과거.** M4/M5/N4/N5 recent는 [9,9,결측,1]; P6/P7/Q6/Q7은 [11,17,0,11]. M4 관측 [5,7,9]의 평균 7, 표준편차 √(8/3). P6 관측 [7,9,11]의 평균 9, 표준편차 √(8/3). N4는 과거 관측이 없어 결측이고 Q6의 0은 Q2에서 이어진 값입니다. Q 외 개체에서 가져오거나 Q6 자체를 포함하면 안 됩니다. P7이 P6 측정을 쓸 수 있는 것은 P6 측정이 P7 예측 전에 도착하는 순차 예측 계약일 때입니다. 일괄 예측은 허용하지 않습니다.

**2. 학습형 변환.** 훈련 관측 recent [9,9,1]의 중앙값 9. 결측 대체 후 [9,9,9,1], 최소 1·최대 9. 검증 순서의 변환은 [5/4,2,-1/8,5/4]. 범주 순서가 gold,silver이면 gold [1,0], silver [0,1], bronze [0,0]. drop='first'에서 gold와 bronze가 모두 [0]이 될 수 있습니다. 학생이 순서를 다르게 선택했더라도 열 이름과 벡터를 일관되게 기록했다면 의미를 확인합니다. 결측을 검증의 값으로 채우거나 인코더를 검증에서 다시 fit하면 잘못입니다.

**3. 지표와 ROC.** 점수와 실제는 각각 [5/4,2,-1/8,5/4], [+1,-1,+1,-1]. 아래 순서 TP,FP,TN,FN; 정확도·정밀도·재현율·F1; (FPR,TPR)입니다.

| 임계값 | TP, FP, TN, FN | 정확도, 정밀도, 재현율, F1 | ROC 좌표 |
|---:|---|---|---|
| +∞ | 0,0,2,2 | 1/2, 정의 불가, 0, 0 | (0,0) |
| 2 | 0,1,1,2 | 1/4, 0, 0, 0 | (1/2,0) |
| 5/4 | 1,2,0,1 | 1/4, 1/3, 1/2, 2/5 | (1,1/2) |
| -1/8 | 2,2,0,0 | 1/2, 1/2, 1, 2/3 | (1,1) |

독립 과제의 양성 점수는 P6=5/4, Q6=−1/8이고 음성은 P7=2, Q7=5/4입니다. P6과 Q7만 이종 라벨 동점이어서 반 점, 다른 세 쌍은 양성이 더 낮아 0점입니다. 따라서 AUC는 $(1/2)/4=1/8$입니다. ROC의 폭 1/2인 대각 구간 아래 사다리꼴 넓이도 $(1/2)(0+1/2)/2=1/8$입니다. 실제 양성 또는 음성이 없으면 AUC는 정의되지 않습니다. 이 표의 라벨은 모두 알려진 −1/+1입니다. 다른 표에서 0이 정답 미상이면 `y == 1` 변환 전에 라벨과 점수에서 같은 행을 제외해야 하며, 미상 0을 음성으로 계산하면 안 됩니다. 이 답은 학생의 독립 문제 앞에 제공하지 않습니다.

검증 F1 기준의 후보 $2,5/4,-1/8,-1$의 F1은 각각 $0,2/5,2/3,2/3$입니다. $-1/8$과 $-1$은 모두 양성을 예측하므로 같은 ROC 좌표 $(1,1)$입니다. 미리 정한 'F1 동률이면 높은 임계값'으로 $-1/8$을 선택해 고정합니다. 동점 5/4의 P6과 Q7은 함께 바뀝니다. 이 과제는 분모 8과 각 임계값이 이진 부동소수에서 정확히 나타나도록 선택했습니다. 다른 값은 경계 반올림을 확인하고 비교 정책을 명시해야 합니다. 양성 예측이 없으면 정밀도 분모 0, 실제 양성이 없으면 TPR/재현율 분모 0, 실제 음성이 없으면 FPR 분모 0입니다. 모두 실제 음성이고 모두 음성 예측이면 F1의 분모도 0입니다. 보고 정책값은 정의 불가와 구별합니다.

**고정 후 라벨 없는 연습 입력.** R8/S8/U8의 최근값은 9,0,-1이고 학습된 최소 1·범위 8로 변환하면 1,−1/8,−1/4입니다. 고정한 임계값 −1/8에 `>=`를 적용하면 행 순서별 예측은 `[+1,+1,-1]`입니다. 동률이었던 다른 후보 −1을 적용했다면 U의 점수 −1/4도 양성이므로 U 판정이 달라집니다. 따라서 사전에 정한 동률 정책이 실제 예측에 영향을 줄 수 있으며, U를 보고 선택을 바꾸지 않습니다. R의 `bronze`는 훈련에 없으므로 ignore 설정에서 범주 열이 모두 0, S의 gold와 U의 silver는 훈련된 열을 사용합니다. 이 데이터에는 정답 열이 없어도 변환과 예측을 할 수 있으며, 최종 테스트가 아닌 연습입니다. 이 입력으로 재학습하거나 설정을 바꿨다면 고정된 예측 절차가 아닙니다.

**4. 경계·코드.** train_x에서만 encoder.fit을 하고 validation에는 transform만 합니다. P6 원본 측정을 예컨대 17→25로 바꾸면 P6 예측의 최근값은 11로 유지되고 P7은 25가 됩니다. 그 변화 후에도 훈련 중앙값 9, min 1, max 9, 범주 gold/silver는 바뀌면 안 됩니다. P7의 변환은 2→3으로 달라집니다. 코드가 검증과 훈련을 이어 붙여 fit하거나 val에서 별도로 fit하면 이를 지적하고 다시 작성하게 합니다. 같은 shape여도 범주 열의 뜻이 다를 수 있습니다.

**5. 오류 경로.** (가)는 미래에만 알 수 있는 값이 훈련 특성에 들어간 누수. (나)는 검증을 계획된 목적으로 사용하지만 되풀이한 선택으로 검증에 과대적합될 위험이며 반드시 미래 입력이 들어갔다는 뜻은 아닙니다. (다)는 보류한 최종 테스트를 선택에 사용하므로 최종 평가를 오염시킵니다. 독립 테스트 보존과 새 표본 또는 적절한 교차검증을 논의하되 교차검증에서도 fold마다 전처리를 훈련 부분에만 fit해야 합니다.

**6. 훈련 최빈 기준과 가중 비교.** 훈련 라벨 `[B,T,T,T,0,0,0,0]`에서 미상 0을 제외하면 B 1, T 3이므로 유일한 최빈은 T입니다. 이 알려진 훈련 행에만 fit하여 검증 순서 B 여섯 행, T 두 행 모두에 T를 예측합니다. T 양성 기준 TP=2, FP=6, TN=0, FN=0; 정확도 1/4, 정밀도 1/4, 재현율 1, F1 2/5입니다. 분모는 실제 B 6개와 T 2개 모두의 가능한 점수 6×1+2×4=14이고 가중점수는 8/14=4/7입니다.

U의 예측 B 여덟 개는 TP=0, FP=0, TN=6, FN=2; 정확도 3/4, 정밀도 정의 불가(0/0; 보고 정책값은 별도), 재현율 0, F1 0, 가중점수 6/14=3/7입니다. V의 예측 B 세 개 뒤 T 다섯 개는 TP=2, FP=3, TN=3, FN=0; 정확도 5/8, 정밀도 2/5, 재현율 1, F1 4/7, 가중점수 11/14입니다. 세 후보 중 정확도는 U, 재현율은 T 기준과 V가 공동, 가중점수는 V가 높습니다. 목표·공식 채점에 따라 선택하고 맞힌 행만으로 분모를 세거나 예측 종류로 가중치를 정하지 않습니다.

훈련 빈도를 B 3, T 1로 반전해 새로 fit하면 예측은 B가 됩니다. 처음 fit된 T 기준을 그대로 두고 검증 정답만 바꾸면 모델 상태와 예측은 그대로입니다. 미상 0 네 개는 이 자료의 알려진 클래스가 아니며, 수가 많다는 이유로 학습 대상이 되지 않습니다. 검증 정답을 최빈값 선택에 끼워 넣는 오류를 확인합니다.

결과뿐 아니라 시점, 범주 열 이름, 분모, 틀린 단계와 사용한 도움을 피드백합니다. 이 답안은 점수 기준을 제안할 뿐 학생의 실제 숙달을 입증하지 않습니다.
