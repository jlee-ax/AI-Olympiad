2주차 · 과거 기록에서 예측까지¶

예측하기 전에 이용할 수 있는 기록을 고르고, 훈련에서 배운 변환으로 새로운 기록을 처리합니다. 이어서 점수와 임계값, 평가 기준을 살펴봅니다.

이 노트북의 숫자와 표는 설명을 위해 새로 만든 합성 자료입니다. 실제 센서의 성능이나 사물의 관계를 뜻하지 않습니다. 앞의 2주차 교안에서 배운 훈련·검증·테스트, 평균 대체, 표준화와 혼동행렬을 활용합니다.

실행 환경: Python 3, NumPy, pandas, Matplotlib, scikit-learn 1.3 이상(sparse_output과 ROC의 첫 +∞ 임계값 지원)이 필요합니다.

앞 교안은 측정 직후에 그 측정값을 사용할 수 있었지만, 이 보충은 측정 전 예측입니다. 따라서 같은 시각의 측정은 사용할 수 없습니다. 각 자료의 계약에 따라 달라지는 것이며 서로 모순되는 규칙이 아닙니다. 앞 교안 노트북 · 앞 교안 HTML.

1. 무엇을 언제 알 수 있을까요?¶

매일 측정 전에 개체의 당일 이상 여부를 예측한다고 약속합시다. 시각을 정수 $t$로 나타냅니다. 한 예측 행은 (개체, t)입니다.

정보 예측 시점에 사용? 이유
개체 종류 예 설치 시 미리 기록됨
같은 개체의 시각 $u<t$에 도착한 측정 예 이미 관찰됨
시각 $t$의 측정, 이후의 측정 아니요 측정 전에 예측함
당일 이상 정답 아니요 예측 후에만 확인됨

정답은 +1 이상, -1 정상입니다. 각 정답은 그날 끝에 알려집니다. 예측 특성에 넣지 않습니다. 개체·시각·행 ID는 대응 관계를 확인하기 위한 식별 정보입니다. 모델의 수치 입력으로 자동 사용하지 않습니다.

이 예제의 목표는 훈련에 없던 새 개체를 이후 시점에 예측하는 것입니다. 따라서 예측 행을 만들기 전에 훈련 대상 A/B와 검증 대상 C/D를 정하고, 훈련 목표 시각은 4·5, 검증은 6·7로 나눕니다. 훈련의 정답은 시각 6 이전에 확인되었다고 가정합니다. 별도의 새 개체 E는 최종 테스트용 자리만 정해 두며, 자료나 정답은 여기에 없습니다.

새 개체 C/D의 과거 측정은 이 예측 서비스가 시각 6 전에 이미 받은 같은 개체의 라벨 없는 문맥으로 가정합니다. 이것은 A/B의 훈련 예측 행이나 fit에 넣지 않습니다. 시각 6 측정은 그날 예측 후 도착하여 시각 7 예측에는 허용됩니다. 만약 모든 시각의 예측을 시각 6 이전에 한꺼번에 제출하는 계약이라면 시각 6 측정도 사용할 수 없고 그 계약에 맞게 다시 만들어야 합니다.

목적에 따라 분할은 달라집니다. 이미 알고 있는 개체의 미래를 예측한다면 같은 개체가 훈련과 검증 양쪽에 있을 수 있지만 시간 순서를 지켜야 합니다. 처음 보는 개체를 같은 시기의 독립 자료로 평가하는 목적이라면 원본 개체를 겹치지 않게 나누되 반드시 미래 시점을 요구하는 것은 아닙니다. 이 예제처럼 새 개체의 미래가 목적일 때만 두 조건을 모두 요구합니다. 어떤 분할도 그 자체로 모든 누수를 막지는 못합니다.

2. 같은 개체의 과거로 특성을 만듭니다¶

아래 원본 측정표에는 예측 뒤에야 알게 되는 값도 보관되어 있습니다. 각 예측 행에 실제로 들어갈 값을 고를 때는 반드시 같은 개체와 측정 시각 < 예측 시각 조건을 적용합니다.

  • recent: 허용된 과거를 시간순으로 정렬해 빈 값을 forward-fill한 뒤 마지막 값을 고릅니다. 이전 관측이 전혀 없으면 결측입니다.
  • mean3, std3: 빈 값이 아닌 최근 원본 관측 세 개를 사용합니다. 빈 칸을 forward-fill한 복사값을 세 번의 관측으로 세지 않습니다. 실제 관측이 세 개 미만이면 두 값 모두 결측입니다.
  • 이전 관측 세 값이 $x_1,x_2,x_3$이면 $m=(x_1+x_2+x_3)/3$, 모집단 표준편차 $s=\sqrt{[(x_1-m)^2+(x_2-m)^2+(x_3-m)^2]/3}$입니다. 이 표준편차는 ddof=0입니다.

예를 들어 A의 시각 4 예측에서는 앞선 원본 값이 2, 4, 6이므로 recent=6, $m=4$, $s=\sqrt{8/3}$입니다. A의 시각 5 예측에서는 시각 4의 값 4까지 도착했으므로 세 관측이 4, 6, 4입니다. 평균은 $14/3$, 표준편차는 $\sqrt{8/9}$입니다. 예측 시각의 측정은 포함하지 않습니다.

def make_features(raw, targets):
    # 한 개체에 같은 시각의 기록이 둘이면 실제 도착 순서를 정해야 합니다.
    if raw.duplicated(["unit", "time"]).any():
        raise ValueError("개체와 시각이 중복됩니다.")
    rows = []
    for row in targets.itertuples(index=False):
        past = raw.loc[(raw.unit == row.unit) & (raw.time < row.time)]
        past = past.sort_values("time")  # groupby만으로 시간 정렬이 되지는 않습니다.
        filled = past.reading.ffill()
        recent = filled.iloc[-1] if len(filled) else np.nan
        last3 = past.reading.dropna().tail(3).to_numpy(dtype=float)
        mean3 = last3.mean() if len(last3) == 3 else np.nan
        std3 = last3.std(ddof=0) if len(last3) == 3 else np.nan
        rows.append({"id": row.id, "recent": recent, "mean3": mean3,
                     "std3": std3, "kind": row.kind})
    return pd.DataFrame(rows).set_index("id")

train_x = make_features(records, train_targets)
val_x = make_features(records, val_targets)

3. 훈련으로만 중앙값·범위·범주를 배웁니다¶

결측 대체·스케일과 범주 목록처럼 자료에서 배우는 규칙은 훈련 예측 행으로만 fit합니다. 검증은 이미 배운 규칙으로 transform합니다. 과거 문맥을 이용해 각 행에 값을 계산하는 것과, 검증 예측 행을 전처리 규칙 학습에 섞는 것은 다릅니다.

훈련 recent는 6, 4, 결측, 2입니다. 관측값을 정렬하면 2, 4, 6이므로 중앙값은 4입니다. 결측을 4로 바꾼 훈련의 최솟값 $a=2$, 최댓값 $b=6$입니다. $a<b$이면 최소·최대 변환은

$$x' = \frac{x-a}{b-a}.$$

예를 들어 훈련 6은 1, 검증 8은 $(8-2)/(6-2)=1.5$입니다. 기본 설정 clip=False에서 검증 값은 0~1 밖이 될 수 있습니다. 학습값이 모두 같아 $a=b$이면 이 식을 그대로 나눌 수 없으므로 도구의 상수 열 처리와 문제 조건을 따로 확인합니다. 이 방법은 앞 교안의 평균·표준편차를 쓰는 표준화와 다르며, 각 행 벡터의 길이를 1로 만드는 행 단위 정규화와도 다릅니다. 중앙값은 관측값의 순서로 정하며 관측 개수가 짝수이면 가운데 두 값의 평균입니다. 훈련 열 전체가 결측이면 중앙값을 정할 수 없으므로 별도 정책이 필요합니다.

종류 blue, red는 훈련에서 정한 두 열입니다. green은 훈련에 없으므로 기본 설정은 오류를 냅니다. handle_unknown="ignore"를 명시하면 이 특성의 해당 one-hot 열이 모두 0이 됩니다. drop=None인 이 예제에서는 알려진 두 범주 중 하나를 나타내지 않습니다. 만약 drop="first"처럼 범주 하나를 생략한다면 영벡터가 생략된 알려진 범주와 미지 범주 모두를 뜻할 수 있어 구별이 모호해집니다.

4. 점수·임계값과 ROC¶

이제 검증 행을 평가합니다. 전처리한 recent에 red 표시가 1이면 0.25를 더한 값을 정해 둔 장난감 점수로 사용합니다. 이 규칙은 모델이 학습한 것도, 실제 확률이나 성능에 대한 주장도 아닙니다. 계산된 윈도 열은 이 간단한 점수에는 사용하지 않습니다. 점수가 클수록 +1 쪽이라고 약속하고, $score\geq threshold$이면 +1로 판정합니다.

검증의 행 순서 c6,c7,d6,d7에 대한 점수는 1.5, 2.5, 0, 1.5이고 정답은 +1, -1, -1, +1입니다. 임계값 1.5에서는 동점 두 행이 함께 양성이 되어 TP=2, FP=1, TN=1, FN=0입니다. 행 수는 4이므로 정확도 $3/4$, 정밀도 $2/3$, 재현율 $2/2=1$입니다.

$$F1=\frac{2TP}{2TP+FP+FN}=\frac{4}{5},\quad TPR=\frac{TP}{TP+FN},\quad FPR=\frac{FP}{FP+TN}.$$

F1은 양성의 정밀도와 재현율을 함께 보는 지표이고 TPR은 재현율입니다. 정밀도는 양성 예측이 없으면, 재현율과 TPR은 실제 양성이 없으면, FPR은 실제 음성이 없으면 각각 분모가 0이므로 정의되지 않습니다. 위 F1 식도 분모가 0이면 정의되지 않습니다. 도구가 경고와 함께 0 또는 NaN 같은 보고값을 주더라도 수학의 정의 불가와 구분합니다.

def counts_at(y, score, threshold):
    predicted = np.where(score >= threshold, 1, -1)
    return {
        "TP": int(((y == 1) & (predicted == 1)).sum()),
        "FP": int(((y == -1) & (predicted == 1)).sum()),
        "TN": int(((y == -1) & (predicted == -1)).sum()),
        "FN": int(((y == 1) & (predicted == -1)).sum()),
    }

def ratio(numerator, denominator):
    return numerator / denominator if denominator else None  # None은 정의 불가

def rates(c):
    tp, fp, tn, fn = (c[k] for k in ("TP", "FP", "TN", "FN"))
    return {"accuracy": ratio(tp + tn, tp + fp + tn + fn),

            "F1": ratio(2*tp, 2*tp + fp + fn),
            "TPR": ratio(tp, tp + fn), "FPR": ratio(fp, fp + tn)}

ROC는 임계값을 높은 값에서 낮추면서 구한 가로축 FPR, 세로축 TPR의 점을 잇습니다. 맨 처음 $+\infty$는 모두 음성인 점입니다. 동점 1.5의 두 행은 같은 임계값에서 함께 판정되므로 그 사이에 한 행만 양성으로 바꾼 점은 이 점수 규칙의 ROC 점이 아닙니다. 그래프의 선은 계산된 점들을 연결한 것으로, 선 위의 모든 중간점이 실제 임계값에서 나온다는 뜻은 아닙니다. roc_curve는 양성 점수에 확률뿐 아니라 임계값 적용 전의 결정 점수도 받습니다. 앞 교안에서 본 ROC-AUC는 곡선 아래 면적이자 양성–음성 쌍의 순위 점수이며, 이종 라벨의 동점은 반 쌍으로 셉니다. 이 예제는 AUC가 0.5이지만 위 그래프의 모든 점이 대각선 위에 있지는 않습니다. AUC 0.5만으로 점수가 무작위 생성됐다고 판단할 수도 없습니다. 한 임계값의 F1이나 정확도 및 확률 보정과는 다릅니다. 실제 양성 또는 음성이 없는 자료에서는 각각 TPR 또는 FPR을 만들 수 없어 온전한 ROC를 해석할 수 없습니다.

임계값과 후보는 훈련과 검증 결과로 선택합니다. 같은 검증을 계속 보고 수많은 규칙을 고르면, 검증에만 우연히 잘 맞도록 선택되는 검증 과대적합이 생길 수 있습니다. 검증을 보고 선택한다는 사실만으로 즉시 금지된 누수는 아닙니다. 반면 최종 테스트나 예측 시점에 없는 미래 정보를 학습·선택에 넣으면 그 평가에 대한 누수입니다. 둘 다 새 자료의 성능을 과신하게 할 수 있지만 정보가 들어온 경로가 다릅니다. 모든 후보와 임계값을 고정한 뒤 보류한 최종 테스트로 평가합니다. 테스트 결과를 보고 다시 설정을 바꾸었다면 그 테스트는 더 이상 독립 최종 평가가 아닙니다.

5. 무엇을 맞히는 데 얼마의 가중치를 둘까요?¶

평가 기준이 정답에 따라 가중치를 달리 정할 수도 있습니다. 아래의 새 합성 표에서 실제 배경 B의 가중치는 1, 실제 대상 T의 가중치는 5입니다. 가중치는 예측이 아니라 실제 정답으로 정하며, 정답을 알기 전 예측 특성으로 쓰는 것이 아닙니다. 아래 함수의 대상 가중치는 부동소수로 나타낼 수 있는 유한한 양의 수여야 합니다.

$$\text{가중 정확도}= \frac{1\times(맞힌\ B\ 수)+5\times(맞힌\ T\ 수)} {1\times(전체\ 실제\ B\ 수)+5\times(전체\ 실제\ T\ 수)}.$$

전체 실제 정답 후보 맞힌 B 맞힌 T 전체 행 정확도 가중 정확도
B 5개, T 1개 가 5 0 $5/6$ $5/10$
B 5개, T 1개 나 3 1 $4/6$ $8/10$

분모는 맞힌 행만이 아니라 모든 평가 행의 최대 가중점수입니다. 가의 수학적 점수는 정확히 $1/2$이지만, 부동소수 계산은 합산 순서에 따라 마지막 자리가 조금 다를 수 있습니다. 아래 검사는 절대 오차가 $10^{-12}$ 이하인지 비교합니다. 이는 계산 결과의 근사 비교이며, 앞에서 정한 분류 규칙의 score >= threshold를 바꾸지 않습니다. 같은 두 후보의 순위가 기준에 따라 바뀝니다. 이것만으로 어떤 기준이 언제나 낫다고 정할 수 없습니다. 실제 문제에서는 공식 점수와 평가 단위를 확인합니다.

IOAI 2025 Radar 공식 문제는 실제 배경과 비배경을 다르게 가중해 전체 가능한 점수로 나눕니다. 위 숫자와 표는 설명을 위한 별도 합성 예이며 이 국제 문제가 국내 중등 기출이라는 뜻이 아닙니다.

훈련에서 최빈 기준 배우기¶

이번에는 별도 훈련 라벨을 B 3개, T 1개, 미상 0 5개로 둡니다. 미상 0은 이 합성 계약에서만 모르는 정답 표시이므로 B/T 빈도에서 뺍니다. 문자 B/T와 숫자 0을 NumPy 배열에 섞으면 0이 문자열 '0'으로 바뀔 수 있는데, 함수는 '0'을 숫자로 임의 변환하지 않으므로 예제처럼 dtype=object를 지정하거나 원래 목록을 전달합니다. 알려진 훈련 라벨에서 각 클래스 c의 개수를 $n_c$라 할 때 최빈 클래스는 $\operatorname{argmax}_c n_c$입니다. 모든 정답이 알려진 훈련 행에 같은 c를 예측하면 맞힌 수가 $n_c$이므로 이 알려진 행에 대한 상수 예측의 훈련 정확도가 최대인 c를 고릅니다. 이 예에서는 B입니다. B/T가 동률이면 이 예제는 학습을 중단하고, 미리 정한 동률 정책이 필요하다고 알립니다.

DummyClassifier(strategy="most_frequent")를 알려진 훈련 행에 fit한 뒤 같은 검증 여섯 행에 그대로 predict합니다. 이 기준은 훈련 X값과 정답 사이의 관계를 배우지 않습니다. 훈련과 검증의 클래스 빈도는 달라질 수 있지만 검증 정답으로 기준을 다시 정하지 않습니다. 아래 코드는 검증 정답만 바꿔도 예측이 유지되는지 보여 줍니다. 알려진 훈련 라벨이 한 종류뿐이어도 fit할 수 있지만, 보지 못한 클래스를 배운 것은 아닙니다. predict_proba의 열은 classes_를 확인하세요.

검증에서 대상 T를 양성으로 볼 때 가(모두 B)의 TP=0, FP=0, TN=5, FN=1이므로 정확도 5/6에 비해 재현율은 0, 정밀도는 0/0으로 정의되지 않습니다. zero_division=0은 이 경우의 보고값 0을 정하는 정책이고 F1은 0입니다. 나의 TP=1, FP=2, TN=3, FN=0이므로 재현율 1, 정밀도 1/3, F1 1/2이고, 가중 정확도는 표에서 8/10입니다. 어느 지표도 언제나 우월하지 않습니다. 먼저 과제의 목적과 공식 평가 기준을 확인한 뒤 비교합니다.

def weighted_accuracy(actual, predicted, target_weight=5):
    actual, predicted = np.asarray(actual), np.asarray(predicted)
    if (isinstance(target_weight, (bool, np.bool_))
            or not isinstance(target_weight, (int, float, np.integer, np.floating))):
        raise ValueError("가중치는 유한한 양의 수여야 합니다.")
    try:
        target_weight = float(target_weight)
    except (ValueError, OverflowError):
        raise ValueError("가중치는 부동소수로 표현되는 유한한 양의 수여야 합니다.") from None
    if not np.isfinite(target_weight) or target_weight <= 0:
        raise ValueError("가중치는 유한한 양의 수여야 합니다.")
    if (actual.ndim != 1 or actual.shape != predicted.shape or len(actual) == 0
            or not np.isin(actual, ["B", "T"]).all()
            or not np.isin(predicted, ["B", "T"]).all()):
        raise ValueError("같은 길이의 B/T 정답과 예측이 필요합니다.")
    weights = np.where(actual == "T", target_weight, 1.0)  # 실제 정답 기준
    # 모든 가중치를 같은 수로 나눠도 점수는 같고, 큰 수의 합이 넘치는 것을 줄입니다.
    weights = weights / weights.max()
    return float(np.sum(weights * (actual == predicted)) / np.sum(weights))

from sklearn.dummy import DummyClassifier
from sklearn.metrics import precision_recall_fscore_support


def fit_known_mode(raw_labels):
    # 이 합성 자료에서 0은 미상이고 Boolean은 받지 않습니다. 동률이면 중단합니다.
    raw = np.asarray(raw_labels, dtype=object)
    if (raw.ndim != 1 or any(isinstance(v, (bool, np.bool_)) for v in raw.flat)
            or not np.isin(raw, np.array(["B", "T", 0], dtype=object)).all()):
        raise ValueError("이 예제의 훈련 라벨은 B/T/0이어야 합니다.")
    known_mask = np.isin(raw, ["B", "T"])
    known = raw[known_mask].astype(str)
    if len(known) == 0:
        raise ValueError("알려진 훈련 라벨이 없습니다.")
    classes, counts = np.unique(known, return_counts=True)
    if np.count_nonzero(counts == counts.max()) != 1:
        raise ValueError("최빈 동률: 먼저 동률 정책을 정하세요.")
    chosen = classes[np.argmax(counts)]
    # Dummy는 X의 값과 정답 사이의 관계를 학습하지 않습니다.
    training_x = np.arange(len(raw)).reshape(-1, 1)
    model = DummyClassifier(strategy="most_frequent")
    model.fit(training_x[known_mask], known)
    return model, chosen, known_mask

아래는 예측 대상 행과 사후에 확인할 정답입니다. 정답의 값은 그룹·시각 분할을 정하는 데 사용하지 않으며 예측 특성으로도 사용하지 않습니다. 선택한 검증 행의 정답은 예측 점수를 만든 뒤 임계값 평가·선택에만 사용하고 훈련이나 전처리 fit에 넣지 않습니다. 각 정답은 해당 시각의 예측 후 그날 끝에 도착하고, 시각 5의 정답은 시각 6 전에 알려진다고 가정합니다.

대상 행 M4 M5 N4 N5 P6 P7 Q6 Q7
사후 정답 -1 +1 -1 +1 +1 -1 +1 -1

본문 6절의 두 명세에서 분할을 설계한 뒤, 이 보충에서는 과거 특성과 변환에 집중합니다. 시각 6 전에 학습을 끝내고 그때까지 훈련에 없던 새 개체의 시각 6·7을 순차 예측합니다. 여기서는 M4/M5/N4/N5를 훈련, P6/P7/Q6/Q7을 검증으로 사용합니다. 각 개체의 허용된 과거는 라벨 없는 문맥으로 쓸 수 있지만 훈련 대상 행이나 전처리 fit에 자동으로 들어가지는 않습니다. 최종 테스트의 새 개체와 정답은 생성되지 않았습니다.

  1. 점수는 변환한 recent 자체이고 클수록 양성입니다. 이 연습의 점수와 임계값은 이진 부동소수로 정확히 표현할 수 있도록 정했습니다. 다른 자료의 경계는 부동소수 오차를 확인하고 비교 정책을 정해야 합니다. 점수가 임계값 이상이면 양성입니다. 임계값 $2$, $5/4$, $-1/8$에서 TP/FP/TN/FN, 정확도·정밀도·재현율·F1, FPR/TPR을 구하세요. ROC 좌표를 임계값이 높은 순으로 적어 가로축 FPR, 세로축 TPR에 그린 뒤 동점이 한 번에 바뀌는지 확인하세요. 실제 양성 또는 음성이 없는 표와 양성 예측이 없는 표에서 어떤 분모가 0인지 쓰세요. 그린 ROC의 사다리꼴 면적과 양성–음성 점수 네 쌍의 순위 점수를 각각 구하세요. 양성 점수가 높으면 1, 같으면 1/2, 낮으면 0으로 세고 두 방법의 결과를 비교하세요. roc_auc_score((y == 1).astype(int), scores)와 auc(fpr, tpr)로도 확인하세요. 이 과제의 정답은 알려진 −1/+1뿐입니다. 다른 자료에서 0이 정답 미상이라면 먼저 그 행을 정답과 점수에서 함께 제외한 뒤 계산하며, 0을 음성으로 바꾸지 않습니다. 실제 양성이나 음성이 없을 때 왜 AUC가 정의되지 않는지 설명하세요.

    이제 후보 임계값은 $2$, $5/4$, $-1/8$, $-1$이며 검증 F1이 가장 큰 값을 고릅니다. F1이 같으면 더 높은 임계값을 고른다는 기준을 미리 정합니다. $-1$에서 달라지는 예측이 있는지 먼저 확인하고, 선택한 임계값과 이유를 적은 뒤 고정하세요. 같은 예측을 만드는 두 임계값은 ROC의 서로 다른 새 좌표를 만들지 않습니다. 점수를 고정하고 임계값만 바꿀 때 AUC와 F1 중 무엇이 달라질 수 있는지도 설명하세요. 이 선택은 검증용 정답으로만 하고 최종 테스트는 사용하지 않습니다.
