# 학생 교안 정리와 2주 선수 내용 보완

## 변경과 기준

기존 2주 학생 노트북과 HTML에서 수업·자습 시간 배정, 실측 상태와 운영 설명을 제거했다. 같은 내용이 생성기에서 다시 나타나지 않게 수정했다. 앞서 별도로 작성한 1주 보충 학생본에도 운영 시간 문구가 있어 함께 제거했다. 예측 시점·관측 시각 같은 학습 개념과 최종 테스트를 모델 선택 후 평가한다는 원리는 남겼다. 교사용 계획·기존 1주 본 교안과 별도 미커밋 사용자 작업본은 변경하지 않았다.

[원문·우선순위 검토](prioritization.md)는 기존 10주 계획과 17개 요구 기록을 읽고 2주 실물의 설명과 자습 목록을 대조했다. 평균·표준화, 기본 그룹 분할과 혼동행렬을 다시 만드는 대신, 실제 설명·실행·독립 평가가 부족했던 **과거 관측의 특성화 → 학습형 전처리 → 점수와 평가 기준**을 우선했다. 과거 국제 문제는 교육적 전이 근거이며 KOAI 2027 중등 기출이라는 주장이 아니다.

[새 학생 노트북](../../lessons/week02/week02_temporal_preprocessing.ipynb)과 [HTML](../../lessons/week02/week02_temporal_preprocessing.html)은 개체와 예측 시점을 명시하고, 허용된 과거의 forward-fill·최근 관측 윈도, 중앙값·최소최대 변환과 미지 범주, ROC와 동점·0분모, 누수와 검증 과대적합, 실제 정답에 따른 가중점수와 순위 변화를 연결한다. 새 합성 입력의 손계산·코드 과제와 [별도 교사용 해설](../../lessons/week02/week02_temporal_preprocessing_teacher.md)이 있다. 교사용 해설이 같은 저장소에 있다는 사실만으로 학생 접근이 제한되는 것은 아니다. 이 자료는 기존 2주 자습 항목과 연결하며, 실제 완수 시간이나 학생 성취는 아직 관찰하지 않았다.

## 검증 결과

- 기존 시스템 회귀 255개가 통과했다. 수정 교안의 실제 기능은 별도로 확인했다.
- 두 기존 학생본은 생성된 HTML이 노트북과 일치했고, 생성기를 임시 사본에서 다시 실행해 시간 배정이 재생성되지 않음을 확인했다. 기존 1주 보충의 코드 13셀과 기존 2주의 코드 8셀을 새 실행 상태에서 다시 실행했다.
- 새 노트북은 19셀 중 예제 코드 8셀을 실행하고 표 출력과 ROC PNG를 저장했다. 독립 답안 코드셀 1개는 비어 있다. [실행·유한 사례 검증](../../lessons/week02/week02_temporal_preprocessing_validation.json)과 [독립 검토](independent/)를 구분해 기록했다.
- 독립 검토는 새 입력의 손계산과 10개 정상 시나리오, 원본 순서 변경, 같은 개체의 허용된 과거·미래·다른 개체의 오염, 훈련 통계, 미지 범주, 동점 ROC, 정답 기준 가중 분모를 확인했다. 의도적 오류 14개 가운데 12개는 학생본의 단언이, 2개는 독립 검토의 새 입력 oracle이 탐지했다.
- 독립 검토 중 MinMax 경계의 부동소수 비교, ROC 첫 임계값의 scikit-learn 최소 버전, 비유한 가중치와 역순 합산의 미세 오차 문제를 찾아 수정·재검증했다. 분류 임계값의 `>=` 규칙은 그대로다.
- 세 학생 노트북의 HTML을 현재 노트북에서 다시 내보낸 결과와 대조해 일치를 확인했다. 저장된 ROC 이미지는 축과 표식을 직접 확인했다. 이전 노트북 해시에 묶인 발견 세션의 `artifact_changed`와 새 해시에 결합한 후속 검토는 [discovery 기록](discovery/)에 각각 보존한다.

## 남은 범위와 실행 환경

일반 Jupyter 소켓 커널은 이 환경의 소켓 제한으로 검증할 수 없어 새 in-process IPython 실행으로 대체했다. 브라우저의 로컬 파일 URL 제한으로 HTML 전체 화면은 열지 못했으며 외부 MathJax 접근도 확인하지 못했다. 그림 이미지 확인과 HTML의 구조·재생성 확인은 화면 전체의 시각 검토와 다르다. 실제 학생 답안·도움·소요시간·학습효과 및 비공개 최종 테스트는 미관찰이다.

원래 10주 요구를 줄여 닫지 않았고, 새 교안의 부분적 진전과 전체 범위는 [발견 검토](discovery/)에서 구분한다. 후속 주차의 실제 교안·평가와 국내·국제 2027 범위 관계는 여전히 확인이 필요하다. 기존 2주의 `validation.json`은 과거 실행 기록이며 이번 재검증 근거는 새 독립 기록에 둔다.
