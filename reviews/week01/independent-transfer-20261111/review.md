## 실제 교안 보완

기존 87개 셀을 모두 살펴본 변경 전 검토에서 적절한 평균·분산 설명, 축과 단위, 함수·결측 기초는 유지할 근거가 있었다. 그 검토가 지적한 실행 가능한 빈틈을 이번 교안과 교사용 해설에 다음과 같이 보완했다.

- **오류 진단과 입력 계약:** 실제 `IndexError` traceback의 실패·호출 위치를 읽고 고친다. 평균 함수의 기존 “모든 유한 값” 주장은 `[1e308, 1e308]`의 overflow 반례가 있어 길이·숫자 종류·값 범위를 명시한 계약으로 좁혔다. 이는 임의 크기의 유한 float를 처리하도록 코드를 고친 것이 아니다.
- **새 입력의 설명과 계산:** 새 표의 좌표와 2시간 이동, 인과 해석의 한계, 행·열 broadcasting과 호환되지 않는 shape, 새 값에 대한 분산의 이동·배율·단위를 묻는다. 학생이 도움 여부를 기록할 수 있다.
- **자료 처리와 순서:** 실제 입력 복사본에 `20ml` 문자열을 넣어 단위 확인과 결측 보존을 연습한다. 별도 복사본의 높이 결측에서 전체 행 수와 관측 개수를 구분한다. 누락·중복 병합 키를 예측하고 검증한다. 내적에서는 배열 길이가 같아도 항목 순서가 다르면 다른 답이 됨을 확인한다.
- **해설과 배치:** 각 과제의 답·오류 원인·후속 확인을 교사용 메모에 추가했다. traceback과 새 그래프 확인은 기존 120분의 해당 블록에 배치하고 A–E는 수업 밖으로 유지했다. 다만 실제 수업 가능 시간과 수정된 숙제 소요 시간은 측정하지 않았다.

## 기준과 관찰 범위

[2027 공식 안내](https://kitpa.org/koai/2027)는 중등부·고등부의 네 과목과 필기·코딩 시험을 설명한다. 연결된 [공식 출제 기준](https://kitpa.org/koai/syllabus)은 IOAI 2026으로 표시되어 있으며 1-1은 Python·NumPy/Pandas·시각화 등의 활용, 1-4는 데이터 전처리와 통계적 모멘트 기반 특성을 다룬다. [2026 예시 공지](https://kitpa.org/files/36)와 [원본 PDF](https://kitpa.org/storage/c4016751-0e2c-4548-ab70-ecec994e8f8d.pdf)는 고등부 학습 참고용이며, 2027 중등부 기출이나 난도 분포가 아니다.

[출처 비교표](source-brief.md)는 공식 예시가 실제 요구하는 것과 1주차의 관련 기초를 구분한다. 예를 들어 예시의 Python 상태 문제는 traceback 수정을 직접 요구하지 않고, KNN 입출력 문제는 join을 요구하지 않는다. 1주차 과제는 이후 문제 해결을 위한 단계이지 해당 예시 전체나 KNN 구현을 완료했다는 뜻이 아니다.

[그래프](graph.json)와 [경로](paths.json)는 traceback·그래프 좌표·broadcasting·분산·병합의 다섯 비교에 한정된다. 각 경로에 출처→요구→선수→설명→실습→평가→피드백의 선언과 로컬 파일 위치·해시를 연결했으며, 피드백에서 재시도로 가는 관계는 제안된 경로이지 실제 학생 재시도의 증거가 아니다. 문자열 입력·결측 집계·내적 순서 세 과제는 다섯 비교 목표 바깥에서 별도 검토했으며, 결측 집계는 merge 문항과 노트북 셀을 공유한다. 결측 집계 앞에는 집계 예제가 제공되므로 완전한 독립 평가라고 부르지 않는다. 새 그래프 문항도 완성된 낯선 그래프를 독립 판독하는 평가까지는 아니다.
