# 수정 교안의 별도 검토 — 2026-11-11

검토 범위는 1주차의 traceback, 새 표에서 그래프 좌표 구성·이동, broadcasting, 분산, 병합, 문자열 입력, 결측 집계 및 내적 순서 과제와 교사용 해설이다. 실제 노트북 SHA-256 `ee8279b1af621c22da5094d765ea424171c5448527d931b943a6a30cb7c2f6b7`, 교사용 해설 SHA-256 `bb2c8e3777dac240197fa422e8ca067379ca038dc81a2a2e35c82e4b7c41b8ec`을 확인했다. 별도 검토 에이전트에는 GPT-6.1 Terra와 Max 추론을 지정했다. 런타임 모델 식별이나 판단의 독립성을 파일 해시로 인증할 수는 없다.

| 항목 | 독립 확인과 범위 |
|---|---|
| traceback | 실제 예제를 실행해 `IndexError`, 호출 줄 4와 실패 줄 2를 확인했다. 두 수정안은 [2,4,6]과 [9]에서 각각 마지막 값을 반환한다. 빈 목록은 이 과제의 계약 밖이다. |
| 그래프 | 실제 새 CSV에서 Q02=(2h,9cm), Q04=(5h,14cm), 2h 이동 후 (4h,9cm), (7h,14cm)을 확인했다. 인과관계의 한계도 적절하다. 이 문항은 새 표에서 좌표를 구성·이동하는 과제이며, 이미 그려진 낯선 그래프의 독립 판독은 검증하지 않는다. |
| broadcasting | 열별 38, 행별 208과 길이 2의 오류를 별도 실행했다. (3,)과 (1,3)은 모두 유효하고 명시적으로 확장한 (2,3)도 계산된다. 교사용 해설이 각 경우를 구별해 수용한다. |
| 분산 | 원래 [1,3,8]의 평균 4, 분산 26/3, 2를 더한 평균 6·분산 26/3, 원래 값의 2배에 대한 평균 8·분산 104/3을 확인했다. 단위는 각각 cm, cm²이다. 해당 과제의 설계와 계산에 대한 검토이며 학생의 독립 수행은 미관찰이다. |
| 병합 | Q02=옥상인 복사본에서 미매칭 4행/Q02 결측, 중복 키 검증의 MergeError, 검증 없이 5행을 확인했다. 원래 화분 표를 다시 쓰면 6행이라는 인접 반례를 추가로 확인했으며, 수정된 문제는 첫 복사본을 유지한다고 명시한다. |

검토 중 두 결함을 찾아 수정했다. 병합 문제의 두 번째 입력 상태가 모호해 5행과 6행이 모두 가능했으므로 어떤 복사본을 유지하는지 명확히 했다. 또한 기존 평균 함수는 모든 유한 실수 목록을 허용한다고 적었으나 `[1e308,1e308]`에서 합계가 무한대로 넘쳤다. 정상 값·목록 길이와 보정량 범위, float 반올림 및 범위·자료형을 따로 검사하지 않는다는 조건을 명시하고 길이 10,000·양수/음수 경계·교대값·보정량·빈 입력을 확인했다. 보정량도 Python 정수 또는 유한 float로 제한하며 Decimal은 계약 밖임을 확인했다. 이는 계약을 좁힌 것이며 임의의 유한 float에 대한 overflow를 해결했다고 주장하지 않는다.

2027 공식 안내는 중등부에도 네 과목 전체의 필기·코딩을 명시한다. 연결된 syllabus는 IOAI 2026으로 표기돼 있다. 2026 예시문항은 고등부 학습 참고 자료다. 배열/함수 과제는 예시의 축 조작·KNN 구현을 위한 부분적인 기초이며 해당 문제의 완성이나 2027 중등부 난도의 증거가 아니다. 교육과정상 표준화(2주차), KNN(4주차), 텐서(6주차)의 후속 실제 교안·평가는 이번 범위에서 확인하지 않았다.

필기·진단·새 좌표 문항은 기존 수업 블록에, A–E는 수업 밖에 둔다. 120분 편성의 산술은 검증됐지만 실제 수업 완수 시간과 수정된 숙제 시간은 미관찰이다. 답을 가리고 도움을 기록하라고 지시하나 교사용 키는 저장소에서 접근할 수 있다. 학생의 첫 응답·실제 도움·독립 성취·교육자 보정은 관찰되지 않았다.

주 실행자의 [validation.json](../../../lessons/week01/validation.json)은 새 in-process 커널의 28개 코드 셀·오류 0을 기록하며, 학생 코드 칸은 비어 있다. 별도 검토자의 전체 커널 시도는 읽기 전용 환경에서 IPython 임시 디렉터리 생성이 막혀 시작 전에 실패했다. 위 항목의 표적 계산·반례는 별도로 실행했다. 품질 종합 상태는 여전히 uncertain이며 전체 교안 수용이나 학습 효과를 주장하지 않는다.

최종 출처·경로 재검토에서 2026 예시의 요구와 1주차 기초 목표를 별도로 표기한 점을 확인했다. 예시 1은 traceback 수정, 서술형 2는 join을 직접 요구하지 않는다. 예시 서술형 2는 KNN 거리 계산의 broadcasting 사용을 권장한다. 분산 관련 syllabus 근거는 1-4의 통계적 모멘트로 바로잡았고, 이론 위치에는 크기 배율 설명과 공통 이동 시 편차 상쇄를 설명하는 피드백 셀을 함께 기재했다. 경로·피드백 설계의 검토와 학생의 실제 수행은 별개다.

## 추가 세 과제의 별도 검토

| 항목 | 독립 계산과 범위 |
|---|---|
| 문자열 입력 | 실제 입력 셀에서 P02는 `20ml`, P03은 결측이다. 원문자 그대로 수치 변환하면 ValueError이며, P02의 확인된 단위만 복사본에서 분리하면 관측 5개·합 140ml·평균 28ml이고 P03은 결측으로 남는다. `errors="coerce"`로 원문자를 무조건 결측 처리하면 관측 4개·평균 30ml가 되는 반례를 실행했다. 원본은 보존된다. |
| 결측 높이 | Q02 높이만 결측인 별도 복사본은 실내 전체 행 2개·관측 1개·평균 7cm이며 원본 Q02는 9cm다. 실내 높이가 모두 결측인 인접 사례는 전체 2개·관측 0개·평균 결측이다. 위에 groupby 예시가 제공되므로 새 입력을 이용한 안내 연습이며 관찰된 독립 수행이 아니다. |
| 내적 순서 | A,B,C로 맞춘 내적은 5,200원, 같은 길이의 B,C,A 단가를 그대로 곱하면 6,900원이다. 교사용 후속 반례의 맞춘 값 16원도 독립 계산했다. 이름과 배열 순서를 맞추는 설계 확인이며 학생 응답은 미관찰이다. |

추가 세 과제는 위 다섯 개의 공식 예시 비교 목표에 포함되지 않으며, 이 보충 검토와 실행 결과로 별도 기록한다. 결측 높이 문항은 merge 문항과 노트북 셀을 공유한다. 학생 답을 채우거나 성취를 주장하지 않는다.
