# 1주 시퀀스 조회와 유효 평균 개선

## 선택과 현재 범위

기준 원격 lesson은 `dd39ed5f80eee2d8d719483085906b25371c2c37`이고 안전한 로컬 기준 tree는 `668a75b6641fdc7c91dfef93ee176089df82b7f1`이다. 기존 1주 bridge의 조회 예는 올바르지만 V=T=3인 우연한 크기와 독립 lookup/PAD 평균 문제의 부재가 있었다. 과거의 표·코사인 검색을 다시 제작하지 않고 기존 선택 조회를 확장해 **ID → (B,T,d) 벡터 → 유효 위치 합/개수 → 기존 필수 B의 질문 벡터**로 연결했다. V/T/d/B는 각각 다른 크기의 예로 설명한다. 이는 학생 실패의 관찰이 아니다.

공식 대회와 전공 문서의 읽은 범위 및 역순위·Pixel 좌표와의 우선순위 비교는 [편집 전 원문·선정 기록](source-prioritization.md)에 있다. 고정 예는 토크나이저·attention·학습된 인코더나 국제 과제를 실행하지 않는다. 실제 텍스트·모델은 8주, 오디오는 9주, 새 과제는 10주로 남기며 실제 3–10주 교안과 성취를 확보했다고 보지 않는다.

## 교안 변화

각 위치의 조회 `H[b,t,j]=E[I[b,t],j]`와 `sum(m*H)/sum(m)`을 손계산·(B,T,1) 마스크·위치 축 합·코드에 연결한다. PAD는 이 합성 명세의 ID 0으로 구분한다. 0이 아닌 PAD 벡터는 제외하고, 벡터가 0인 유효 토큰은 분모에 포함하며, 반복 토큰은 위치마다 센다. 음수/범위 밖 ID와 전체 PAD를 이 예의 오류로 알린다. 유효 영평균은 성립하지만 그것을 코사인 방향으로 쓰는 것은 별도 조건이다.

고정 조회벡터 평균은 순서를 잃을 수 있다는 한계를 보인다. 이는 attention/causal mask나 위치·문맥을 쓰는 모든 모델의 성질이 아니다. 기존 필수 B의 입력을 생성한 후 내적·코사인·ID 복원을 그대로 이어 간다. PAD 벡터를 0으로 바꾸고 전체 T로 잘못 나누면 질문 평균은 틀리지만 각 행이 양의 배수여서 코사인/최종 ID만으로는 오류를 놓치는 반례를 점검한다. 필수 A/B·기존 통합 기기 문제·원본 A–E와 교사용 안내를 유지한다.

초안 `f3f739cf…`은 전체 실행 후 독립 검토에서 핵심 평균과 방어 코드의 설명 구분이 더 필요하다는 의견이 나왔다. 최종 bridge `16b797de…`는 수식과 `np.where`/위치 축 합/분모 및 입력 검사·`dtype=object`/`errstate`의 역할을 짧게 구분한다. 코드/출력은 그대로이며 초안 기록은 보존했다. [초안·최종 비교와 작성 기록](author/author-record.md).
