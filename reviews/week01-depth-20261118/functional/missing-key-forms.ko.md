# 빈 키 표현 두 가지에 대한 추가 검산

이 두 사례는 2회차 교사용 풀이가 미연결 기록 이름을 알려 준다는 설명을 확인한다. 앞서 시행한 13개 공개 대조의 결과는 각각의 기록에 보존했다. [기존 대조](README.ko.md)

|입력|기대하는 교사용 진단|2회차에서 관찰한 동작|3회차에서 관찰한 동작|
|---|---|---|---|
|실제 CSV의 8개 `station` 필드를 모두 비운 뒤 `pd.read_csv`로 읽음|미연결 관찰 이름 T1–T8을 알림|pandas가 왼쪽 키를 `float64`로 읽었다. 서로 다른 자료형을 병합하려는 오류가 먼저 발생하여 기록 이름은 하나도 보고되지 않았다.|자료형을 맞춘 뒤 미연결 기록 T1, T2, T3, T4, T5, T6, T7, T8을 모두 알렸다.|
|읽은 표에서 T1의 왼쪽 키를 빈 문자열로 고치고 오른쪽 표에 빈 문자열·East 한 행을 추가|T1을 미연결 관찰로 알림|두 빈 문자열이 같다는 이유로 T1에 East가 붙었다.|T1을 미연결 기록으로 알렸다.|

입력은 공개 수거 일지와 구역표에서 만들었다. 첫 사례는 실제 임시 CSV를 저장한 뒤 다시 연다. 두 번째 사례는 수업에서 학생에게 시키는 방식대로 읽은 표의 값을 직접 바꾼다. 각 보고서에는 해설·자료·기록한 노트북의 SHA-256과 오류 문구 또는 반환된 구역이 들어 있다. [2회차 실행 결과](missing-key-forms-0002.json) · [3회차 실행 결과](missing-key-forms-0003.json)

저장소 루트에서 Python 3.12와 pandas 2.2.3을 사용한다. 2회차 명령은 두 사례의 실패를 재현하여 종료 코드 1을 반환한다. 3회차는 두 경우에 필요한 기록 이름을 모두 확인하여 종료 코드 0을 반환한다. [재현 코드](check_missing_key_forms.py)

```console
python3 -B reviews/week01-depth-20261118/functional/check_missing_key_forms.py --root . --round 2
python3 -B reviews/week01-depth-20261118/functional/check_missing_key_forms.py --root . --round 3
```
