## 어떤 깊이를 요구했나

대상은 Python 기초를 접했고 AI 선행학습이 없는 중학생이다. 국내 2027 중등부 요강과 출제 기준의 필기·실기 구분, 기존 10주 편성을 먼저 확인했다. IOAI 2025 Antique에서 관측 가능한 특성과 알려진 라벨을 구별하는 능력을 추출했다. 국내 2026 공개 예시는 주최 측이 명시한 고등부 학습 참고 자료로 다뤘다. 대회가 각 주차의 시수나 개별 예제의 난도를 정한 근거는 없다. [원문별 근거와 한계](joined/source-review.md) · [4단원 편성 근거](scope.md)

| 단원 | 학생이 새 자료에서 보여 줄 것 | 이번 주의 깊이와 편성 |
| --- | --- | --- |
| Python | 반복 중 값과 실제 반환값을 예측하고, 호출 위치와 멈춘 연산을 찾아 함수를 수정한다. 빈 목록·0·경계를 새로 넣는다. | 상태 변화와 오류 복구까지. 인터프리터 구현은 후속 과제가 아니다. 수업 20분·자습 90분. |

수업 120분, 필수 자습 360분은 편성 추정이다. 첫 기준안에는 Python 코드를 직접 고치는 요구와 분포 그림이 충분히 명시되지 않아 반려했다. 고친 기준과 독립 검토를 Git에 먼저 고정한 뒤 첫 원고를 보관했다. 기준 커밋에 있는 1주차 노트북 네 개를 보존했다. 새 원고에서 공백을 정리한 길이가 100자 이상인 셀 55개를 네 노트북의 같은 길이 이상 셀과 대조했고, 전체 텍스트가 일치한 셀은 0개였다. ## 실제로 실행한 검증

- **학습 과제와 답안.** 학생 폴더에 원고와 CSV 세 개만 두고 새 Jupyter 커널에서 28개 코드 셀을 실행했다. 그림 3개를 렌더링했고, HTML에는 첫 시도 칸 뒤에 접힌 힌트 두 개가 있다. 교사용 풀이 7개 코드 블록도 실행했다. 노트북의 빈 독립 풀이 칸은 학생이 직접 쓸 자리다. 두 번째 파일에서 열·그림을 직접 선택할 수 있는지 별도 판정했다. [커널 실행 기록](rounds/0003/kernel.json) · [재현 프로그램](execute_lesson.py)
- **독립 입력·정답.** 미리 봉인한 다른 입력에서 3×2 배열의 두 축 평균은 각각 `[4,4]`, `[5,4,3]`이었다. 새 표에서 결측 하나를 10으로 바꾸자 유효 관측 수가 5→6, 전체 평균이 4→5로 바뀌었다. 독립 검토자가 이 값과 분산·히스토그램까지 재계산했다. 8개 기준의 원고 점수는 14→15→16점(만점 16점)이었다. [계산·그림·기준별 점수](independent/round-0003.json)
- **정상 및 오류 입력.** 표 검사 13건과 추가 2건을 모두 통과했다. 점심 기준 4권→6권에서 West의 관측 수는 3→2, 하교 평균은 13/3→3이 됐다. East의 0권은 관측 한 건으로 남았다. 반납함 이름이 모두 빈 실제 CSV는 T1~T8을 정확히 보고한다. [13건 상세](functional/round-0003.json) · [두 결측 검사](functional/missing-key-forms-0003.json)
- **반복 보정 장치.** 초안 작성 전 기준 확정, 단원별 최소·상한·선수·시간, 실제 평가 셀과 교사용 풀이·데이터, 각 회차의 변경 이유와 대안을 연결했다. 이미 통과한 셀도 내용이나 의존 자료가 바뀌면 재검토하며 판정 충돌·증거 누락·무검토 수정을 차단한다. 원고와 답지를 따로 고친 경우, 동일 내용의 중복 회차, 무관한 자료 변경, 수정 뒤 재개를 포함해 전용 검사 25건과 저장소 전체 회귀 316건이 통과했다. [사용 방법](../../tools/topic-depth.md) · [회귀 결과와 실행 환경](regression.txt) · [GitHub 자동 검사 정의](../../.github/workflows/topic-depth.yml)
- **기존 시스템과 대조.** 원문의 네 요구를 자료→선수→설명→활동→독립 평가→피드백으로 연결했다. 그래프 근거 28건과 실제 로컬 파일 연결 24건이 일치했다. 기존 품질 항목 16개 중 15개가 통과했고, 전체 과정의 우선순위에 관한 운영 합의(K14)는 미확정으로 남아 기존 통합 절차는 보류 상태다. [통합 대조](joined/) · [재실행 코드](joined/verify.py)
- **NVIDIA SkillEvaluator.** 공식 원본에서 엄격 검수와 12쌍의 과제 준비, 외부 답변 24건의 채점 재생과 측정치 가져오기를 실행했다. 교육 사례 11개에서 스킬 사용·미사용 양쪽 모두 11/11로 관측 차이는 0%p였다. 네이티브 모델 실행은 공급자·격리 실행기 제약으로 0회였다. [조건·원본 결과·실행 한계](calibration/README.ko.md)

## 재현

저장소 루트에서 아래 명령을 실행한다. Git에는 기준 동결 커밋까지의 이력이 필요하다. Jupyter 및 데이터 라이브러리 버전은 커널 기록과 자동 검사 정의에 있다. 독립 입력과 판정은 이 기록 공개 이후에는 공개 회귀 자료다.

```sh
case_dir=reviews/week01-depth-20261118
python -B tools/topic_depth.py check --root .
python -B "$case_dir/functional/check_public_tables.py" --round 3
python -B "$case_dir/functional/check_missing_key_forms.py" --round 3
python -B "$case_dir/independent/verify_round3.py" "$case_dir/rounds/0003"
python -B "$case_dir/execute_lesson.py" lessons/week01/week01_foundations.ipynb --data lessons/week01/data --report /tmp/week01-kernel.json --transport subprocess
python -B -m unittest discover -s tests -q
```

이번 로컬 환경은 ZeroMQ 소켓 바인딩을 제한해 별도 파이썬 프로세스 안에서 실제 IPython 커널의 in-process 전송으로 실행했다. 같은 조건을 쓸 때는 위 커널 명령에 `--transport inprocess`를 지정한다. 316건 전체 재현에는 회귀 기록에 적은 NVIDIA 도구 설치가 필요하다. 교안 자체와 검토자가 푼 새 입력의 결과를 확인했다. 실제 중학생의 독립 완수율·소요 시간·시험 성적은 측정하지 않았다.
