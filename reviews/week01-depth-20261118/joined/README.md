## 수정과 재검증

1. 첫 번째 후보에는 오류 이름만 확인하는 활동, 축 평균의 누적 과정 누락, 그림 종류를 과제에서 먼저 지정하는 문제가 있었다. 두 번째 후보는 실제 traceback, 한 열의 누계와 분모, 도움 전 첫 시도와 접힌 실마리를 추가했다. [1차 판정](../rounds/0001/reviews/joined.json) · [2차 판정](../rounds/0002/reviews/joined.json)
2. 두 번째 후보는 일부만 결측인 키와 미등록 이름을 처리했다. 이후 실제 파일 전체에서 반납함 이름을 지우자 pandas의 자료형 충돌로 관찰 ID가 나오지 않았다. 두 표에 빈 문자열을 넣으면 구역이 잘못 배정됐다. 세 번째 후보는 읽기와 병합에서 문자 식별자·빈 필드 의미를 보존하며 두 결함을 고쳤다. 같은 다섯 사례에서 2차는 두 건 실패, 3차는 다섯 건 통과했다. [2차 추가 검사](round02-physical-keys.json) · [3차 동일 검사](physical-keys.json)
3. 공개 노트북의 28개 코드 셀과 교사용 Python 블록 7개를 실행했다. 별도의 계산으로 그룹 구성·분모·실제 그림 막대와 레이아웃을 대조했다. 등록 CSV만 둔 새 Jupyter 커널에서도 28개 코드 셀 및 예제 그림 세 개의 실행 기록이 있다. 이 검토는 공개 자료만 사용했다. [공개 교재 실행](public-results.json) · [Jupyter 커널 기록](../rounds/0003/kernel.json)

## 판정과 재실행

|검사|최종 결과|
|---|---|

|공식 범위·실제 기출 대조|출처 발견 `recorded_ready`, 네 주제 모두 `covered`. 교재 깊이 `recorded_met`, 네 비교와 필기 형식 일치. 국내의 고등부 공개 예시·국제 실제 과제의 적용 한계를 비교별로 기록했다.|
|학습 경로|구조 검사 오류·경고 0. 네 경로 × 일곱 역할의 바이트 연결 28개가 유효하다. 교사용 답·피드백·독립 과제에 대한 별도 판독은 네 경로에서 `recorded_design_met`, 근거 24개가 유효하다.|

|통합 preflight|로컬 해시 연결 24개가 모두 일치했다. 차단 사유는 `quality_not_ready`와 `workflow_pause`다. 이 교재 및 발견·평가 기록에는 `synthetic=false`가 적용된다. 수업용 반납 자료는 가상 예제로 명시돼 있다.|

국내 KITPA의 2027 중등부 요강과 연결된 실라버스, 국제 IOAI 원본 및 2025 개인전 5번 *Antique*의 원문을 검토했다. 국내에서 연결하는 실라버스는 IOAI 2026 표기다. 국제 2027 문서도 별도로 확인했다. *Antique*에서 라벨 0이 미상을 뜻한다는 점은 코드북·특성·목표를 배우는 근거가 된다. 국내 중등부의 출제 빈도나 해당 국제 과제 전체의 숙달은 이 자료로 판정할 수 없다. [원문 링크와 조사 범위](source-review.md) · [발견 사건 18개](discovery.json)

저장소 루트에서 다음 명령을 실행한다. 첫 명령은 실제 CLI들의 종료 코드와 판정, 각 stdout 해시를 출력한다. preflight의 차단 상태를 그대로 전달하여 현재 전체 종료 코드는 1이다. 발견 이력의 교안 대조 13건에 들어 있는 원문 구간 52개도 각각 당시 보관된 후보의 바이트와 비교한다.

```sh
python3 -B reviews/week01-depth-20261118/joined/verify.py
```

공개 데이터 재실행에는 Python 3.12와 NumPy, pandas, Matplotlib, Seaborn이 필요하다. 커널·공개 실행 결과에는 사용한 패키지 버전을 기록했다. 아래 명령은 도표 렌더링과 CSV 직렬화를 위해 임시 저장 공간을 사용한다.

```sh
python3 -B reviews/week01-depth-20261118/joined/public_cases.py
python3 -B reviews/week01-depth-20261118/joined/physical_keys.py 0002
python3 -B reviews/week01-depth-20261118/joined/physical_keys.py 0003
```

`physical_keys.py 0002`는 보존된 결함 두 건 때문에 1을 반환한다. 최종 후보로 실행한 나머지 공개 검산은 0을 반환한다. 도구가 검사하는 로컬 출처 해시는 날짜와 원문 위치가 기록된 독해 메모를 묶는다. 실제 외부 사이트에서 수행한 독해, 저자와 검토자의 실제 신원, 학생 이해도는 해시로 확인할 수 없다. 외부 요구 추출은 과정 편집자가, 교재 대조는 별도 검토자가 수행했다. 발견 세션 ID `week01-joined-review`와 판정 ID `joined-content-review`는 같은 교재 검토자를 가리킨다.
