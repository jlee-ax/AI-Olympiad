# 교안 깊이 판정의 동결된 비교 조건

동일한 한국어 부록과 자료를 읽는 검토자가 두 수업 활동 중 채택할 안과 새 입력의 결과를 제시한다. 12건 중 11건은 교안 심의이고 1건은 색인 납품이다. 1주차 5건, 2·3·4·5·7·8주차 각 1건이다. 1주차 2건은 수치와 후보 코드가 동일하고 평가 단위만 다르다. 따라서 두 건을 독립적인 복제로 세지 않는다. 후보 이름과 작성자, 스킬 출처를 사례 안에서 숨겼다. 각 사례는 제작한 활동 발췌로, 배포 노트북 전체나 대회 기출이 아니다.

## 검토자에게 배부

`blind/packets.json`만 배부한다. 두 검토자 모두 같은 자료·조건·순서·응답 형식을 받는다. 도구 사용 조건과 모델을 일치시킨다. 처치군에는 지정 스킬과 연결 문서를 추가하고 대조군은 같은 과정 자료만 사용한다. 사례 설계자·정답 예시·점수·다른 팔 답변은 배부하지 않는다. 각 응답은 사례별 `id`, `selection`, `probe`, `basis`, `edit`를 포함한다. 비심의 색인 요청에는 그 사례의 납품 양식이 우선한다. 외부 통신은 필요하지 않다.

## 산출과 해석

11개 본문 사례에 대해 채택안과 새 입력 답을 각각 원문 비교한다. 독립적인 의미 판독자는 설명이 결정적인 목표·선수·과도한 필수 부담 중 해당 근거를 정확히 짚는지, 제시한 편집이나 유지가 그 이유를 살리는지 판정한다. 판독은 실제 응답 문장과 사전 동결한 근거에 기대며 단어 수, 특정 용어, 길이를 채점하지 않는다. 해당되는 4개 조건이 모두 충족되어야 온전한 통과다. 색인 요청 1건과 목적 반전 한 쌍의 일관성은 따로 기록한다. 짧은 수식, 표기법과 정당한 대체 표현을 허용한다. 하나의 선명한 검토 예시는 집단 학생 효과·출판 적합성·배포본 전체 검증을 의미하지 않는다.

주 비교는 새 스킬 대 미제공 조건에서 같은 사례에 대한 판정 일치·불일치다. 각 조건 실제 모델 수, 전체 사례 수, 결측 답변과 실행 경로를 명시한다. 사전 정한 최소 개선폭이나 모집단 대표 표본이 없어 채택을 단정하지 않는다. 서로 다른 사례 내용이 있는 10개 교안 문제군 및 색인 대조 하나다. 사례 수를 모델 반복 횟수로 표현하지 않는다.

NVIDIA Tier 3의 준비·실행, 현재 대화의 독립 검토자 답변, 교안 자체의 실행은 별도로 기록한다. 공개 후 같은 자료를 다시 쓰는 경우 공개 개발 과제로 표시한다.
