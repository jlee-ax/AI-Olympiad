# 1주차 편성 근거

2026년 11월 18일 확인한 KOAI 2027 중등부 안내는 필기와 코딩에 1~4과목을 적용한다. 1주차는 과정 계획에 있는 Python, NumPy·pandas, Matplotlib·Seaborn의 실제 적용 및 텐서 조작의 배열 선수를 담당한다. 주차와 시간은 이 과정의 편성 결정이다. [KOAI 2027](https://kitpa.org/koai/2027) · [국내 출제 기준](https://kitpa.org/koai/syllabus)

Python 기초를 진입점으로 삼되 AI 선수학습은 가정하지 않는다. 실라버스에서 위 도구의 표시는 실전이다. 값·상태·분모·축·단위가 달라질 때 결과를 해석하는 데 쓰이는 원리를 가르친다. 수식 수나 API 수에 점수를 주지 않는다. [NumPy 기초](https://numpy.org/doc/stable/user/absolute_beginners.html) · [pandas 자료 결합](https://pandas.pydata.org/docs/user_guide/merging.html) · [Matplotlib](https://matplotlib.org/stable/users/explain/quick_start.html) · [Seaborn](https://seaborn.pydata.org/tutorial/relational.html)

IOAI 2025 Antique의 과제 설명과 데이터 명세에는 특성과 일부만 알려진 라벨이 구분되어 있다. 여기서 끌어온 1주차 판단은 관측 시점에 어떤 값이 보이는지, 빈값과 숫자 0이 무엇을 뜻하는지 확인하는 일이다. 국제 문제의 학습 알고리즘이나 제출 코드는 이 주의 요구로 채택하지 않았다. 2026 국내 예시는 주최 측이 고등부 기준 학습 참고로 공개했다. 이 자료로 중등부 출제 빈도·난도를 정할 수 없다. [Antique 원문](https://raw.githubusercontent.com/IOAI-official/IOAI-2025/main/Individual-Contest/Antique/Antique.ipynb) · [국내 예시 공고](https://kitpa.org/files/36)

수업 120분에는 이론 20분, 비코딩 20분(필기 10분 포함), 코딩 80분을 배정한다. Python 진단 20분, CSV 작업 40분, 배열·그림 코딩에 20분이다. 필수 자습은 주차 계획의 5~7시간 안에서 6시간으로 편성했다. 이는 편집 비교를 위한 추정 예산이다. 기초 진단과 새 표→계산→표시의 독립 과제를 분리한다. 편집자는 평가용 비공개 입력을 받지 않는다.
