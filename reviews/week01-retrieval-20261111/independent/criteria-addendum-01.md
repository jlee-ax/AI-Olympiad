# 후보 전 3차원 입력 보완

부모가 요구한 전혀 새로운 3차원·축 반례를 후보 편집/열람 전에 추가 고정한다. 원래 기준/입력 파일은 그대로 보존한다. independent-3d-addendum.json의 2개 질의·4개 후보는 작성자가 제안한 2D 수치를 사용하지 않았다. 정확한 분수 기대값·새 문자열 ID·비정사각형 축·양/음 배율·zero 경계를 포함한다.

이는 기존 기준을 완화하지 않으며 정규화 helper의 실제 코드와 임의 d 축 의미를 점검한다. 별도 검토자 참조 구현의 성공과 교안 실제 함수 성공을 분리하고, 좁은 입력 범위가 선언돼 있으면 적용 범위를 정직하게 기록한다.
