# 1주 통합 교안 독립 검토 기준 v1 — 후보 열람 전 고정

후보 내용을 읽기 전에 기존 세 학생 교안, 보존 미커밋 수정, 10주 계획을 직접 읽고 고정한다. 후보 작성자와 별도로 판정하며 특정 알고리즘·입력 숫자·셀 수를 유일한 정답으로 요구하지 않는다. 이후 기준 변경은 이 파일을 덮어쓰지 않고 이유와 적용 시점을 새 addendum에 남긴다.

## 1. 과제 경계와 보존

하나의 학생 진입점에서 문제의 입력·출력·예측 시점 읽기 → 표/CSV와 기초 Python → 통계·배열·그림 → 실제 훈련 자료에서 배우는 모델 → 검증/ID와 제출 → 낯선 명세의 독립 구현으로 이어져야 한다. 같은 데이터를 이어 쓰거나 전환 이유·자료사전을 명시하여 개념의 연결을 학생이 따라갈 수 있어야 한다. 기존 세 문서를 그대로 이어 붙이거나 링크만 단 네 번째 보충 문서는 부적합이다.

현재 저장소 원본 세 자료와 별도 사용자 worktree의 미커밋 파일은 수정 대상이 아니다. 사전 입력 manifest의 raw hash, source/cell snapshot, 각 git status·HEAD·diff를 기준으로 보존 여부를 확인한다. 통합본에 필요한 개념을 재작성할 수 있으나 기존 교안의 모든 독립 문항 숫자를 그대로 복제할 필요는 없다.

필수 목표를 다른 주차로 조용히 미루거나 모델 fit 하나로 완료 처리하면 안 된다. 남겨 둔 기존 필수 연습을 포함한다면 학생이 실제로 열 수 있는 경로·절/셀·할 일·미완료 판정을 명시해야 한다. 링크의 존재만으로 학습 목표를 충족했다고 세지 않는다. 선택으로 둘 수 있는 후속 stack/lookup 심화와 1주 필수를 구별한다.

## 3. 초심자 원리·수식·코드와 반복/부담

표/단위의 구체 예 → 작은 손계산·상태 추적 → 기호 정의/일반식 → 그 식의 연산과 코드 대응 → 출력 해석 → 다른 입력의 스스로 구현 순서가 핵심 개념마다 식별돼야 한다. 개념이 같을 때 설명·함수·데이터를 재사용하고, 다시 필요해진 개념은 무엇이 확장됐는지 밝힌다. API 목록·완성 코드를 주고 결과만 실행하는 것으로 원리 학습을 대신하지 않는다.

행렬곱·제곱거리·자료형/모양을 구분하고 단위가 다른 열 평균/거리의 해석을 설명한다. AI 선행지식이나 미분을 1주 모델 실행의 필수로 가정하지 않는다. 복잡한 ZIP/예외/사전 helper가 있다면 학습 대상의 핵심과 제공 기능의 입력·출력을 구별하고 이해하지 않은 내부 구현을 숙달했다고 처리하지 않는다.

반복과 부담은 전체 텍스트/코드·독립 문제 수, 중복 설명, 새 개념 전환, 지원 범위, 필수 목표별 남은 과제로 비교한다. 근거 없는 최대 셀/단어·점수 기준을 만들지 않는다. 기존 120분·5–7시간은 이전 범위의 계획 추정치이지 새 통합본 완료의 관측값이 아니다. 학생 문서에는 교사 편성/실측/수업·자습 시간 배정 문구를 넣지 않고, 학습에 필요한 실행 방법·질문·예측 시점은 유지한다. 시간과 배치는 teacher에만 관측 한계와 함께 기록한다.

## 4. 10주 선수와 학습 범위

2주 분할/전처리/지표, 3주 회귀·손실·가중합, 4주 여러 지도 모델·검증 선택, 5주 거리·분산, 6주 텐서·학습 루프, 7–9주 표현·검색/원본 ID, 10주 낯선 CSV의 계약·분할·전처리·학습·검증과 연결한다. 첫 모델 실행은 이 선수의 연결 예이지 후속 알고리즘·전범위 모델 실행이나 대회 독립 해결의 완료가 아니다.

공식 KOAI/IOAI 범위, 과거 Antique/Restroom 원문, 자체 합성 입력을 분리한다. 합성의 알려진 라벨만 학습하는 단순화가 원문의 미상 입력 활용 등 모든 요구를 만족한다고 하지 않는다. 기존 2주의 고정 점수/임계값을 훈련된 분류 모델로 오인시키지 않는다.

## 5. 독립 문제·복수 정답과 성취

명시된 계약을 지킨 적절한 다른 학습 모델을 최소 1개 실제로 실행해 수용 여부를 확인한다. 예시 중심/회귀 모델과 예측·점수가 다르다는 이유만으로 오답 처리해서는 안 된다. 정확히 지정한 손계산 알고리즘의 수치 대조와 자유 모델 선택 문제의 채점은 구별한다. 누수 없는 학습과 잘못된 예측을 가진 낮은 성능 모델도 형식 오류와 같은 것으로 취급하지 않는다.

학생 독립 코드는 빈 상태를 보존하고 답/완성 핵심 코드는 공개 학생 출력에 미리 넣지 않는다. teacher 파일 분리만으로 비공개가 보장되지 않는다. ‘새 입력’이 기존 예제의 단순 실행인지 규칙/스키마 전이를 요구하는지 구별한다. 검토자가 만든 정답·테스트 실행과 학생 실제 독립 구현·이해·소요 시간은 끝까지 분리한다. 보호된 실제 숨은 테스트를 만들지 않았다면 미생성/미검증으로 남긴다.

## 6. 실행·수치·변이의 사전 계획

각 전체 실행/변이/별도 사례는 **새 subprocess의 새 in-process 커널 또는 별도 계산 프로세스**에서 실행한다. 같은 프로세스에 여러 커널을 재생성하지 않는다. 정상 대조군이 통과하기 전 변이 실패를 성공으로 세지 않고, 변이 위치 이전의 harness 실패·NoneType.outputs/전역 상태 오류는 무효로 기록한다. 실패한 중간 검증도 삭제/성공으로 덮지 않고 입력 SHA·원인·유효/무효를 보존한다.

- 별도 list/loop/Fraction 구현으로 합/개수·평균/분산·축/원소 배치·예시 모델 손계산과 예측을 재계산한다. float의 유도량은 허용오차로 비교하되 문제의 임계값 판정을 임의로 느슨하게 바꾸지 않는다.
- 훈련 특성/y 변경, 미상 행 변경, 검증 입력/정답 변경으로 학습 상태의 의존/불변 경계를 검사한다. 단순 fit 호출·출력 존재와 실제 학습을 구별한다.
- 훈련/검증 혼합 fit, 검증 재fit, target/future/ID 피처, 미상=음성 치환, 0 결측 처리 오류, 빈 관측 분모, shape만 맞는 축/순서 변이를 주입한다.
- ID와 행을 함께/따로 섞기, 같은 길이의 예측만 뒤집기, duplicate/missing/None/NaN/빈 ID, 잘못된 특성 열/순서, header/index/열 수/행 수/라벨·파일명 오류를 계약에 따라 시험한다.
- 정상 형식인 상수 예측과 오염된 upstream ID→예측표를 별도로 넣어, 형식 통과가 성능/정당한 모델/ID 진실성을 입증하지 못하는지 확인한다. 항상 오류로 거부하도록 요구하지 않고 어떤 독립 provenance 검사로 발견되는지 기록한다.
- 알려진 예시뿐 아니라 독립 새 숫자/순서/명세와 다른 타당한 모델을 실행한다. 교사용 예시·자유 모델 채점과 학생 요구의 일치를 대조한다.
- 저장 출력과 새 실행을 비교하고 그래프·정적 HTML/링크의 읽기 품질을 확인한다. 브라우저/file URL·일반 소켓 정책은 우회하지 않으며 못 본 시각 범위는 미검증으로 표시한다.

## 7. 판정과 변경 기록

최종 결과는 필수 목표의 실제 위치·열려 있는 평가, 정상/오류별 통과·실패·미검증, source SHA, 실행 환경, 범위·부담·학생 수행 한계를 함께 적는다. 교안 결함은 부모/저자에게 재현 위치·입력·예상/실제를 보내 수정받고 새 SHA에서 재검증한다. 검토자 자신의 harness 결함은 교안 결함과 구분하며 무효 근거를 보존한다. 기준을 나중에 바꾸어 후보를 유리하게 평가하지 않는다. 허용된 새 independent 경로만 작성하고 교안/기존 검토/index/commit/remote를 수정하지 않는다.
