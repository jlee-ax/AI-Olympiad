# 2주 다수 기준·평가 목적 전이 · 후보 전 독립 기준

이 기준과 새 입력은 후보 내용 확인·실행 전에 고정한다. 기존 본문/보충의 constant−1 기준, 미상과 결측 구분, train-only 전처리, 분모0 정책, 목적 지표 선택, AUC 순위/면적, 시간·그룹 계약, 학생 빈칸과4주 연결을 보존한다. 새 코딩 문제나 시간 확보를 자동으로 가정하지 않는다. 기준 파일/숫자 입력을 작성자와 공유하지 않는다. 파일 분리는 접근 통제가 아니며 이 기록은 실제 비공개 학생 최종시험이 아니다.

## 1. 훈련 라벨에서 배운 다수 기준

정답이 알려진 훈련 행의 클래스 빈도로 상수 예측을 정한다. 입력 X와의 관계를 배우는 비상수 모델은 아니다. constant−1은 의도한0분모 설명에 타당하므로 삭제/열등하다고 단정하지 않는다. 빈도와 동률 정책을 밝히며 순서로 우연히 바뀌지 않아야 한다. 한 클래스만 있으면 다수 기준 자체는 학습 가능하다. 이를 두 클래스를 요구하는 다른 분류기의 제약과 혼동하지 않는다. 모두 미상/빈 훈련에는 배울 빈도가 없음을 명시하고, 임의 기본값을 학습한 다수 결과로 부르지 않는다. 허용 라벨과 미상0을 명시하고 그밖의 라벨은 거부 또는 문서화된 명시적 정규화로 처리한다. 의미가 같은 허용 숫자 표현 자체를 부당하게 탈락시키지 않는다. 문자열·bool·잘못된 값이 몰래 양성이 되는 경로는 점검한다.

검증 y 변경은 fitted 기준/예측에 영향을 주면 안 된다. 훈련의 알려진 클래스 빈도가 역전되면 예측도 바뀌며, 미상행을 더해 다수를 정하지 않는다. X만 바꿔도 기준 클래스/예측은 그대로다. 이때 훈련 X로 fit하는 전처리 통계까지 불변이어야 한다는 잘못된 조건은 요구하지 않는다. 검증을 보고 공식 목적에 맞는 후보를 고르는 것은 허용되지만 검증 라벨로 기준 빈도를 재fit하는 것은 별개다.

## 2. 희귀 양성과 목적 지표

같은 평가 행의 두 후보를 정확도·양성 정밀도/재현율/F1·문제에 명시한 정답 기준 가중 점수로 비교한다. 다수 기준이 어느 공식 지표에도 최적이라고 하지 않으며 F1/AUC/가중 점수를 언제나 우월하다고 하지 않는다. 모든 양성을 놓쳐도 정확도가 높을 수 있고, 양성 예측이 없을 때 정밀도0/0과 재현율0, F1의 count식 결과를 구별한다. 실제 클래스가 없거나 빈 평가이면 각 지표의 분모와 보고 정책을 따로 기록한다. 행별/개체별 집계와 훈련 라벨 빈도는 다른 목적이다. 기존 B/T 표 재사용과 학습 라벨의 결정 경로를 구분하며 평가표의 정답 빈도로 다수 기준을 학습하지 않는다.

## 3. 목적별 분할 전이

같은 ID의 독립 snapshot에서 친숙한 구성 요소의 보지 못한 조합을 평가한다는 합성 계약과, 새 개체/미래 계약을 구별한다. 별도 검토자 참조에서는 같은 ID가 훈련·평가 양쪽에 있는 유효 사례와 두 가지 조합 분할을 허용하고, 계약상 보류한 조합이 양쪽에 새는 분할·없는 과거를 요청하는 특성을 거부한다. 이는 공식 Robot 데이터의 실제 분할을 복원한 것이 아니다. 원문은 동일 여섯 로봇·독립 snapshot·평가 시 이전 관측/행동 미제공·친숙한 구성 요소의 새 조합 가능성이다. robot_id를 모든 과제에서 금지하거나 그룹 분리/시간창을 모든 목적에 강요하지 않는다. 명세를 먼저 정하고 그 목표를 만족하는 여러 분할을 수용한다.

## 4. 독립 확인과 학습 경로

후보 최종 SHA 수령 뒤 원바이트를 snapshot한다. 실제 제공 함수/예제를 고정 입력에 호출하는 결과와 검토자 참조/샘플 풀이를 분리한다. 상수 예측 배열이 같다는 사실만으로 ID 순서가 검증됐다고 하지 않으며, 대응 ID나 예측이 다른 동료 후보를 별도로 확인한다. 정상 control 뒤 단일 오류(검증 y 재fit, 미상 음성화, 잘못된 동률/빈도, 반전 지표/분모, 조합 누출, 허용되지 않은 과거)를 넣고 기대·실제·검출 주체·raw traceback을 보존한다. 커널/수집 하네스 실패와 교안 오류를 구분하며 미실행을 적는다. 가능한 범위에서 새 subprocess/fresh in-process 전체 실행과 기존 필수/정상·반례 회귀를 한다. 4주 전체 구현이나 학습된 비상수 모델, 학생 성취/도움/실측시간을 주장하지 않는다. 기존 활동 재구성/중복 감소와 실제 요구량 증가를 모두 살피며 120분·자습 시간의 충분함을 추측하지 않는다.

쓰기 허용은 이 independent 폴더뿐이다. 학생/교사용 원본·1주차/사용자 작업·index·remote는 변경하지 않는다. 일반 소켓 커널·브라우저 제한을 우회하지 않는다. 후보를 받기 전에는 고정 입력을 실행하지 않는다.
