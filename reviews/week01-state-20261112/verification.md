## 선정 근거와 범위

[독립 기준과 원문 대조](../week01-state-independent-20261112/criteria.md)를 먼저 정하고 현행 본문·통합본·교량, 공식 안내 및 여러 국제 과제와 대조했다. [KOAI 2027 안내](https://kitpa.org/koai/2027)와 연결 [출제 기준](https://kitpa.org/koai/syllabus)은 범위의 근거다. 기존 교안은 계산·입력 불변과 완성된 복사 예시는 제공하지만, 학생이 배열의 변경 전후 원본·뷰·복사본과 저장된 계산값을 독립적으로 추론하는 요구가 약했다. 기존 기기 2번의 입력을 그대로 활용해 ‘입력 관찰 → 실행 전 예상·이유 → 직접 작성한 코드로 변경 → 예상과 결과 대조’ 흐름을 보강했다. 기본 슬라이스가 보는 데이터와 이미 반환된 정수가 다름을 설명했다. 센서 수 계산식·수치 특성·학습 모델은 학생이 고르며 완성된 정답 코드를 학생용에 더하지 않았다. 과거의 배열 공유 버그 수정과 이번 학생의 상태 추론 요구를 구별한다.

대안으로 영역 반환값의 독립성, 가변 기본 인자, 훈련 행 재정렬·결측 키 병합·검증 결측·공동 분포 읽기를 비교했다. 영역 과제는 호출 중 입력 불변만 명세하므로 반환 후 독립성을 소급 요구해 기존 올바른 답을 탈락시키지 않았다. 함수 바인딩 시점은 추가 선수 부담이 있고, 전처리·평가는 2주에서 이미 다룬다. 이번에는 1주 NumPy 상태 이해를 보완하고 나머지를 열린 요구로 유지했다. 3~10주 이론·모델·응용의 완성이나 모든 원문의 빠짐없는 조사를 주장하지 않는다.

새 단원·새 코드 셀 대신 Markdown 3곳과 교사용 설명을 바꾸었다. 그러나 기존 문항에 수행이 추가됐으므로 학습량이 그대로이거나 시간 안에 끝난다는 근거는 없다. 10주 후속 구현에서 입력과 산출물의 갱신을 이해하는 선수 경로로 두되, 저장한 정수의 특성을 모든 배열·전처리기·모델에 일반화하지 않는다. 실제 학생의 예상·오류·도움·소요 시간을 관찰해야 분량과 성취를 판단할 수 있다.
