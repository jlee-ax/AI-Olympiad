# 기준 addendum 01 — 부모의 추가 요구와 모델별 oracle 구체화

기준v1과 입력 manifest는 변경하지 않는다. 새 교안 초기7f0e 후보를 읽은 뒤 부모가 다음을 추가로 명시했다. 이는 결과를 유리하게 하기 위한 기준 약화가 아니다.

- 메모리 ZIP/CSV 확인만으로 끝내지 않고 실제 임시 작업 디렉터리에 정확한 파일명을 써서 재열기·정리를 확인한다. 서버나 대회 서비스에 전송하는 작업은 포함하지 않는다. 초기7f0e에는 이 물리 단계가 없었으며 후속e0b 후보에 추가됐으므로 수정 후 검증 대상이다.
- 새 독립 문제는 공통 train-only 평균 대체 조건을 유지하되 타당한 학습 분류기를 선택할 수 있어야 한다. 최초의 ‘가까운 중심을 먼저’ 문구는 단일 경로를 필수처럼 만들 여지가 있어 보정됐다. 지정된 중심 모델의 수치 예시는 비교 기준으로 남길 수 있으나 열린 답안을 그 예측과 다르다는 이유로 오답 처리하지 않는다.
- 기존 bridge는 새 pipeline으로 가는 링크 한 줄만 바꾸도록 허용됐다. 코드·출력은 바뀌면 안 된다. 원본 본교안과2주 자료의 hash 보존, bridge 코드/출력 동일성과 HTML 링크 동기화를 따로 검사한다. 과거 전체 artifact SHA에 묶인 리뷰는 새 raw SHA에 자동 재사용했다고 하지 않는다.

후보의 모델은 평균 대체+Euclidean NearestCentroid이므로 mean/centroid/squared-distance oracle를 실제 자료로 구체화한다. 이는 v1의 알고리즘 비종속 검토 계열에 해당하며, 다른 타당한 모델에 이 모델의 예측벡터를 강제하지 않는다. NumPy/sklearn 기본 prior는 현재 실행 환경에서 uniform이고, 이 조건을 확인한다. 원문 CSV와 합성 연습의 엄격한 정수 문자열 형식도 구별한다. 원문 scorer는 pandas.read_csv(header=None)와 accuracy_score를 쓰며, 합성 연습 inspector의 더 좁은 문자열 검사 전체를 대회의 모든 parser 동작이라고 일반화하지 않는다.

v1 제출 명세의 `\n` 표시는 행 구분을 보이기 위한 표기다. 실제 정상 바이트는 ASCII 음수기호와 실제 LF 행 구분으로 구성된 b'-1\n1\n-1\n'이며, backslash 문자와 n을 CSV 값에 넣는다는 뜻이 아니다.
