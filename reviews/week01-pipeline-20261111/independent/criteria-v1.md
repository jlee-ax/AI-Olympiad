# 문제 해석→전처리→학습→검증/제출: 사전 독립 검토 기준 v1

새 `week01_problem_pipeline.*`의 내용을 읽기 전에 고정한 기준이다. 실제 교안의 결과를 유리하게 만들기 위해 이 파일을 덮어쓰지 않는다. 새로운 명세가 요구하는 모델별 수치 oracle·추가 경계는 공통 기준의 구체화로 별도 기록하며, 기준을 바꿔야 한다면 이유와 이전 판정을 남기는 새 addendum으로만 기록한다. 현재 새 artifact에 대한 합격 판정은 하지 않는다.

## 읽은 출발점과 범위

기존1주 본교안89셀은 변수/조건/반복/함수/반환·오류, 평균·분산·표준편차, 표의 한 행/특성/정답/ID, 결측과0, CSV 선택·집계·병합, axis/shape·전치/내적·그래프를 다룬다. 본문은 이 화분 표로 모델을 학습하지 않는다고 명시하며 결측 대체·분할은 다음 주에 연결한다. 기존 배열 교량29셀은 가중치를 직접 정한 선형 변환·쌍별 점수·ID를 다루며 학습된 모델이라고 하지 않는다. 행렬곱·stack·임베딩 lookup을 모두 마쳐야 작은 학습 모델을 사용할 수 있는 것은 아니다.

2주 종단 교안의 z≥1은 훈련으로 전처리를 fit한 뒤 사전에 정한 분류 규칙을 적용한다. 시계열 보충의 scaled recent+0.25×red도 학습 모델이나 실제 확률이 아닌 고정 장난감 점수다. 이들을 실제 훈련 X/y에서 결정 규칙을 배운 모델의 실습으로 세지 않는다. 새 교안이 이 경계를 훼손하거나 2주 고정점수를 학습 모델이라고 부르면 지적한다.

10주 계획에서 1주는 주로 Python·표·배열, 2주는 분할/전처리/평가, 3주는 회귀, 4주는 여러 지도 모델·튜닝, 6주는 신경망 학습이다. 새 1주 연결 실습은 작은 실제 모델의 입문 경험으로 이해할 수 있지만, 후속 이론·여러 모델·전체 공식 범위까지 완료했다고 확대하지 않는다. 기존89셀·배열 교량·필수 과제에 새 내용을 단순 추가하면서 같은 시간 안의 완수를 주장하지 않는지 본다. 실제 학생 수행·시간은 관찰 전이며, 시간/내부 운영 상태 문구는 학생본에 넣지 않고 교사용 한계로만 둔다.

2027 KOAI 안내와 연결된 국내 syllabus를 직접 읽었다. 중등부에도 전범위 필기·코딩을 명시하며, 연결 syllabus는 조회 당시 IOAI2026 기준 표기다. 국제 Antique는 이미 AI를 배운 참가자를 전제로 한 원문이며, 초심자용1주 축소 예와 난도·조건·자료 규모·허용방법을 동일시하지 않는다.

## 합격·실패·미검증을 구별하는 공통 기준

1. **문제 계약과 초심자 설명**: 한 행의 대상, 예측하려는 정답, 예측 시점에 이용 가능한 입력, ID 역할, 훈련/검증/추론의 정답 공개 여부, 출력 요구를 학생이 표와 말로 연결할 수 있어야 한다. 새 API fit/predict, 모델이 배운 값, 손으로 따라갈 예측 하나를 설명한다. 필요 없는 수학·다수 모델을 한꺼번에 선수로 가정하지 않는다.
2. **실제 학습 모델**: 적어도 하나의 예측기가 실제 훈련 X/y에 fit되고 새 입력을 predict해야 한다. 전처리 fit, 사전 고정 임계값, 상수 기준 예측만으로 학습 분류기를 구현했다고 판정하지 않는다. 허용된 훈련값/라벨을 적절히 바꾼 대조에서 배운 상태가 달라지고, 경계를 가로지르는 새 질의의 예측이 달라지는 사례를 확인한다. 임의의 작은 perturbation마다 예측이 반드시 변해야 한다고 요구하지는 않는다.
3. **행·열·라벨 의미**: X는 행×특성, y는 같은 행 순서의 정답1개, ID는 출력 대응 정보다. 정답이나 예측 뒤에 생기는 정보를 특성에 넣지 않는다. 알려진 라벨 mask가 X/y에 같이 적용되고, 0 미상을 음성−1로 바꾸지 않는다. 미상 특성을 활용하는 별도 방법은 해당 자료 계약과 방법이 허용하는지 보고 판단한다.
4. **분할·fit 경계**: 예측 목적에 맞는 훈련/검증/최종 경계를 지킨다. 반복 개체·파생 원본과 시간은 해당 목적에 맞춰 검사한다. 학습형 전처리의 fitted statistics와 모델 상태를 실제 읽어 훈련만 사용했는지 확인한다. 검증 극단값·정답 변경이 훈련 상태를 바꾸지 않아야 한다. 최종 테스트나 추론 정답 없이도 predict/파일 작성이 끝나야 한다.
5. **손계산·예측·검증**: 명시한 예제 절차를 별도 list/sum/Fraction 구현과 비교한다. 지정된 tie·0분모·결측·한 클래스/빈 관측 등의 입력 조건과 오류 정책을 따른다. 계약 밖 입력까지 일반적으로 처리했다고 확대하지 않는다. 코드 실행, 형식 유효성, 검증 정확도, 최종 일반화 성능은 별개의 판정이다.
6. **명세별 출력**: 원래 요청 행 순서·개수·허용 정수 라벨·header/index/ID 열·파일명/파일형식/shape를 실제 직렬화한 바이트를 다시 읽어 확인한다. ID 숫자 순서로 임의 정렬하지 않는다. 어떤 과제가 header를 요구하고 다른 과제가 금지한다면 각각의 명세를 따른다. 모든 CSV에 같은 규칙을 적용하지 않는다. 형식상 유효한 상수 예측은 성능이 낮아도 형식 검사에는 통과할 수 있다.
7. **검증/최종 테스트 역할**: 검증으로 후보·설정을 고르는 것은 정상이고 반복 선택에 맞춰질 위험은 따로 설명한다. 최종 테스트는 모든 선택 뒤의 보류 평가다. 학생이 같은 저장소에서 정답을 읽을 수 있다면 파일 분리만으로 비공개라고 하지 않는다. 실제 숨은 자료가 없으면 미생성·미검증으로 기록한다.
8. **독립 과제와 복수 정답**: 새 입력에 학생 답안 칸이 비어 있는지와 교사용 key의 계약·계산을 대조한다. 지정된 알고리즘의 손계산 문항은 그 절차에 맞춰 채점하되, 모델/전처리/분할 방법을 선택하라는 열린 문항은 한 teacher 예측벡터나 코드만 유일한 정답으로 강요하지 않는다. 타당한 이유·훈련 경계·일관된 X/y/ID·평가·출력 계약이 맞는 다른 모델과 구현을 수용한다. 단 고정 규칙만 제시한 답은 실제 fit 모델 구현 목표를 대체하지 않는다. 점수가 낮다는 이유만으로 올바른 구현을 오답으로 만들지 않는다.
9. **실행·표시·출처**: 최종 SHA를 묶고 새 in-process 커널에서 실제 모든 셀을 실행한다. 저장 출력/PNG와 HTML이 새 실행과 일치하는지 확인한다. 빈 학생 셀도 실행된 것으로 세되 독립 성취로 세지 않는다. file URL·일반커널 소켓 제한을 우회하지 않는다. 실제 학생의 이해·소요시간·학습성과와 숨은 테스트 독립성은 코드 실행으로 입증하지 않는다.

## 사전에 정한 정상·오류 반례 계열

- 학습 영향: 1차원 예시 −1 훈련값[1,3], +1[7,9]의 클래스 평균은2와8이다. 이 구조를 쓰는 모델이면 질의4/6은 −1/+1이며, +1 훈련값을[3,5]로 바꾸면 평균4가 되어 질의4의 예측이 달라진다. 이는 모델 구조별 oracle를 구체화하는 예시이며 다른 타당한 estimator에 같은 수치를 강제하지 않는다. 라벨 swap/훈련 데이터 교체와 고정 규칙 대조도 사용한다.
- 미상/배치: ID를 비연속·역순 문자열로 두고 label0·특성 결측·실제 수치0을 섞는다. X/y mask 한쪽만 변경, label 또는 ID를 입력에 추가, 0→−1 치환을 고의로 넣어 차이를 확인한다.
- fit 누수: 검증의 관측값을 극단값으로 바꾸거나 검증 라벨을 뒤집어도 이미 배운 훈련 statistics/모델 상태는 불변이어야 한다. 훈련+검증 fit, 검증 재fit, 정답 열 입력, 추론에서 정답 열 의무 읽기를 변이로 넣는다. 단 허용된 검증 선택 자체를 누수라고 단정하지 않는다.
- 제출 명세 A: ID[Q9,Q2,Q7] 순서 예측[−1,+1,−1]을 라벨 한 열·header/index 없음으로 요구하면 `-1\n1\n-1\n`의 순서를 보존한다. ID를 정렬하거나 header/index를 추가하면 실패해야 한다. 명세B가 id,pred header2열을 요구하면 그 형식을 따르며 A의 header 금지를 잘못 적용하지 않는다.
- 형식/shape: 길이 부족·초과, 2차원 열벡터와1차원 구별, 확률/0/문자·bool 라벨, 허용되지 않은 추가 열, 중복/누락 ID와 순서 바꾸기, 잘못된 파일명/빈 파일을 해당 계약에 맞게 시험한다. 파일 바이트를 실제 parser로 다시 읽어 첫 예측이 header로 사라지지 않았는지 본다.
- 복수 경로: 열린 모델 선택에서 다른 정당한 train-only 전처리와 학습 가능한 모델이 서로 다른 유효 예측을 내더라도 허용되는지 key를 읽는다. 지정 알고리즘 문항과 열린 설계 문항을 혼동하지 않는다. 동률이 생길 때 명세가 없으면 유일 정답을 조용히 발명하지 않는다.

## 직접 읽은 공식 원문 경계

Antique는 train/validation/test 각각500독립표본, 특성5열과 train label1/−1/0(진품/복제/미상), 다수 미상 입력도 활용하는 학습 과제다. submission.ipynb가 submission.zip 안에 submissionA.csv·submissionB.csv를 만들며 각 행은±1, header가 없다. 지표는 accuracy다. 로컬 toy의 더 작은 표, 공개된 검증 정답, known-only 지도학습, 다른 CSV 명세는 교육적 축소/변경임을 밝혀야 한다. 미상0을 음성으로 바꾸거나 형식 연습만으로 원래 반지도 과제를 해결했다고 하지 않는다.
