# 1주차 문제 해석에서 학습·제출까지

## 확인한 공백

실제 1주 본교안은 표·평균·함수와 배열을 설명하고, 축·ID 보충은 고정 가중치와 행 대응을 다룬다. 별도 보존 중인 미커밋 본교안에는 예측 시점과 고정 예측식이 더 있지만 그 계수를 훈련 데이터로 학습하지는 않는다. 2주 전처리 교안의 상수 분류기와 시계열 보충의 고정 장난감 점수도 데이터에서 예측 규칙을 학습하는 예로 바꾸어 해석하지 않았다.

[KOAI 2027 안내](https://kitpa.org/koai/2027)가 연결한 [국내 기준](https://kitpa.org/koai/syllabus)은 확인 당시 IOAI 2026 기준으로 표시됐다. [IOAI 2025 Antique 원문](https://raw.githubusercontent.com/IOAI-official/IOAI-2025/main/Individual-Contest/Antique/Antique.ipynb)은 5개 특성, 미상 0 및 두 예측 라벨, 미상 표본 활용, 제출 파일을 함께 명세한다. 과거 국제 개인전 문제이지 국내 2027 중등 기출로 확인된 문제가 아니다.

## 보완한 경로

[학생 노트북](../../lessons/week01/week01_problem_pipeline.ipynb)과 [HTML](../../lessons/week01/week01_problem_pipeline.html)은 별도 합성 문제에서 입력·정답·ID·예측 시점·출력 조건을 구분하고, 알려진 훈련 행으로만 평균 대체와 가까운 중심 분류기를 실제 fit한다. 손계산한 중심과 거리를 코드에 대조하며 훈련 자료를 바꾸면 배운 중심과 같은 입력의 예측도 달라지는 것을 확인한다. 별도 검증의 3/4는 작은 합성 예의 계산이며 실제 성능을 추정하지 않는다.

예측을 ID에 붙여 요구 순서로 정렬하고 무헤더 CSV 둘을 ZIP에 넣는다. 임시 폴더에 실제 `submission.zip`을 쓴 뒤 다시 읽고, 내용 확인 뒤 삭제한다. 이 연습은 공식 데이터·대회 제출이 아니다. 알려진 라벨만 쓰는 이 지도학습 예 역시 미상 표본 활용을 요구하는 Antique 전체의 해법이 아니다.

다른 라벨 약속·세 특성·헤더 있는 CSV를 요구하는 새 독립 과제에서는 명세를 다시 읽고 학습 분류기를 선택해 설명하게 한다. 가까운 중심은 비교 가능한 한 예일 뿐, 다른 타당한 모델의 다른 예측을 일률 오답으로 처리하지 않는다. 기존 축·ID 보충의 마지막에 새 교안 링크를 추가했고 본교안과 2주 교안은 수정하지 않았다. 공개 저장소의 교사용 해설은 접근 통제가 아니다.

[교사용 해설](../../lessons/week01/week01_problem_pipeline_teacher.md)은 기존 120분 수업과 별도 자습의 기존 목표를 지우지 않고 중복 설명을 재배치할 후보를 제시한다. 이 보충까지 기존 계획 시간에 들어간다고 주장하지 않으며 추가 부담과 실제 완수 시간은 미관찰로 남긴다. 학생 자료에는 운영 시간 배정을 넣지 않았다.

## 검증과 남은 범위

- [교안 검증](../../lessons/week01/week01_problem_pipeline_validation.json)은 새 in-process 커널에서 27셀의 코드 12개와 15개 확인군을 실행했다. 알려진 라벨만의 fit, 검증 변경 시 훈련 상태 불변, 여섯 입력 순열, 다른 타당한 분류기, 실제 임시 ZIP 재읽기·삭제, ID·행 수·헤더·값·파일명 오류가 포함된다.
- [독립 검토](independent/independent-review.md)는 기준을 사전에 고정해 별도 손계산, 새 입력과 서로 다른 모델을 대조했다. 변이 검토기의 첫 결과는 display singleton 오류로 무효 처리·보존했고, 각 변이를 별도 프로세스에서 재실행했다. 유효한 13개 변이 중 11개는 교안 자체 검사, 2개는 독립 oracle이 탐지했다. 새 명세의 CSV·라벨 계약에 대한 별도 오류 사례 8개도 확인했다.
- 시스템 회귀 255개가 통과했다. 두 1주 보충본의 HTML은 현재 노트북에서 재생성한 결과와 같았고 학생용 시간 배정 검색에서 결과가 없었다. 별도 미커밋 사용자 작업의 보존 해시 6개와 원래 본교안·2주 교안은 유지했다.
- [상태 재조회](discovery/)는 이전 기록을 보존하고 변경된 교량·새 교안을 각 원본 SHA에 다시 연결한다. 기존 workflow의 `criteria_agreement_required` pause와 평가 불확실성을 합의나 통과로 바꾸지 않는다. 이번 교안 제작은 사용자의 별도 명시 지시에 따른 것이다.

일반 소켓 Jupyter/Colab과 HTML의 전체 화면 렌더링은 이 환경에서 확인하지 못했다. in-process 실행과 HTML의 구조·재생성 확인은 그 검증을 대신하지 않는다. 공식 Antique 데이터·제출 수락, 실제 학생의 독립 답안·도움·학습 효과·소요 시간, 미상 표본 활용 모델과 전체 10주 과정의 충분성은 여전히 미검증이다.
