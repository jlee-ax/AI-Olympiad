# 임계값 동률·고정 추기

부모가 source-only 초안을 열기 전에 요청한 추가 검토다. 기존 기준/v2 기대는 변경하지 않는다. 별도 새 입력에서 서로 다른 두 임계값이 동일한 검증 예측과 공식점수를 낼 수 있으나, 그 사이에 놓인 새 무라벨 점수에서는 예측이 달라진다. 미리 명시한 높은 임계값 우선 규칙을 적용하고 실제 숫자 임계값·비교 연산·목적·동률 정책을 고정/보존한 뒤 그대로 적용하는지 확인한다. 검증 예측만 같다는 사실을 동일한 배포 규칙으로 오인하지 않으며 새 입력/정답을 보고 동률을 해소하지 않는다.

이 추가 기대는 후보 source를 읽기 전에 별도 합성값으로 고정했다. 구체값은 저자/agent 메시지에 공개하지 않는다. 아직 실행하지 않았고 source-only 초안의 저장 출력/HTML/실행 완료를 승인하지 않는다.
