# 2주차 개선과 검증 — 2026-11-11

## 선택한 공백과 범위

이번 작업은 1주차 사용자 통합 작업과 별도로 2주차 두 노트북과 그 교사용 도구를 보완한다. [원문 대조와 우선순위](source-prioritization.md)는 KOAI 공지와 출제 범위, 여러 IOAI 실제 과제, Stanford CS229, 교재 및 선택 편향 논문을 구분해 읽은 기록이다. 2026년 KOAI 공개 예시는 고등부 학습 참고이며 국제 과제를 국내 중등 기출로 취급하지 않는다. 두 기존 노트북 모두 이미 훈련 집합 전용 변환, 시간·개체, 지표와 ROC를 다뤘으므로 그것을 반복하는 대신 **예측 시점·그룹에 맞는 분할, 동일 검증 자료에서 목적에 맞는 후보 선택과 고정, 이후 라벨 없는 입력에 고정된 절차 적용**의 연결을 우선했다. 3–10주 계획의 선후 관계는 원문 대조 문서에 남겼고 후속 주차 완성으로 간주하지 않는다.

- 본문의 A/B 4개 알려진 행, 손계산과 C/D 검증은 보존했다. 추가 G/H는 같은 합성 자료의 별도 훈련 후보로 제공한다. 4주에는 A/B/G/H로 변환과 모델을 새로 fit해야 한다. 원래 A/B만으로 그룹 2-fold를 수행하면 각 훈련 fold가 단일 클래스라 로지스틱 회귀가 실패했다. 확장한 예의 각 fold는 두 클래스를 포함한다.
- 보충은 측정 **전** 예측이라는 계약과 본문의 측정 **후** 계약을 구분한다. 학생이 그룹·시간에 맞게 분할을 설계하고 검증 F1 및 사전 동률 규칙으로 임계값을 골라 고정한 뒤 라벨 없는 새 연습 입력에 적용하게 한다. 본문과 연결되는 공통 제출 경로를 표시하되 새로운 단계가 추가되었으므로 실제 부담 감소를 주장하지 않는다. E/F는 최종 테스트가 만들어졌다는 표시가 아닌 자리표시다.
- 학생용 파일에 운영 시간 표시를 추가하지 않았다. 교사용 문서는 구형 검사 기록과 현재 검사 범위·별도 검산을 구분한다. 기존 validation JSON은 이 후보에 대한 새 승인으로 덮어쓰지 않았다.

## 실행 근거

- [작성자 기록](author/README.md)과 [별도 계산](author/independent-checks.json): 새 in-process Jupyter 커널에서 양 노트북을 실행했다. 그룹 CV의 두 fold에서 각각 훈련 4행, 양 클래스, fold별 대체 평균 3과 16/3을 확인하고 로지스틱 및 kNN(k=3)을 실행했다. 이 별도 검사는 본문 기본 검사기의 기능이 아니다.
- [보조 독립 검토](secondary-review.md): 별도 Python 프로세스에서 두 노트북 셀을 실행하고 3개 모델의 6개 fit/predict 및 kNN(k=5)의 예상 실패, 새로운 시계열 입력·순서 변경·미래/다른 개체 누수 반례, F1 동률과 경계 연산자를 독립 계산했다. 이 기록은 실제 관찰의 사후 요약이며 별도 raw stdout을 보존했다고 주장하지 않는다.
- [독립 평가 자료](independent/)는 후보 작성 전 기준·입력 고정, 작성 중 발견한 답안 노출과 그 수정 이력, 최종 후보의 별도 실행 및 실제 반례 기록을 보존한다. 학생의 응답이나 숙달을 시험한 것은 아니다.
- [본문 검사기 안전·회귀](safety/README.md): 최종 후보에서 33/33 사례와 출력 stream 결합 9/9 사례를 확인했다. [보충 검사기 최종 결과](safety/temporal-final-results.json)는 최종 노트북·HTML·교사용 설명 및 검사기 조합에서 26/26 사례를 기록한다. 정상 실행 외 기존 파일·심링크·중복 답안·저장 출력·`python -O`·중간 쓰기 실패·입력 변경을 확인한다. 격리 디렉터리는 신뢰된 Python을 위한 작업 공간이며 OS 보안 샌드박스가 아니다.
- 독립 입력·작은 합성 사례는 실제 대회 데이터, 통계적으로 안정적인 점수 또는 학생 성취를 입증하지 않는다. 일반 소켓 Jupyter는 한 차례 `Operation not permitted`로 시작하지 못했다. 전체 HTML/MathJax 브라우저 화면은 확인하지 못했고 저장된 ROC 그림만 별도 시각 확인했다. 예제 코드의 실행·정답 계산과 실제 학생의 독립적 수행, 도움 필요 정도, 소요 시간은 구분한다.

## 상태와 남은 과제

교안 변경 후 두 기존 discovery 세션을 읽기 전용으로 재조회하면 각각 `artifact_changed`, `needs_work` 및 미해결 요구가 표시된다. 이전 판정이나 계획을 현재 후보에 대한 승인으로 이용하지 않는다. 원래 Radar의 다중 라벨·1:50 계약, 공개 문제의 다른 모달리티, 출제 범위 연도 적용과 실제 학생의 학습량·전이는 열린 상태다. 실제 4주 노트북과 숨은 최종 시험은 이번에 만들거나 검증하지 않았다.

1주차 노트북·사용자 수정과 삭제, 그 작업 스레드는 변경하거나 중단하지 않았다. 이번 변경 경로는 `lessons/week02/`와 이 신규 기록 디렉터리로 제한한다.

`git diff --check -- lessons/week02`는 통과했다. 신규 검토 기록 전체의 공백 검사는 원본 바이트를 보존한 이전/후보 HTML·빌더 스냅샷의 행 끝 공백과 실행 출력 JSON의 빈 끝줄을 보고한다. 증거 파일은 이력을 바꾸지 않도록 정리하지 않았다.
