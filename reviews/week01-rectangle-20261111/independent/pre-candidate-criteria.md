# 사각형·배열 적용 · 후보 전 독립 기준

기존 bridge16b797… / integrated487379… / 원본ee827…를 기준으로 고정한다. 기존 기초는 적절하며 이번 선택은 열린 Pixel 요구의 제한된 배열 선수만이다. 후보를 보기 전 기준·새 입력을 고정하며 사전 새 테스트는 실행하지 않는다.

1. **원리와 새 적용:** (top,left),(bottom,right)의 정수 좌표를 r∈[top,bottom), c∈[left,right)라는 실제 칸 집합에 연결한다. 좌상 포함·우하 제외에서 높이/너비의 차와 곱이 나오는 이유를 손계산·그림·코드로 잇는다. 실행·shape만 맞고 다른 위치를 고르는 반례를 구별한다.
2. **계약과 면적:** 비정사각형 H,W와 C=3에서 공간 픽셀 수 HW를 센다. 정확한1/16 상한은 16A≤HW로 비교하며 등호를 허용한다. H,W가16의 배수가 아니어도 올림으로 초과를 허용하지 않는다. 아래 소형 예의 별도2칸 예산과 비어 있지 않음은 교육용 계약이며 공식 Pixel의 모든 정책으로 일반화하지 않는다.
3. **경계:** 아래끝=H/오른끝=W는 유효 stop일 수 있다. 음수·범위밖·역순·빈 구간은 교육용 계약대로 판정한다. NumPy가 음수/범위밖 slice를 처리·클리핑해 실행된 사실을 유효 계약으로 오인하지 않는다. 면적곱만 양수인 양축 역순도 거부한다.
4. **출력과 원본:** 같은 면적의 다른 위치를 좌표 집합으로 구별한다. 3개 채널은 하나의 공간 픽셀의 값이며 budget을3배로 만들거나 이미0인 값을 제외해 사각형 면적을 줄이지 않는다. 마스크/변환 이미지의 원래 공간·채널 대응과 선언된 shape/형식을 확인하고 원본은 보존한다. 교육용 binary mask 등과 공식 제출의 좌표 JSONL을 구분한다.
5. **기존 필수 보존·통합:** 원본 A의 reshape 원소수·배치, 전치와 같은shape의 의미차이, 행/열 broadcasting·오류 및 새 배열 T 생성/독립 빈칸을 유지한다. B의 두 라이브러리/분포·범주, C의 새CSV·결측/dtype·집계/병합·중복/미지키, D의0/None·관측수/평균/전부미상, E의내적/순서/새세션, bridge A/B와 현재lookup→mean→raw/cosine/ID를 삭제·면제하지 않는다. 완성 설명 반복을 줄이는 것은 새 입력 수행 삭제와 다르다.
6. **완성 예와 독립 답안 분리:** 완성 예와 다른 새 입력에서 학생이 좌표·검사·마스크를 직접 작성할 열린 코드 경로가 있어야 한다. 실제 후보의 제공 셀을 새 subprocess/fresh in-process kernel에서 실행한다. 새 커널에서 T와 필요한 원본/bridge 준비 셀만으로 경로가 재현되는지 확인한다. 빈 학생 셀은 실행돼도 과제완료가 아니다.
7. **검출 주체:** 후보에 범용 함수가 있으면 실제 함수를 새 입력에 호출한다. 함수가 없으면 학생 지시로부터 검토자가 쓴 샘플 답안을 별도 실행한다. 후자를 교안 자체의 자동 의미이해/새 입력 통과로 표시하지 않는다. 함수명/반환API/한 가지 코딩 방법을 사전 강제하지 않으며, 루프·slice 등 동일 명세의 타당한 해법을 허용한다.
8. **실행 근거:** 후보 최종SHA 수령 후 각 정상/단일 오류를 별도 새 subprocess·커널에서 시험하고 기대·실제·raw traceback·검출 주체를 보존한다. 새 입력은 사전 기대와 대조하며 실패 원인을 읽는다. 수정 시 이전 실패를 덮어쓰지 않는다. 새checkout 재현은 새repo-root/새output에 연결하고 원래설정/로그를 유지한다. 일반 커널 소켓·browser file 정책을 우회하지 않는다.
9. **범위·부담:** Pixel의CLIP/자동영역탐색/학습·공식 제출 전체나7~10주 과제를완료했다고 하지 않는다. 새 수학/검사 부담과 여러파일 이동을 인정하며 기존120분/5~7시간 적합성·학생실패·실제소요시간·성취를관찰없이단정하지않는다. 학생본은불필요한시간배정/내부검증상태를제외하되문제풀이·Jupyter실행안내는유지한다.
