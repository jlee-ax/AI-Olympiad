# 独립 입력 노출·교체 기록

제작자가 상태 목록을 확인하다 보조 검토자 작업 설명에 있던 v1의 일부 크기·유효/초과 기대값을 우연히 보았다고 자발적으로 알렸다. 부모는 새 입력으로 교체하라고 지시했다. 제작자는 교안을 아직 편집하지 않았다고 보고했고 노출 수치를 사용하지 않겠다고 밝혔다.

원래 `frozen-inputs.json`과 `FREEZE.sha256`은 삭제·덮어쓰지 않는다. v1은 **노출된 역사적 입력**이며, 후보가 독립 입력을 보지 않았다는 근거로 사용할 수 없다. 후보 전 9개 기준과 baseline manifest는 그대로 유지한다. 이후 독립 입력 검증에는 새 `frozen-inputs-v2.json`만 사용한다. v2의 구체값은 제작자·부모 메시지나 다른 agent의 작업 설명에 쓰지 않는다. 상태 목록 노출을 피하려고 교체 수치의 추가 하위 에이전트 위임을 하지 않았다.

이 기록은 접근이 차단된 실제 비공개 시험을 만들었다는 뜻이 아니다. 교안과 분리된 검토 입력이며, 저장소 접근자가 읽을 가능성을 제거하지 못한다. 실제 학생 성취는 미관찰이다. 이 시점에 노트북·후보·새 검증 코드는 실행하지 않았다.
