## Small teaching contract and integration

For an H×W array, interpret coordinates as **boundaries**, not two included corner pixels:

`0 ≤ top < bottom ≤ H`, `0 ≤ left < right ≤ W`;
`top ≤ row < bottom`, `left ≤ col < right`;
`A=(bottom-top)*(right-left)`.

Official Pixel's fraction is `16*A ≤ H*W`. **That fraction allows no positive-area integer rectangle in P02's 2×2 grid or A's 2×3 T**: their budgets are only 0.25 and 0.375 pixels. Reusing these small inputs therefore requires a separately stated synthetic budget. The proposed T application allows at most four of its six cells (4/6), which is deliberately different from official Pixel's 1/16. A proposed 8×12 worked grid permits six pixels under 1/16; that is a design proposal, not a read/validated candidate. Keep the two budgets explicit, and avoid a second large independent assignment.

Use the existing 1D slice diagnosis as the prerequisite, briefly demonstrate 2D boundaries, then attach one independent task to T. Preserve A's reshape/transpose/broadcast requirements and a single answer/code/help record. Construct a Boolean H×W region and a new zero-filled output of the original shape, copying only the selected slice. This contrasts a crop (smaller shape) with a full-size output (same coordinates, outside replaced). Check coordinates **before** slicing, area, retained values, replaced values and unchanged original. In RGB, area counts spatial pixels, not three channel elements or nonblack output values.

The new application does not fulfil the old function D's observed-count/mean/all-missing policy, B's two plotting libraries, C's CSV/group/merge, E's ordered dot product, or bridge A/B. Preserve them and the user's uncommitted original. Reduce repeated worked-example explanation/re-running rather than marking distinct objectives complete. No separate full Pixel notebook/model/large homework package is needed.

Independent synthetic checks executed in memory: an 8×8×3 rectangle `((1,3),(3,5))` selected four pixels; after one selected pixel was originally black, only three nonblack positions remained.
