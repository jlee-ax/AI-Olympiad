## 비교와 이번 선택

| 후보 | 가치·한계와 우선순위 |
|---|---|
| **ROC→AUC 순위 해석→임계값 결과와 구별** | 명시적 미포함 개념이며 기존 ROC·F1·동점과 연결된다. Q23 요구도 확인했다. **이번 단일 우선순위.** 새 대형 예제보다 기존 활동을 깊게 연결한다. AUC가 공식 지표·임계값·확률 보정을 대신하지 않는다. |
| 학습형 다수 baseline·희귀 양성 | constant와 다른 학습 상태와 높은 정확도의 한계를 보여 준다. 추가 불균형 훈련/평가 계약 설명이 필요하므로 차순위다. 기존 baseline을 오류로 규정하지 않고 4주 같은 조건의 비교에서 재fit한다. 이번에는 AUC 해석의 짧은 반례로 쓸 수 있다. |
| 다른 평가 목적의 독립 전이·실험 | 새 개체 미래와 Robot의 같은 ID 새 조합은 다르며 읽은 판본의 독립 과제로 후자를 확인할 수 없다. 후속 적용 가치는 높다. 계약 설명은 정확성 수정으로 우선하되 새 조합 데이터·모델·실험 전체를 AUC와 함께 누적하지 않는다. 4주·7–10주 독립 평가와 잇는다. |

## 자체 메모리 계산

`python -B` 인라인 코드에서 양·음 쌍을 Fraction으로 계산하고 `roc_auc_score`와 대조했다. 별도 스크립트나 raw stdout 파일은 저장하지 않았다. 실제 대회 데이터·학생 응답은 사용하지 않았다.

| 입력·변경 | 기대 / 실제 결과 |
|---|---|
| 기존 본문 별도 ROC 표 | AUC 3/4 = 0.75 |
| 기존 보충 worked 점수 | AUC 1/2 = 0.5. 기존 판정의 F1 0.8과 모순되지 않는다. |
| 기존 보충 독립 점수 | AUC 1/8 = 0.125. 항상 0.5 이상이라는 오해의 반례다. |
| 새 y=[+1,−1,+1,−1], s=[.9,.8,.7,.1] 및 s−1 | 둘 다 AUC 0.75, 고정 임계값 .5의 F1은 0.8→0. |
| 같은 y의 완전 순위·역순위·전부 동점 | AUC 각각 1·0·0.5 |
| 훈련/평가 음성9·양성1인 prior baseline | prior [.9,.1], 전부 음성, 정확도 .9·재현율0·AUC .5. AUC .5가 정확도 .5라는 뜻은 아니다. |
| 훈련·평가 라벨 빈도 반전 | prior [.1,.9]와 전부 양성으로 바뀜. X의 부호만 바꾸면 예측은 불변. |

실증 AUC는 양·음 쌍에서 양성 점수가 더 크면 1, 동점이면 1/2, 더 작으면 0을 주어 평균하는 작은 계산으로 시작할 수 있다. 두 클래스가 필요하며 hard label만 쓰면 원래 순위를 잃는다. 무작위 순위의 기대 수준 0.5·개별 유한 표본의 값·정확도를 구별한다. 낮은 최종 테스트 AUC를 보고 점수 방향을 바꾸면 새로운 선택이므로 독립 최종 평가를 유지하지 못한다.
