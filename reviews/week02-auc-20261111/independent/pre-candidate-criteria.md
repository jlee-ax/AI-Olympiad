# 2주 AUC 보강 · 후보 전 독립 기준

후보를 읽기 전에 고정한다. 이번 선택은 기존 ROC 표를 이용한 이진 AUC의 순위·면적 해석과 단일 임계값 평가의 구분이다. 새로운 대형 데이터·분류기 학습·다중클래스 AUC·적분 기법을 필수로 확대하지 않는다. 기존 2주 두 교안의 전처리/미상/시점/분할/0분모/F1/그룹·가중 평가와 빈 학생 답안·4주 연결을 보존한다. 다수 클래스 기준 및 다른 평가 목적의 독립 전이는 후속 큐이며 이번 AUC 보강이 이를 해결했다고 주장하지 않는다.

1. **면적과 순위의 같은 수학:** 양성·음성 각 한 개의 쌍을 세고 양성 점수가 더 크면 1, 서로 다른 클래스의 점수가 같으면 1/2, 작으면 0으로 합산해 P×N으로 나눈다. 전체 ROC의 사다리꼴 면적과 일치해야 한다. 양성 방향과 클래스 열/행의 의미를 먼저 고정하며 score>=threshold의 판정 동점 정책과 AUC의 이종 클래스 동점 반점을 구분한다. 모든 양·음 동점 쌍을 0 또는 1로 세는 오류·축 전치·절댓값 처리·점수 부호 반전을 정상 control과 비교한다.
2. **경계 의미:** 역순 점수의 AUC는 1−AUC, 모든 점수가 같은 경우는 두 클래스가 있을 때 AUC=1/2이다. AUC=1/2만으로 무작위 추측 과정·정확도 1/2·쓸모없는 모든 특징·모든 하위집단 성능을 단정하지 않는다. 실제 양성 또는 음성이 없거나 알려진 행이 없으면 쌍 분모가 0이므로 수학적 AUC는 정의되지 않는다. 라이브러리 버전의 경고/NaN/예외를 기록하고 수학적 0/0과 보고 정책을 구분한다. 본 합성 자료의 정답 미상 0은 음성으로 치환하지 않는다.
3. **순위와 판정:** 엄격한 증가 변환 뒤 AUC와 전체 ROC가 유지되어도 같은 숫자 임계값에서 혼동행렬/F1은 달라질 수 있다. 임계값도 같은 함수로 바꾸면 기존 판정이 유지된다. 더 큰 AUC가 모든 임계값·공식 지표에서 더 좋은 후보라는 주장을 배제한다. 주어진 toy score는 자료에서 학습한 모델도, 자동으로 보정된 확률도 아니다. AUC를 추가해도 기존 검증 지표의 선택/동률 고정/새 무라벨 적용/최종 테스트 보류를 대체하지 않는다.
4. **정확성과 명세:** 검증 입력을 전처리 fit에 섞는 누수와 검증 결과로 예정된 후보를 선택하는 역할을 모순 없이 설명한다. Robot Chasing은 같은 여섯 로봇·익숙한 요소의 새 조합·무작위 순서의 독립 snapshot이며 평가 시 이전 관측/행동이 없다는 원문 계약과, 합성 새 개체/미래/허용된 과거 문맥 계약을 분리한다. toy 이진 AUC를 Robot의 공식 다중행동 로봇별 정확도로 둔갑시키지 않는다.
5. **학습 경로와 부담:** 기존 ROC 좌표·그림을 재사용하고 완성 예와 다른 새 입력에서 학생이 계산·코드·이유를 작성할 경로가 있어야 한다. 이미 있는 ROC/F1/전처리 전 과정 과제와 별도의 대형 반복 과제를 쌓지 않는다. 기존 상수 −1 baseline은 0분모 설명에 타당하므로 AUC가 없거나 특징을 쓰지 않는다는 이유만으로 탈락시키지 않는다. 시간/성취/도움은 실제 관찰 전에는 미관찰이다. KOAI 고등부 학습참고 문항을 중등 기출 또는 2027 확정 문항으로 주장하지 않는다.

최종 SHA 수령 후 후보 원바이트 snapshot과 SHA를 보존하고, 제공 코드 전체를 새 subprocess/fresh in-process 커널에서 실행한다. 실제 교안 함수가 있으면 고정 독립 입력을 직접 적용한다. 없으면 완성 예의 실행과 검토자 별도 참조 풀이를 구분한다. 참조 계산·정상·단일 오류의 기대/실제·검출 주체·raw traceback을 기록하며 임의 예외 종료를 의미 검출로 세지 않는다. 범위를 줄이면 미실행 사례를 명시한다. 코드 실행을 학생 이해·숙달·수행 시간의 증거로 옮기지 않는다. runtime만 정리하고 입력/실패/기준/로그를 보존한다.

쓰기 범위는 이 independent 디렉터리뿐이다. 1주·사용자 작업·교안/교사용 원본·index·remote를 변경하지 않는다. 독립 새 입력의 값·기대값은 작성자에게 전달하지 않고 기준 동결 상태와 SHA만 부모에게 보낸다. 파일 이름을 숨김이라 불러도 공개 저장소 접근 통제나 실제 비공개 최종 테스트가 되지는 않는다. 후보 확정 전 독립 입력/기대 계산은 실행하지 않는다.
