## 기능 검증

| 실행한 사례 | 확인한 결과 |
|---|---|
| 실제 1주 통합본에서 분모 설명을 제거하고 중복 안내 삽입 | 전체 46셀 사본에서 빠진 설명 하나를 복구하고 중복 셀 하나를 제거했다. 복구 후 모든 셀이 원본과 일치했다. 코드 22셀과 독립 검사 1셀을 실행했다. 영·결측·음수가 섞인 입력의 평균은 3, 전부 결측과 빈 입력은 각각 None, 관측된 0 하나는 0이었다. |
| 실제 2주 전처리 보충본 사본의 설명 중복과 순서 오류 | 설명을 통합·보강하고 파이프라인의 위치를 옮겼다. 기존 훈련 통계 불변·미지 범주 검사는 교체 셀에 보존했다. 코드 10셀과 독립 검사 1셀을 실행했다. 훈련 범위가 3~7일 때 새 값 −1, 3, 11은 −1, 0, 2로 바뀌었다. 범위 자르기를 켜면 11과 15가 모두 1이 됐다. |
| 위험한 삭제·실패·재개 | 필수 경로 단절, 엉뚱한 셀 수정, 독립 검토자가 아닌 편집자의 자기 승인, 경계 입력 재사용과 다른 작성자의 파일 덮어쓰기를 거부했다. 반려된 동일 작업을 건너뛰었고, 같은 후보를 재실행해도 파일은 한 벌이었다. 검증한 후보로 기준본을 옮긴 뒤 과거 기록을 유지하고 새 교안 비교를 다시 요구했다. |
| 범위·우선순위 | 올바른 기초 단계와 잘못된 후속 주차를 다르게 판정했다. 코드 없는 기초 읽기와 실제 코드가 든 교안, 배경 질문과 필수 근거, 건전한 내용 유지와 손상된 내용 수정을 대조했다. 중지·예산 소진·오래된 출처가 수정 허가로 바뀌는 일도 검사했다. |
| 실제 과거 조사 이력 | 당시 과정 조사 기록의 요구 14개 중 미해결 13개를 그대로 보존했다. 이번 도구는 당시 자료에서 분명한 4개를 수정안 작성 대상으로 구별했다. 배열 축, 마스크의 참여 의미, 가중 점수의 분모, 추론 시 사용할 수 있는 도구가 해당한다. 나머지 9개는 추가 원문 대조·배치 판단이 필요했다. 당시 별도 보충본에서 이미 충족된 요구는 다시 편집 후보가 되지 않았다. 이 수치는 당시 교안을 기준으로 한 재생 결과다. |
