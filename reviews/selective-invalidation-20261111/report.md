# 계획·교안·근거 변경의 선택적 재검토 표시

## 확인한 결함

현재 main과 이번 작업 기준점의 하네스 3개 파일은 동일했다([원격 기준 확인](remote-baseline.json)). 기존 실제 `independent-transfer` quality의 `PLAN` 노드는 실제 파일 경로가 없고 평가 객체 8개의 의존 경로에도 없었다. 계획을 바꾸면 K01의 전체 해시 검사는 실패하지만, 계획을 명시적으로 새 버전으로 바인딩한 뒤에도 개별 검토의 지문은 그대로였다. 독립된 정상 대조군에서도 관련 계획 변경 후 K12가 통과 상태로 남는 반례를 재현했다. 실제 옛 기록 전체는 이미 `uncertain/ready=false`였으며 현재 전체 승인이 있었다고 주장하지 않는다.

기존 하네스는 교안의 연결된 셀·설명·코드·평가 영역과 일부 실제 근거 파일의 변경은 이미 선택적으로 감지했다. 이번 수정은 그 기능을 보존하면서 빠진 계획 연결과 검토 근거의 현재성을 명시한다. 전체 계획 파일을 모든 검토에 연결하면 무관한 주차 변경에도 모두 다시 검토해야 하는 반례가 있어, 그 방식은 사용하지 않았다.

## 구현

- `tools/quality.py`: 의존 노드에 명시적 `path`와 `locators`를 선언할 수 있다. 관련 주차와 공식 범위 항목, 공통 지침은 `unit.plan_dependency_ids`의 실제 의존 경로에 연결돼야 한다. 공통 지침 영역 `#plan-context`는 번호 붙은 주차/범위 행 밖의 본문·지침·링크를 포함하며 CSS·script와 단순 배치용 래퍼는 제외한다. 선택 영역이 그대로면 전체 파일 pin 갱신만으로 개별 내용 검토를 만료시키지 않는다.
- K12와 `selective_review`는 `current`, `binding_required`, `impact_confirmation_required`, `review_required`를 구분한다. 연결이 없던 옛 기록을 내용이 바뀐 것으로 단정하지 않고 연결·영향 확인 대상으로 표시한다. 실제 변경·누락은 관련 review/object/path/locator와 이전·현재 바인딩을 보여준다. 원래 검토의 통과·실패 상태도 따로 보존한다.
- 검토의 일반 근거와 세부 검사 근거 파일도 확인한다. 연결 누락과 확실한 근거 변경이 함께 있으면 근거 변경을 재검토 대상으로 우선 표시하고 연결 작업도 함께 남긴다. 최신 실패·중단·낡은 기록 뒤에서 옛 통과를 찾아 재사용하지 않는다. 새 해시 계산은 검토나 승인을 생성하지 않는다.
- `evaluate`, `plan`, `workflow.decide`, joined preflight에 같은 목록을 노출한다. 기존 미합의 등의 중단 이유를 바꾸지 않으면서 목록을 조회할 수 있다. K11/K13/후보 정렬에서 근거 파일 누락 때문에 전체 목록이 사라지던 연동 오류도 보정해, 관련 경로의 읽기 실패와 무관한 검토를 함께 보고한다.

형식과 재현 명령은 [하네스 문서](../../tools/README.md#selective-review-freshness-and-explicit-plan-bindings)에 있다. 예제의 새 바인딩과 검토는 명시적인 합성 대조군이며, 기존 합성 이력을 보존해 새 기록을 덧붙였다. 실제 사용자 검토·동의·교안은 갱신하지 않았다.

## 검증 범위와 한계

[실제 기록 복제 재현](reproduction/review.md)과 [독립 검토](independent/independent-review.md)에서 관련/무관 계획 영역, 공통 지침, 교안 셀과 근거·파일 누락, 연결 누락, 새 검토 추가, 최신 실패 우선, 조회의 원본 불변을 대조했다. 최종 v4의 독립 사례 31개, 실제 기록 복제본의 근거 변경·누락 6군 및 CLI 전파 10개 검사가 기대 결과와 일치했다. 구현자의 테스트와 전체 회귀 결과는 [구현 검증](implementation/)에 있다. 최초 테스트의 잘못된 지역 선택과 독립 검토가 발견한 근거 누락 연동 실패도 보존했다.

최종 core `tools/quality.py` SHA-256 `03f24f7e9b89979e30facf258f8c8f9f358b1aca2de876a1adae5e058f0fc96b`에서 선택적 변경·실패 테스트 15개, preflight 테스트 17개와 전체 회귀 **271개가 통과**했다. 전체 실행 중 소스 지문도 유지됐다([최종 회귀 로그](implementation/full-regression-v4.txt), [실행·지문 기록](implementation/full-regression-v4.json)). 이전 후보의 검증은 이전 후보 결과로 별도 보존하며 최종 통과로 바꿔 쓰지 않았다.

중복된 재현 입력과 큰 raw 출력은 경로별 크기/SHA manifest를 갖춘 압축본으로 보존했다. 복구한 바이트의 일치, 각 사례 파일의 독립성, 한 파일 변경의 비전파, 원문 symlink target 미읽기와 복구된 대조군 CLI 결과 일치도 검사했다. 요약·실패 판정·재현 코드는 바로 읽을 수 있으며, 세부 원문은 각 보고서에 적힌 archive/restore 명령으로 확인할 수 있다.

해시는 선언된 영역의 변경을 감지한다. 변경이 교육적으로 중요한지, 옛 판단을 유지할 수 있는지, 원문이 맞는지와 학생 성취는 사람이 따로 판단해야 한다. 선언하지 않은 의존성의 의미를 자동으로 찾아주지 않는다. K01 전체 산출물/계획 pin, K08 실행 영수증, 전체 catalog와 집계 승인 검사는 별도의 보호장치로 유지된다. 지역 내용 검토가 유지됐다는 이유로 전체 상태를 통과시키지 않는다.

작업은 별도 `codex/selective-review-invalidation-20261111`에서 수행했다. 기존 lessons/curriculum/실제 검토 이력과 사용자의 미커밋 파일은 보존했다. 이번 작업에서 교안 보정은 시작하지 않았다.
