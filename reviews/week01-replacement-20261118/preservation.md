# 두 경로에서 계속 배울 수 있는 것

두 경로의 편성 차이를 학생이 실제로 하는 일로 비교했다. 기존 경로는 `607c56e`에서 수업 진입점이 안내한 네 권, 새 경로는 다섯 번째 본문과 조건부 복구 한 권이다. 아래 내용은 최종 네 문항의 점수와 별개로 전체 교체를 결정할 때 고려한다.

| 기존 학생 활동과 위치 | 새 경로에서의 대응 | 후속 편성과 남는 차이 |

| 화분에서 어떤 열을 예측 시점에 알 수 있는지 정하고 0과 결측을 구분한다. 통합본 `5a7a14b7`, `e3783955`. 원본 실습에서 조건을 바꿔 새 CSV를 읽는다. | `dictionary`, `written-card`, `table-independent`, `transfer-brief`에서 한 행의 대상, 기록·목표·가용 시점, 조건 변경을 확인한다. `weighting-principle`, `class-transfer`는 관측 하나와 집단 하나에 같은 비중을 주는 두 요청을 분리한다. | 2주의 분할·대체·평가로 이어지는 선수 단계다. 반납량 예측 시점과 관측 분모는 1주 안에 남는다. |
| 평균·분산과 축을 손으로 추적하고, 같은 모양에서도 입력 순서가 틀릴 수 있음을 확인한다. 통합본 `0a64f981`, `a3f9c114`, 교량 `bf96efdf`. | `axis-picture`, `axis-check`, `math-concept`, `array-lab`, `math-lab`에서 축·단위를 확인한다. 한 경기 기록에서 게시판과 팀별 점수를 만들고 한 기록을 정정한 뒤 양쪽 출력을 다시 검사한다. | 이 수준의 축·원소 대응과 부호 있는 가중합을 1주에서 직접 연습한다. 여러 출력으로의 일반 선형 변환을 독립 구현하는 교량의 `4ac3bb9a`와는 깊이가 다르다. 3주 선형회귀 35분 및 6주 순전파·텐서 활동에는 연결되지만 그 다중 출력 실습을 맡을 별도 시간은 확인되지 않았다. |
| 그래프의 점을 원래 행과 연결하고 분포, 범주에 따라 다른 그림을 읽는다. 통합본 `f574b6b5`와 원본의 필수 그림 활동. | `plot-period`, `plot-histogram`, `plot-categories`, `transfer-first-code`, `transfer-figures`에서 표시 하나를 원자료로 되짚고 두 기준의 그림을 직접 작성한다. | 자료를 온전히 복사한 완성 답과 학생의 첫 선택을 구분해 검토한다. 수업에서 두 번째 그래프를 반복하던 시간은 단위·분모 선택에 쓴다. |
| 통합본 `303c6117`에서 기기 점검의 가용 특성, 훈련 ID, 정답 없는 검증 예측을 남기고 `exercise-validation-release`에서 나중에 검증 라벨을 연다. 파이프라인 보충 `bb177697`는 모델 선택과 제출 ID까지 확장한다. | 새 교안은 시점·유효값·기록 ID를 보존하는 결합까지 진행한다. 모델을 학습하고 예측을 보관한 뒤 따로 받은 정답과 대조하는 학생 과제는 이 경로에 없다. | 2주 수업에는 DummyClassifier 검증 20분, 분할 20분, 전처리 20분이 잡혀 있다. 10주 수업에는 새 CSV의 모델·검증 60분과 오류 수정·최종 점검 30분이 있다. 1주에서 이미 모델까지 확인할 수 있던 학생에게는 기존 조기 경로가 사라진다. | 교량 `2442117e`에서 패딩을 빼고 토큰 벡터를 집계해 내적·코사인 순위 및 실제 ID를 검산한다. | 경기 점수의 열 순서와 부호, 표 결합에서 실제 기록 ID는 다룬다. 벡터 정규화·코사인 순위와 토큰 마스킹을 결합하는 독립 경로는 새 1주에 없다. | 8주의 토큰·BERT 3~3.5시간에 패딩·마스크가, 9주의 CLIP 수업 20분과 자습 2~2.5시간에 유사도 검색이 들어 있다. 해당 주들의 전체 분량을 실제 학생에게 적용한 결과와 간단한 반례 연습의 수용 시간은 미확인이다. |
| 기존 본문·교량·파이프라인에는 진단·실패·선택 확장 이후의 복구 경로가 따로 있다. | 새 본문에서 중복되거나 짝이 없는 키의 실제 기록을 못 찾을 때 `transfer-faults`에서 보충으로 들어간다. `repair-return`에서 다른 자료를 처리한 뒤 원래 본문에서 다른 키를 빼고 다시 검사한다. | 새 분기는 표 결합 오류에 관해서 구체적인 복귀 증거를 준다. 모델 명세·검색을 먼저 탐구하려는 학생에게 기존 선택 경로를 제공하지는 않는다. |
