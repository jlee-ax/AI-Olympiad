# 1주차 교체 후보의 독립 제작 검수

등록된 R5 본교안과 학생이 실제로 열 수 있는 식별자 보충 교안을 검수했다. 네 주제의 과제와 해설은 고정한 범위를 충족했다. 전 과정의 운영 합의와 가장 긴 지원 경로의 자습 시간에는 미해결 사항이 남았다. 학생 학습 효과나 기존 교안과의 우열은 이 제작 검수에서 측정하지 않았다. [R5 독립 판단](../../week01-depth-20261118/rounds/0005/reviews/joined.json) · [재실행 결과](reports.json)

## 재실행

저장소 루트에서 교안 환경의 Python을 사용한다. 이번 실행 환경은 Mistune 3.4, NumPy 2.3.5, pandas 2.2.3, Matplotlib 3.10.8, Seaborn 0.13.2, ipykernel 7.4.0이다. 첫 두 명령은 등록된 실제 학생 자료의 실행과 공개 계산을 반복한다.

```bash
python -B reviews/week01-replacement-20261118/run_route.py reviews/week01-replacement-20261118/route.json --transport inprocess
python -B reviews/week01-replacement-20261118/joined/public_cases.py
python -B reviews/week01-replacement-20261118/joined/replay.py
python -B reviews/week01-replacement-20261118/joined/cli.py
python -B reviews/week01-replacement-20261118/joined/replay.py --verify
```

`replay.py`는 저장소 평가기를 호출하며 통합 판정 `blocked`에 맞춰 1로 종료한다. `cli.py`는 임시 입력으로 12개 실제 CLI 호출을 확인하고 그 통합 종료 코드 1을 돌려준다. `replay.py --verify`는 후보와 원자료, 그래프·판정·품질 묶음 지문, 두 차단 사유와 결합 수가 보존될 때만 0이며 `production_ready: false`를 출력한다. 명령별 실제 종료값과 평가기 지문은 결과에 담았다. [CLI 명령과 지문](reports.json)

전체 원시 CLI 입력이 필요하면 `replay.py --export <저장소의 임시 디렉터리>`로 생성한다. 저장소에 생성본을 중복 보관하지 않는다. `record_comparisons.py`는 본교안의 셀별 원문 줄과 지문을 검증한 뒤 현재 탐색 기록에 비교를 추가한다. 공개 사례만 검산했으며 별도 맹검 평가 자료는 이 검수에 사용하지 않았다.
