# 두 학습 경로의 분량을 세는 방법

실제 학생의 속도를 관찰하기 전에 사용할 편성 모형이다. 두 경로 모두 Python 기초를 배운 중학생, 설치가 완료된 Jupyter, 같은 120분 수업과 자습 계획을 전제로 한다. 코드를 실행하는 벽시계 시간은 분량 추정에 사용하지 않는다.

각 경로의 학생용 시작점에서 필수로 지정한 활동을 따라가며 셀 ID를 기록한다. 한 문제에서 코드·수치·설명을 함께 작성하면 학생이 한 번 수행한 부분을 두 번 더하지 않는다. 예시 복사와 직접 작성은 구분한다. 처음 읽는 짧은 단위·규칙·자료표나 작은 실행 한 번은 2–4분, 짧은 필기 답·추적·근거 쓰기는 3–6분, 함수 또는 배열 조작을 직접 작성하고 새 입력 한 개로 검사하는 작은 연습은 6–10분, 파일 연결·오류 분리·그림 선택 및 검증처럼 여러 판단이 이어지는 작업은 10–18분을 초기 견적 범위로 삼는다. 필기·코딩이 연결된 큰 과제는 실제로 구별되는 작업으로 나누고 기존 과제와 겹치는 부분을 표시한다. 짧은 전환·파일 이동·커널 새 시작은 1–3분이다. 이미 다룬 블록을 다시 열어 같은 데이터를 새 커널에서 준비해야 하는 경우에는 이동·준비만 다시 센다.

수업은 설명, 학생의 비코딩·필기 시도, 코딩과 점검을 나누어 120분 안의 실제 활동표를 남긴다. 교사가 조절하는 대면 활동의 시간 상한과 초과 시 자습 배치의 유무를 표시한다. 자습에서 읽기, 예측·설계, 구현·재시도, 해석·복습의 시간을 합산한다. 같은 과제를 여러 능력의 근거로 인용해도 시간은 한 번만 계산한다. 필수·조건부 경로 각각에 합계 범위와 불확실성을 붙인다. 조건부 연습이 다른 활동을 대체하면 서로 배타적이라는 내용을 학생·교사용 안내에서 확인한다. 과거 교안과 새 교안의 힌트·정답 공개 조건도 같은 기준으로 판단한다.

예상 범위는 활동의 정확한 목록과 근거를 다시 검토한 뒤 정한다. 조절할 수 없는 필수 작업의 상한이 편성을 초과하거나 활동이 정확히 식별되지 않으면 시간 적합성은 미확정으로 남긴다. 교체 판단은 별도 사전등록 규약을 따른다.
