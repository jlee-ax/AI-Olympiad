# 1주차 교재 교체 사전등록

기준일은 2026-11-18이다. 대상은 변수·조건·반복·함수·리스트·파일 읽기를 조금 연습한 한국 중학생이다. AI 선행이나 pandas 경험을 전제로 하지 않는다. 최종 비교 대상은 두 경로다. 기존 경로는 기존 진입 교안과 배정된 보충 자료를 포함하고, 보완한 새 경로는 새 진입 교안과 진단 근거가 있는 추가 자료를 포함한다. 두 경로에 동일한 학습 전제·문항·입력·판정 기준을 적용한다. 보완 전 새 경로(R3)는 형성 진단의 기준선으로만 사용한다. 이 규약을 작성할 때 저장소에서는 10주 계획 HTML만 읽었다. 기존·후보 교안, 교사용 해설과 과거 평가 자료는 열지 않았다. 기초 요건과 근거의 출처는 [근거와 선수 관계](sources.md)에 있다.

## 사전 고정한 두 세트

| 용도 | 구성 | 배정 시간 | 정확한 파일 묶음의 SHA-256 |
|---|---|---:|---|
| 형성 진단 | 세 독립 과제, 질문·원자료·채점표·검산기 7개 파일 | 35분 | `33e6a6da604cda42513709da68d6d494d70ba3e06787c3e7ecc29070df513a2f` |
| 최종 전이 | 네 독립 과제, 질문·원자료·채점표·검산기 7개 파일 | 75분 | `30e43de394006489149b3c840c85ad02b8e9d2f3dd7382e1ef15b7cb4703c8ee` |

동결 시 임시 위치는 `/tmp/koai-w1-sealed-nov18/{diagnostic,final}`이다. 각 폴더 내 일반 파일을 파일명 오름차순으로 정렬해 각 파일의 정확한 바이트를 SHA-256으로 계산한다. 한 파일당 `<소문자 64자 해시>  <파일명>\n`을 UTF-8로 이어 붙이고 마지막 LF까지 포함한 명세를 다시 SHA-256으로 계산했다. 개행·공백·파일명·입력 데이터·코드·채점표가 대상이다. 아래 프로그램은 공개 후에도 같은 결과를 확인한다. 두 검산기를 각각 Python으로 직접 실행해 원래 입력, 변경 입력과 수치 반례를 확인했다. 검산기는 그림의 선택·설명·지도 가능성에 점수를 부여하지 않는다.

```sh
python verify_seal.py /tmp/koai-w1-sealed-nov18
```

진단과 최종은 서로 다른 상황, 자료, 질문과 변경 조건으로 작성했다. 진단 세트로 보완할 때는 진단이 드러낸 일반적인 막힘만 집필자에게 전한다. 최종 파일과 채점표는 독립 판정자에게만 제공하며 후보 파일의 버전·해시를 먼저 기록한다. 최종을 본 뒤 바뀐 경로에는 이 세트를 다시 독립 최종 검사로 사용할 수 없다. 판정 기록을 확정한 뒤 정확한 두 묶음을 공개하여 재채점할 수 있다.

## 최종 확인할 수행

1. 한 요구를 Python 함수로 바꾸고, 선택 조건이 달라지면 결정을 바꾸어 다른 입력에서 확인한다.
2. 새 CSV의 한 행, 열의 역할·시점·유효값을 밝히고 원래 사례의 수와 뜻을 지켜 선택·집계·병합한다. 수정 자료에서 다시 읽어 결과를 해석한다.
3. 새 배열의 축이 가리키는 대상과 원소의 대응을 따라가며 계산한다. 모양·수치·단위를 직접 검산하고 입력 배치가 바뀌었을 때 방법을 고른다.
4. 관측의 분포와 범주별 차이를 질문에 맞게 나타낸다. 작은 계산과 실제 두 시각화 라이브러리의 결과를 연결하고 데이터가 달라졌을 때 해석을 다시 한다.

각 문항에서 **G**는 실행 전에 대상과 방법을 스스로 고르는 증거, **I**는 올바르게 구현한 기본 결과와 확인, **W**는 이유·적용 조건이나 반례, **T**는 다른 입력·요구에 대한 선택과 검증이다. 서로 다른 유효한 방법, 수학적으로 동등한 기술 및 한국어 설명을 인정한다. 패키지별 요구는 1주 계획에 적힌 실제 실행 기회로 확인하며 특정 함수명·표현 순서·교재의 비유에는 점수를 부여하지 않는다. 빈칸을 채울 방법이나 사용할 연산을 질문에 제시한 경우 그 사례의 G 점수를 주기 어렵다.

### 학생이 실제 응시하는 경우

소단원마다 빈 세션에서 질문을 읽고 계획을 기록한 뒤 계산·코딩·변경·설명하는 순서를 지킨다. 일반 API 문법은 조회할 수 있다. 이미 본 완성 답안이나 정확한 풀이 힌트를 참고하면 해당 증거에 '도움'을 기록한다. 각 문항의 G·I·W·T는 채점표의 조건을 충족하면 1, 아니면 0이다. 4개는 충분, 2~3개는 부분, 0~1개 또는 명시된 핵심 오판을 스스로 고치지 못한 답은 미흡이다. 비교용 75분이 끝났을 때의 결과와 이후 보충 결과를 구분한다. 같은 학생이 두 최종 경로를 차례로 배우고 같은 문항을 다시 풀면 연습 효과가 섞인다. 여기에는 학생 결과가 없다.

### 교재만 비교할 경우

모든 판정자는 먼저 동일한 최종 문항을 읽고 **경로별로** 해당 주차만 배운 초심자가 무엇을 근거로 접근할 수 있는지 확인한다. 각 F1–F4 × G·I·W·T에 교안/셀 위치, 학습자가 볼 단서, 결정에 필요한 작업 또는 부족한 연결을 남긴다. 지정된 문제 데이터의 정답과 독립 검산은 실행 근거란에 따로 적는다. 평가자가 이미 알고 풀 수 있는 정도를 교재에 돌리지 않는다.

| 기호 | 1점을 주는 교재 증거 | 0점에 머무는 경우 |
|---|---|---|
| G | 작동 예와 연습 뒤, 목표에서 방법을 선택하는 독립 시도가 있다. 보기나 함수 설명을 참고해도 연산과 판단 기준을 학습자가 결정한다. 문제와 같은 원리의 다른 소재도 인정한다. | 문제 제목·따라 칠 코드·미리 보이는 정답이 선택을 끝내 주거나 근거가 평가자의 배경지식에만 있다. |
| I | 해당 주에 도달 가능한 설명·작은 원자료·실행 가능한 연산이 이어져 기본 계산을 재구성할 수 있다. 교재 실행 및 별도 문항 검산을 구별한다. | 함수명 목록·완성 출력·외부 링크만 있거나 제공 파일로 핵심 연산이 성립하지 않는다. |
| W | 왜 그 방법이 목적과 맞는지 값·축·단위·대상 등 구체적인 증거로 설명하게 한다. 다른 조건에서 실패하거나 다른 법이 맞는 예가 있고, 학습자가 우선 판단할 기회가 있다. | 규칙만 선언하거나 틀린 경우를 찾고 바로잡을 근거 없이 정답만 읽는다. |
| T | 독립 입력에서 의미 있는 조건 또는 입력 구조가 바뀌고, 무엇을 유지·변경할지 스스로 결정한 뒤 결과를 점검한다. 여러 작은 연습이 합쳐 이 기회를 주어도 된다. | 고정 코드를 다시 실행하거나 같은 역할을 하는 이름·숫자만 바꾸며 필요한 판단은 이미 고정되어 있다. |

정확한 최종 질문의 소재나 특정 API가 교재에 그대로 나올 필요는 없다. 점수가 엇갈리면 반대 판정을 지지하는 셀도 함께 확인한다. 확인되지 않는 증거는 `?`로 남기고 교체 근거 계산에서는 0으로 취급한다. '교재가 제공하는 독립 연습의 기회'와 '평가자가 얻은 올바른 출력'과 '실제 학생의 독립 달성'을 각각 명시한다. 앞의 둘로 마지막 결과를 추정해 보고할 수 없다.

### 중대한 오류와 시간

원자료·결과의 대응을 틀리게 가르치고 자체 점검도 통과시키는 경우, 미래의 실제 정답을 입력에 사용하거나 결측·연결 중복으로 실제 대상 수가 달라진 결과를 옳다고 승인하는 경우, 의미가 바뀐 축이나 단위를 같은 결과로 설명하는 경우, 분산·표본 수·축의 뜻을 바꾸어도 같은 결론을 승인하는 경우는 해당 문항에서 미흡이다. 경로의 설명이나 필수 정답이 이런 오류를 지속적으로 가르치거나 필수 파일/실행이 막혀 주차 안에서 복구할 수 없으면 전체 교체 후보에서 제외한다. 학생에게 탐색용으로 보여 주고 스스로 발견·수정하도록 정확히 해설한 실패 사례는 근거가 될 수 있다.

수업은 이론 20분, 비코딩 20분(필기 연습·해설 10분 포함), 코딩 80분으로 총 120분이다. 자습은 300~420분의 **기존 추정**이다. 진단과 최종을 실제 운영할 때 35분과 75분은 같은 종류의 기존 연습을 대체하는 배정안이다. 독립 검토 문항을 교재의 새 필수 과제로 통째로 더하지 않는다. 대체할 필수 연습이 이미 다른 목적을 담당하면 남은 수행 기회와 소요를 함께 계상한다.

시간표에는 경로별 필수 블록의 읽기, 첫 실행, 도움 없이 작성, 변경·디버깅, 설명·새 세션 재실행, 보충 분기를 구분하여 수업/자습별 하한과 상한(분)을 쓴다. 같은 동작은 한 번만 센다. 공통 활동은 같은 가정을 사용한다. '선택'으로 표시됐지만 본문·채점 통과에 필요한 부분은 필수에 넣는다. 공통 원래 배정에서 바꾼 활동은 어떤 활동이 몇 분 줄고 늘었는지 보여 주면 된다. 기존 계획의 5~7시간을 그대로 옮겨 적거나 커널 실행 초를 학습 시간으로 환산한 값에는 근거 점수를 주지 않는다. 범위 상단에서 120분/420분을 넘거나, 추정이 불완전해 계획 안에 넣을 수 있는지 확인되지 않으면 **시간 근거 미확인**으로 둔다. 5시간은 최소 의무 체류 시간이 아니다. 1주 전 Python 기본 보충 6~12시간과 그 밖의 추가 지원은 따로 기록한다. 모든 수치는 학생 시간 관찰 전 편성 판단이다.

### 교체를 결정하는 규칙

1. 두 최종 경로에 같은 최종 16칸(4문항 × 4증거)과 같은 자료로 증거표를 채운다. 1주 필수 비트는 모두 비교하되, 예를 들어 조합 방법에 대해 한 교재에만 특정 API를 요구하지 않는다. 문항마다 충분/부분/미흡을 함께 기록한다.
2. 시간 근거·필수 범위·실행·중대한 오류를 먼저 확인한다. 기존 경로가 제공한 정당한 선택, 예외/반례, 정상 자료 처리와 추가 보충 진입로가 그대로 쓰이는지 또는 동등한 경로가 있는지 기록한다. 기존 셀 → 후보 위치/방법 → 언제 배우는지 → 빠지면 어느 학생/문제에서 손해인지 대응시킨다. 1주 필수를 다음 주로만 보내면 손실이다. 원래 후속 주의 확장 과제를 옮길 때는 후속 계획이 이미 그 활동을 수용하는지 구체적 주차·목표·시간으로 확인한다. 한 방법을 다른 동등하게 타당한 방법으로 바꾼 것과, 특정 상황을 해결할 수 없게 된 것은 구별한다.
3. **전체 교체**에는 다음 조건을 모두 요구한다. 보완한 새 경로가 네 문항 모두 3개 이상, 그중 세 문항 이상 충분이어야 한다. 따라서 3/4점은 그 문항의 ‘부분’이며 많아야 한 문항에서만 허용된다. 이 경우 나머지 세 문항이 모두 4/4이어야 하고 아래의 보존·개선·시간·오류 조건도 충족해야 한다. 네 문항 모두 4/4인 경우에도 나머지 조건을 적용한다. 기존이 뒷받침한 G/I/W/T나 위의 실질적인 필수 학습 경로가 사라지지 않아야 한다. 서로 다른 두 문항 이상에서 기존보다 새로 1점이 생기고 적어도 한 점은 G·W·T 중 하나여야 한다. 필수 작업이 시간 범위에 들어가며 비용 증가/절감을 같은 기준으로 설명해야 한다. 높은 문항 수치 하나가 범위·실행·시간의 결함을 상쇄하지 못한다.
4. 보완한 새 경로가 위 조건을 모두 충족하면 전체 교체를 선택할 수 있다. 요건을 충족하는지 확인하지 못했거나 서로 다른 장단점이 남으면 기존 경로 유지 또는 **검증할 부분 수정 제안**을 기록한다. 두 경로의 증거가 동등하면 새로 얻은 증거라는 요건을 충족하지 못한다. 부분 수정 결과를 통째로 최종 검증한 것처럼 쓰지 않는다.

판정에는 무엇이 우세하지 않았는지, 확인한 수치·실행과 확인하지 못한 학생 수행을 함께 적는다. 이 규칙과 문항은 연구진의 교재 비교 도구이며 KITPA의 채점 규정이나 실제 KOAI 출제 예측치가 아니다.
