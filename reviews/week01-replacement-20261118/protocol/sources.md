## 필수, 진단과 후속의 경계

| 위치 | 학생이 할 수 있도록 도울 일 | 경계의 이유 |
|---|---|---|
| 시작 전/진단 | 파일 읽기와 기본 오류 확인, 조건·반복·함수로 작은 입력을 처리. 계획의 Python 5중 4, shape·axis 4중 3 목표와 미달 시 별도 보충 경로를 점검한다. | 이미 연습한 문법은 진입 조건이면서 실제 데이터를 다루는 도구다. 전체 초급 문법 과정을 수업 120분에 다시 넣을 수 있다는 근거는 없다. 형성 진단 자체가 이 기존 진입 기준을 대체하는 시험은 아니다. |
| 1주 필수 | 한 행·열·단위·자료형, 특성/정답과 코드의 역할, 관측과 결측의 구별, CSV 읽기·선택·키 연결·집계·변경 파일, 행 수 검증과 자료사전. | 차주 전처리 전에 누구에 관한 어떤 자료가 있는지 알아야 한다. 합친 표의 실제 사례 수를 모르면 정상 실행도 확인 기준이 되지 않는다. 특정 키 검사 API나 모든 종류의 SQL 조인은 필수로 지정하지 않는다. |
| 1주 필수 | 반복·함수, NumPy 인덱싱·shape·axis·dtype·브로드캐스팅·reshape·transpose. 평균·분산과 내적을 작은 수로 설명하고 검산. | 바꾸는 축, 남길 축, 짝을 이루는 특성을 확인해야 다음 주 통계·3주 회귀·후속 텐서로 연결된다. 원소 수만 맞는 배열에서도 해석이 달라질 수 있다. |
| 1주 필수 | 실제 Matplotlib·Seaborn을 모두 사용. 분포·범주 비교에서 축·단위·집계 방식을 읽고 다른 자료에서 관찰을 다시 설명. 새 세션에서 처음부터 실행. | 질문에 따라 한 표시의 의미가 달라진다. 그래프 모양을 예쁘게 그리거나 특정 스타일을 외우는 일은 비교 근거가 아니다. |
| 연결/후속 | 1주는 예측 시점에 제공되는 열, 행·개체·측정의 차이를 식별하면 충분하다. 2주의 학습/검증/테스트, 전처리 fit, 대체·지표·시간 분할, 3~6주의 회귀·거리·PCA·PyTorch·GPU, 7~10주의 실제 모델 및 모의시험은 그 주차에서 수행한다. | 1주에서 가능한 정확한 산술·의미·사용 가능성 확인이 뒤 주차에 필요한 질문을 준비한다. 미래 정보의 평범한 구별을 완전한 누수 방지 파이프라인 구현 능력과 동일시하지 않는다. |
| 근거 부족 | 특정 분야의 예제를 풀면 어느 새 분야든 독립 해결, 합격·점수 향상, 실제 5~7시간 완료, 모든 학생의 전범위 성취. | 공개 문제·문서 검토·독립 검산으로 학생 행동이나 통과율을 측정할 수 없다. |

수치와 도구 동작은 라이브러리의 공식 설명을 대조했다. pandas는 연결 키와 결합 구조에 따라 결과 행이 달라진다. NumPy는 브로드캐스팅을 뒤쪽 차원부터 맞추고 분산 계산에서 분모 선택을 명시한다. 시각화 문서는 분포의 구간과 범주 안 관측·요약 표현을 구별한다. 이러한 문서는 구현 근거이며 시간이나 교육 효과 자료는 아니다.
