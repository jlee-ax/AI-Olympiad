# 처음부터 만든 1주차 교안의 비교 결과

**기존 1주차를 유지하고 새 교안의 CSV·배열 활동을 시범 적용할 것을 권고한다.** 학생은 새 본문에서 자료를 읽고, 서로 다른 두 요청에 어떤 계산을 쓸지 정하며, 같은 자료 한 칸을 수정한 뒤 두 결과가 어떻게 달라지는지 검산한다. 첫 결합에서 문제가 생긴 학생만 보충 자료를 열고, 그곳의 새 자료에서 오류를 고친 뒤 원래 과제로 돌아온다. [새 교안](../../lessons/week01/week01_foundations.ipynb) · [조건부 보충](../../lessons/week01/week01_foundations_repair.ipynb) · [교사용 해설](../../lessons/week01/week01_foundations_teacher.md)

새 학생용 파일이 없던 커밋에서 시작해 다섯 차례 원고를 남겼다. 독립 검토를 거치면서 관측 하나와 집단 하나의 비중 차이, 연산을 고르는 순서, 결측·실제 0·문자열 식별자를 분리하는 방법을 보강했다. 네 번째 원고는 학생이 입력을 고치고도 앞서 만든 두 출력을 다시 확인하지 않고 끝낼 수 있어 반려됐다. 다섯 번째에서는 그 확인을 기존 정정 연습에 통합했다. [회차별 기록](../week01-depth-20261118/rounds) · [실험 설계와 공식 근거](protocol/sources.md)

기존 경로는 통합본이 안내한 네 노트북 전체를 읽었다. 두 검토자는 집필에서 분리한 새 문제를 각자 풀고, 두 교안의 학생 자료를 반대 순서로 검토했다. 새 교안은 **다른 CSV의 식별자·집계 단위를 스스로 정하는 활동**과 **요청에 맞게 배열의 축·단위·연산을 고른 뒤 변경 입력으로 검산하는 활동**에서 일관된 근거를 보였다. 반면 적합한 후보 중 하나를 선택하고 동률을 처리하는 함수 설계가 약했다. 기존에 있던 실제 모델 검증, 마스크 경계, 벡터 검색의 학습 경로 일부도 빠졌다. 이 두 활동을 기존 교안에 실제 편입했을 때의 효과는 미측정이다. [기존 활동과 후속 주차의 대조](preservation.md)

수업 편성은 두 경로 모두 120분이다. 같은 산정법으로 계산한 필수 자습 추정은 새 교안 200–373분, 기존 경로 388–729분이다. 새 교안의 복구 분기를 한 번 쓰면 222–417분, 두 실마리도 모두 쓰면 226–425분이다. 가장 긴 경로에서는 계획 상한 420분을 5분 넘을 수 있다. 실제 학생의 소요 시간·성취는 관찰하지 않았다. [산정법](workload-method.md) · [활동별 새 교안 견적](workload/replacement.json) · [기존 경로 견적](workload/incumbent.json)

새 경로 코드 32셀과 기존 경로 코드 81셀을 노트북별 새 커널에서 실행했다. 표의 정상·오류, 결합 실패 후 보충·복귀는 31개 대조로 확인했다. 공개 브랜치에서는 학생 자료의 실제 파일·진입 경로·시간 장부·커널 실행을 다시 검사한다. 봉인 평가 원본과 개별 판정은 별도의 로컬 연구 기록에 보관했다. [새 경로 실행](execution/replacement.json) · [기존 경로 실행](execution/incumbent.json) · [그래프 및 품질 검사](joined/README.md)
