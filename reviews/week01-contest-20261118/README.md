# 1주차 교안 검토 · 그림 네 점의 감정 결과로 어디까지 판별할 수 있는가

**판정.** 학생에게 실제 대회 자료로 판별식을 세우고 반증하는 일을 맡길 수 있는 실험 교안이다. 교실에서는 그림 두 점의 측정값에서 출발해 거리와 단위가 정하는 결정 경계를 그린다. 자습에서는 학생이 자기 식을 함수로 작성하고, 공개 감정 결과 하나씩을 가린 뒤 틀린 그림을 설명한다. [학생 교안](../../lessons/week01/week01_foundations.ipynb) · [교사용 해설과 손계산](../../lessons/week01/week01_foundations_teacher.md)

### 무엇이 바뀌었나

이전 판본은 새 CSV의 병합, 축별 계산과 오류 수정은 확인했지만, 같은 그림을 놓고 경쟁하는 두 판별식을 비교하거나 틀린 예측을 근거로 가정을 고치는 일은 요구하지 않았다. 이번 판본의 첫 과제는 A(0,5), B(4,0), Q(3,4) 세 점에서 어느 측정값을 믿을지 정하는 것이다. 원래 단위에서 Q의 거리제곱은 10과 17이고, 첫째 값만 10배로 표시하면 901과 116이다. 단위 선택이 판정까지 바꾸는 이유를 경계의 식과 그림으로 확인한다. [이전 학생용 고정본](https://github.com/jlee-ax/AI-Olympiad/blob/85211bc61260e8281f90aa15f6119255e1a07f53/lessons/week01/week01_foundations.ipynb)

공식 IOAI 2025 `Antique Painting Authentication`에서는 다섯 수치로 진위를 예측한다. 500점 중 진품 두 점, 복제품 두 점만 감정 결과가 공개됐고 나머지 496점의 측정값 활용도 요구했다. 교안은 공개 훈련 파일을 그대로 쓴다. 입력과 라벨, 행 위치와 반환값, 아직 감정하지 않은 상태와 측정값 0을 구분해야 풀이가 작동한다. 다른 공식 과제에서 따온 마지막 연습은 반대 표시의 표지판 **번호**를 찾게 해 같은 거리 계산을 다른 명세에 맞게 바꾸도록 한다. [그림 진위 판별 원문](https://github.com/IOAI-official/IOAI-2025/blob/39558e9a639d170bd92de91958fcdc915f670463/Individual-Contest/Antique/Antique.ipynb) · [표지판 검색 원문](https://github.com/IOAI-official/IOAI-2025/blob/39558e9a639d170bd92de91958fcdc915f670463/Individual-Contest/Restroom/Restroom.ipynb) · [국내 범위와의 관계](sources.md)

### 학생에게 답을 맡겼는지 어떻게 점검했나

| 발견한 문제 | 바꾼 내용 | 확인한 결과 |
|---|---|---|
| 최초 검수 기준으로는 제공된 분류기를 실행하고 그림만 그려도 통과할 수 있었다. | 집필 전에 기준을 반려하고, 학생 자신의 식·동점 규칙·새 입력 반례와 같은 조건의 비교를 필수화했다. | 첫 기준과 반려 기록, 수정 기준과 독립 판정을 함께 보존했다. |
| 학생이 만든 두 좌표의 손계산과 실제 코드가 요구하는 다섯 열 표 사이가 비어 있었다. | 학생이 고른 수를 같은 모델 함수에 전달하는 도구와 작은 사용 예를 넣었다. | 독립 검토자가 교사용 답을 열기 전에 별도 식과 입력을 만들고 실제 네 그림과 새 사례에서 실행했다. |
| 표준편차가 평균절대편차와 우연히 같은 수치로만 설명됐고, 가린 정답과 다수결 결과를 먼저 짐작하게 하는 문장이 있었다. | 비대칭인 세 수의 분산·표준편차를 직접 계산하고, 점수를 드러내는 문장을 학생용 정적 본문에서 제거했다. | 최초 실행에는 미상 산점도와 손계산 경계만 표시된다. 자기 규칙을 등록하면 네 행의 예측표와 감정 그림 네 점이 열린다. |
| 두 파일의 행 순서와 배열 모양이 우연히 맞으면 잘못 연결한 값도 정상처럼 보였다. | 다른 열 이름·순서·결측이 있는 두 CSV와 그림/측정 항목 순서가 다른 배열을 실습에 넣었다. | 감정표 역순, 실제 0, 감정 미상, 감정표 미기록이 다른 상태로 남는다. 독립 입력에서는 잘못 전치하면 선택할 그림 자체가 바뀐다. |

### 실제 자료에서 얻은 것

| 검사 | 결과 |
|---|---|
| 알려진 그림 한 점을 뺀 뒤 훈련 | 회차마다 세 감정 그림과 미상 496점으로 새로 맞췄다. 평가할 그림은 측정값까지 훈련에서 빠진다. |
| 같은 네 점의 진위 예측 | 다수결 0/4, 원래 단위의 최근접 2/4, 표준화한 최근접 3/4, 교사용 중심점 풀이 3/4였다. 183번째 그림에서는 가장 가까운 그림이 복제품 47번에서 진품 142번으로 바뀌었다. 142번째 그림은 두 최근접 방법 모두 틀렸다. |
| 명세를 바꾼 검색 | 풀이가 사진 번호를 반환하고 입력을 뒤집어도 결과가 유지되며 적격 후보가 없으면 결과가 비는지 확인했다. 원본 대회의 실제 이미지로 학습한 검색 성적은 측정하지 않았다. |
| 재실행과 고의 오류 | 빈 학생 함수 상태와 작성 후 상태에서 도표·예측·교사용 코드·제출 파일을 실행했다. 동점에서 마지막 행을 고르거나 새 질의까지 사용해 훈련 폭을 추정하도록 계산을 바꾼 사본에서는 해당 검사가 실패했다. |

**적용 범위.** 한 점 차이는 25%포인트이며 네 점은 최초부터 공개된 훈련 자료다. 이 숫자에서 공식 비공개 평가 성적이나 실제 학생의 새 문제 해결률을 추정할 수 없다. 120분 수업과 330분 필수 자습, 선택 포함 375분은 편성치다. 독립 검토에서 필수 자습은 235–410분으로 추정했고, 느린 학생이 선택 활동 45분을 모두 하면 455분으로 7시간을 넘는다. 그런 경우 선택 활동은 남은 시간 안에서만 진행한다. 기존 10주 계획의 Python 5문항·배열 4문항 진단과의 동등성도 미확인이다. 실험 브랜치에서 경시 문제 풀이 단원으로 채택할 근거를 확보했으며, 기존 1주차 전체를 대체할지는 열린 판단으로 남긴다.
