# 합성 예시의 계획 맥락 영향 확인

별도 검토자 `/root`가 `examples/quality.json`의 합성 `unit:axis`와 `claim:axis`, 직전·현재 학생 계획의 해당 범위를 읽고, 평가 분할 원칙의 변경이 NumPy 축 평균 예시의 합성 목적·입력·기준을 바꾸지 않는다고 확인했다. 이전 계획 SHA-256은 `cbe69f862ae76a87cd69233889c7fd6698e38ac34eb4d385f2b825722daeabb5`, 현재 계획은 `c60063bf1c55b957f4b6271a0796d5301d9f209de28a91d468c0c20e72fa0133`다. 현재와 이전 계획의 1주 행 및 해당 범위 행은 변하지 않았다.

해당 예시의 2×3 입력 `[[1,2,3],[4,5,6]]`에서 축 0 평균 `[2.5,3.5,4.5]`는 변경된 개체·시간 분할 지침과 독립된 합성 수치다. 다섯 새 K02/K05/K09/K15/K16 기록은 이 합성 시연의 범위 확인을 반영한 가상 제어이며 기존 12개 예시 검토를 덮어쓰지 않는다. 가상 실행·평가·검토자와 도움·학생 수행은 실제 수업이나 학습자 결과가 아니다. 이 점검은 실제 1주 교안이나 학습 효과를 승인하지 않는다.
