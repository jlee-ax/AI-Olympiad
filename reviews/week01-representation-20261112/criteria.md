# 1주 표현 연결 독립 검증 기준 (수정 전)

기준 통합 후보는 Git blob `4a024e233e8a1a8ff39d145bccb5cb4c3b4827b9`, 기존 본문은 e3d3afde의 96셀 버전이다. 학생 성취·시간을 관찰한 기준이 아니다.

1. 기존 화분 P02 관찰에서 출발해 표의 관찰 열과 한 칸의 배열을 분명히 구분한다. 코드 실행에서 열 shape와 각 배열 shape, 실제 ID, P02의 노란 잎 수 1을 확인한다. 이 사례의 object Series를 모든 pandas 열과 혼동하지 않는다.
2. 행 순서를 섞고 인덱스를 비연속 값으로 바꿔도 ID와 관찰이 맞는지 검증한다. ID 위치(첫 행)만 사용해 일치한 결과를 합격으로 치지 않는다. 없는 ID와 중복 ID는 코드가 약속한 계약에 따라 확인하고, 오류 처리 주장이 없는 경우 구현된 것처럼 말하지 않는다.
3. 설명용 자료에 대한 변경 실험이 제공된다면 원래 잎 사전과 입력표·패널의 값이 보존되는지 검증한다. 표 사본의 object 칸 안 배열 공유와 배열별 복사를 구분하고, 변경하지 않은 경우 보존을 추정하지 않는다.
4. 기존 독립 기기 문제의 데이터·검증 공개 순서와 빈 학생 답안은 바꾸지 않으며 기기의 특성 조립, 평가/모델 풀이를 제공하지 않는다. 2주차와 사용자의 기존 본문·교량은 바이트가 동일해야 한다. 별도 1주 선수 다리로 모델 완수나 학생 전이를 주장하지 않는다.
5. 통합 교사용 안내의 본문 과제 C/D/E 위치는 96셀 본문의 실제 제목·셀 ID에 맞는다. 코드 실행 순서와 별도 커널 복귀도 기록된 경로와 맞는지 확인한다.
6. 독립 검토는 새 노트북이 정한 허용 입력·경계만 평가한다. 새 구현 전체 실행과 HTML/출력의 동기화는 별도이며 실제 학생 수행과 같은 것으로 보지 않는다.
