## 기존 범위와 비교

기존 본교안은 반복 누적, 입력 불변 및 목록 슬라이스를 다룬다. 그러나 목록 슬라이스 예는 이후 원소 변경을 추적하지 않고, 통합본의 복사·뷰 설명은 완성 예시다. 기존 기기 문제는 T2의 범주·배경·전치와 특성을 묻지만 원본·뷰·복사·저장된 계산 결과의 상태를 독립적으로 추적하지 않는다. 이 점을 ‘상태를 전혀 다루지 않는다’고 일반화하지 않는다. 기존 영역 과제는 호출 중 입력 불변만 계약이므로, 반환 후 crop의 변경에도 독립이어야 한다는 조건을 소급 적용해 기존 답을 탈락시키지 않는다.

기기 2번의 T2를 사용해 입력 복사 → 상태 채널 뷰 → 뷰의 사본 → 이미 저장한 정수와 변경 후 재계산을 예측·확인하는 방법을 우선한다. 본래 과제의 배경·축과 수치 특성·후속 모델 학습에 이어지지만 기존 문제를 더 어렵게 만드는 실제 수행 요구다. 실제 소요시간과 학생 이해는 관찰되지 않았다. 기존 영역 과제에 독립 반환을 새 명세로 도입하는 대안은 원본/반환값 계약을 직접 다룰 수 있으나, 이미 복잡한 사각형 함수에 새 계약을 더하고 계산 결과의 시점은 덜 직접적이다. 함수의 가변 기본 인자는 고등부 예시에 직접 등장하므로 후속 진단으로 남기되 이번에 다룬 정수 특성의 동작만으로 해결되었다고 하지 않는다. 누수·평가 목적은 2주에 이미 구체적으로 다루며 이를 무조건 1주에 되풀이하지 않는다. 자료 병합의 결측 키는 의미가 미상일 때 위험하지만 모든 결측 키 일치를 무조건 오류로 처리하지 않는다.

## 사전 고정한 검증

1. 기준 대비 셀 순서·ID·메타데이터, 학생 코드와 출력을 대조한다. 실험 요구가 있는 문제·답란 및 설명 외의 변화, 기존 사각형 계약, 입력 및 빈 답안, 2주차 변경 여부를 확인한다.
2. 입력을 준비한 뒤 변경 코드를 실행하기 전에 T2의 원본·실험 배열·뷰·뷰 사본·저장된 정수·다시 계산한 정수를 예측할 수 있는지 본다. 결과를 학생 본문에 제공하지 않고 계산식·수치 특성·모델은 학생이 정하게 하며, 배경의 의미와 전치도 보존한다. 학생용과 공개 교사용 해설을 분리한다.
3. 실제 입력 셀에서 검토자가 작성한 계산식으로 T2의 배경 변경과 센서 끄기를 실행한다. 원본 입력·다른 행 및 다른 데이터셋은 보존해야 한다. 저장된 정수의 과거 값과 재계산 값을 구별한다.
4. 독립 비연속 입력에서 배경 변경과 꺼진 센서 켜기를 시도한다. 세 오류 변형인 원본을 실험 배열로 쓰기, 뷰 대신 복사하기, 뷰의 사본 대신 뷰 자체를 쓰기가 각각 원본 불변, 원본과 뷰의 연동, 사본의 불변 기대를 깨는지 검사한다.
5. 학생 셀·답란은 비어 있어야 하며 HTML이 생성된다면 소스·답란·링크와 동기화 여부를 별도 확인한다. 학생 수행, 실제 시간, 브라우저 표시, 국제 과제 해결을 관찰하지 않은 경우 확인했다고 적지 않는다.

`reproduce.py`의 시험은 검토자가 구성한 시나리오 및 변형 테스트로서 학생 자동채점기 또는 학생 제출물의 실행이 아니다.
