# 함께 논의할 결정

아래는 모두 미결정이다. 이 문서 자체는 사용자의 승인이나 자동 실행 권한이 아니다.

1. 공식 KOAI 2027 범위와 대상: 공식 공지 확인 전 대회 범위를 어떻게 가정하고 업데이트할까? 학생의 수학·코딩 수준을 어떻게 진단할까?
2. 수업 설계 우선순위: 10주 × 2시간 안에서 이해, 구현, 문제해결, 평가에 얼마만큼 시간을 배분할까?
3. 스킬 그래프의 세분도: 스킬의 최소 단위와 선수 관계, 숙련을 어떤 증거로 판단할까?
4. 30분 검토의 실제 단위: 한 주기에서 어디까지 살피고 어떤 시점에 사용자에게 보고할까?
5. 평가: 후보 지표별 판정 방식, 최소 증거, 통과 수준, 실패 및 미검증의 구분은?
6. 중단: 완료, 연속적인 개선 정체, 예산·시간 한도, 권한 부족 또는 위험의 기준은? 사람의 확인이 필요한 경계는?
7. 기록: 어떤 수준의 기록을 어디에 얼마나 보존할까? 민감 정보는 어떻게 피할까? 정리와 영구 삭제는 별도 의사결정이다.
8. 역할: 에이전트가 제안할 수 있는 변경과 사용자가 승인해야 하는 변경의 경계는?

결정 시 날짜, 결정자, 이유, 대안, 관련 근거, 다시 검토할 조건을 기록한다. 이후 새 근거 또는 요구가 생길 때에만 이유와 함께 변경한다.
